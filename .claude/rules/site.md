# Public site facts

Specs: `docs/features/waitlist-landing/spec.md` , `docs/features/landing-motion-free-tier/spec.md` and `docs/features/landing-round-seven/spec.md` and `docs/features/site-polish/spec.md`. Design: `docs/features/waitlist-landing/design.md`. Decisions: `docs/adr/0039-the-public-waitlist-is-guarded-by-turnstile-and-fails-closed.md`, `docs/adr/0040-the-waitlist-and-the-referral-cap-live-in-d1-and-the-cap-is-a-settings-row.md` and `docs/adr/0041-the-public-site-is-served-by-the-api-worker-through-host-dispatch.md`.

- **One Worker, three more hosts.** `apps/api/src/backoffice/host-dispatch.ts` sends `SITE_ORIGIN`'s host to `createSiteApp` and `www.` plus that host to a `301` to `SITE_ORIGIN` with path and query kept. Neither the site nor the MCP app mounts the other's routes, and nothing under `apps/api/src/mcp`, `apps/api/src/routes`, `apps/api/src/account-inbox`, `apps/connector` or `libs/` imports the site (`tools/repository-shape/src/backoffice-isolation.test.ts`).
- **Policy.** Every site response carries `SITE_CONTENT_SECURITY_POLICY` from `apps/api/src/site/site-policy.ts`: `script-src 'self' https://challenges.cloudflare.com`, `connect-src 'self'` for the theme save, no inline script, no inline style, no external font or image. Pages carry no `style` attribute; the invite meter is SVG attributes. The only first-party script is `/site/site.js`, served by the Worker next to `/site/site.css`; the media under `/site/` is served by the assets binding from `apps/api/site-public/site/`.
- **Language and theme.** English is `/`, Portuguese is `/pt-br`; the path decides. `/pt-br/` and a legacy `?lang=` answer `301` to the path, keeping `ref` and `agent`, and the legacy redirect sets the `__Host-zb_site_locale` cookie. `/` with no cookie and a Portuguese `Accept-Language` answers `302` to `/pt-br` with `Vary`. The language menu lives in the footer, a `<details>` disclosure opening upward, of `POST /locale` buttons with inline flag SVGs, drawn by `apps/api/src/web-shell` for every locale of the enum like the theme switch ([the shared shell rule](web-shell.md)); `POST /locale` and `POST /theme` set the cookies and redirect only to a path rebuilt from the locale enum, a known agent and a well-formed referral code. The site script applies a theme at once and saves it with a same-origin request that answers `204`; without a script the form returns to `#theme`. The script keeps every `returnTo` field in step with the address after a tab or agent pick. Copy is `apps/api/src/site/site-copy.ts` in `en_US` and `pt_BR`; no view holds a string. No copy names a fixed official number or offers bringing your own number.
- **Legal pages.** `/terms` and `/privacy` in English, `/pt-br/termos` and `/pt-br/privacidade` in Portuguese (`legal-links.ts`); the text is `legal-copy.ts`, filled from `COMPANY`, the pricing and retention constants and `LEGAL_UPDATED_ON`, which moves with every change of substance. The path decides the language; the language menu and the theme switch return to the twin page; canonical, hreflang and the sitemap pair the twins. The pages load no captcha and no demo poster, and the header join button leads to the form on the home page. The footer columns (Product, Legal, Company with the Logic Bit link and the support address), the huge text wordmark and the waitlist note link them. Portuguese prevails when the two versions differ, because Logic Bit is Brazilian.
- **Join.** `POST /join` runs, in order: the client address check, `INSTALL_PAGE_LIMITER` under the `join:` key prefix, the email shape, the Turnstile verdict, then `joinWaitlist`. Refused token `403`, Turnstile unreachable `503`, bad email `422`, rate limited `429` with `Retry-After`, no address `400`. A missing or blank `TURNSTILE_SECRET_KEY` or `TURNSTILE_SITE_KEY` renders the paused notice, never the form, and a POST writes nothing. The thank-you answer is `no-store` and carries no email.
- **Turnstile.** `verifyTurnstileToken` returns `Accepted`, `Refused` or `Unavailable`; it checks `success`, the hostname of `SITE_ORIGIN` and the action `waitlist-join`. Cloudflare's published always-pass secret answers hostname `example.com` with no action and `metadata.result_with_testing_key`, so that result is accepted only when `ENVIRONMENT` is `development`. No log line carries the token or the secret. Only the production and staging site keys are in `apps/api/wrangler.jsonc`; the secret is a Worker secret written by the owner, and the development block carries Cloudflare's published test pair.
- **Referral is closed.** `REFERRAL_SHARING_OPEN` in `site-constants.ts` is `false`: the thank-you is the calm `ThanksPanel`, the FAQ drops the referral entry and the final call drops its invite button. `ReferralThanksPanel` stays tested (`site-referral-panel.test.ts`); the cap, the credits and `?ref` capture below keep working.
- **Waitlist and cap.** Migration `0010` creates `landing_waitlist` and `site_settings`. The insert credits the referrer in the same statement only while the referrer's credited count is under the `waitlist_referral_cap` row, so concurrent joins cannot exceed it; a duplicate email writes nothing and answers with the same markup; a missing cap row makes a join answer `503` and the backoffice page show an error. The backoffice edits the cap through `POST /waitlist/cap` behind the session, the CSRF guard and a step-up code, with an audit row; `GET /waitlist/export.csv` quotes every cell, prefixes formula cells with an apostrophe and writes an audit row.
- **Media.** `apps/api/scripts/record-landing-demo.ts` records the demo from the development Worker (fake WhatsApp channel, an MCP `ask` answered by a tap, then `send_message`), renders the captured text frame by frame in `apps/api/scripts/landing-demo/stage.html` and encodes with ffmpeg into `apps/api/site-public/site/`, once per locale: `demo-<locale>-960.mp4` and `.webm`, `demo-<locale>-poster-960.webp` and `-540.webp`, `og-<locale>.png`; the page chooses them by its locale, and the CSV header of the backoffice export is in the backoffice locale. Each file is under 2 MB and the total under 6 MB; `apps/api/test/unit/site-assets.test.ts` pins that.
- **Scroll motion.** The "Why zapbip" stories (`views/why-section.tsx`, scenes in `views/why-scenes.tsx`) and every element with the `reveal` class reveal once: `site-scripts.ts` sets `has-reveal` on the document and `is-visible` on each target through an `IntersectionObserver`, and the steps run by time. Nothing is tied to the scroll position (no `animation-timeline`) and no story is pinned. All motion lives under `prefers-reduced-motion: no-preference`, and the hidden state exists only under `html.has-reveal`, so the page is complete with no script and under reduced motion (`test/integration/site-motion.test.ts`).
- **Quick start.** The "Start in 30 seconds" block (`views/quick-start-section.tsx`) is a tablist of links `<language path>?agent=<id>#start`, one per install facet agent plus "any app" (`SiteStartTab`), with one panel each. `?agent` selects the panel (first agent by default) and feeds the join hint (`site-context.ts`); browsing the tabs never touches the hint, the panel's button does. Every panel shows the example connection link `SITE_EXAMPLE_CONNECTION_LINK` (production origin, `zb_conn_` plus an `EXAMPLE-` body in the real format) with a caption that says it is an example; the code block wraps long lines. A panel shows `AGENT_INSTALLS[id].quickStart(...)` from `libs/agents` (`hint`, an optional click `path`, `code`) tinted by `code-tokens.ts`; `libs/agents/src/quick-start.test.ts` proves every install section contains its agent's whole `code`, and only the address is proven for the click-path agents. The script switches tabs without a reload, types the command in (hidden only under `has-typing`, a finite caret) and copies `data-code`. Nothing is stored. The Pricing section prices the plans from the `PRICING_*` constants in `libs/types` through `price-format.ts`, in USD for English and BRL for Portuguese; both cards say "Request access" and link to the join form, because billing is not open. Every join button says "Request access" (`Pedir acesso`) while signups are closed; no copy says "get started free".
- **Logos.** `apps/api/site-public/site/logos/<stem>.svg` exists for each `officialLogo` stem an install facet names, one file per mark, from Simple Icons (CC0 data) recorded in `NOTICE.md`; the image has an empty alt text next to the visible name and sits on a white chip in both themes. An agent with `officialLogo: null` shows its initials; a mark whose owner withdrew it (OpenAI) is never shipped (`test/unit/site-logos.test.ts`).
