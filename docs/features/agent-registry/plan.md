- A1. Folder root `libs/agents/supported/<id>/`; id = folder name = docs slug = `--client` value.
- A2. Generated files are committed; one planner serves the CLI and the shape test.
- A3. `enumMember` keeps today's member names; values are unchanged.
- A4. Order everywhere: wake-ladder rung, then the English `matrixName` in lower case.
- A5. `tsx` 4.23.15 (root) runs the CLI; Prettier 3.9.10 formats the outputs; no new external dependency. `smol-toml` 1.9.1 moves with the Codex isolation code. It is already pinned in `apps/connector`; adding it to `libs/agents` is decided (owner delegated 2026-11-06).
- A7. **Where generated files live and how the gate proves them fresh.** Inside the package: `libs/agents/src/generated/{ids,definitions,install,connector,plugins}.ts` and the rendered `supported/<id>/install.<owner locale>.md`. Outside it, because Mintlify reads `apps/docs`: `apps/docs/agents/<id>.mdx`, `apps/docs/pt-br/agents/<id>.mdx`, the matrix and connector snippets, the `Agents` and `IAs` lists of `docs.json`. Freshness (a pin landing in Step 8, after the first real run, so it is green when it lands): `tools/repository-shape/src/agent-registry.test.ts::every generated file is fresh` calls `planGeneratedFiles` over the real folders and fails unless every planned write equals the committed bytes and `deletions` and `violations` are empty, i.e. `pnpm agents:generate` is a no-op. The `shape` gate is in `ALWAYS_GATES` of `scripts/verify.sh`, so a hand edit to a generated file, or a folder edit without regenerating, fails `pnpm verify` in every class of diff. `pnpm agents:check` runs the same planner for a fast local loop.
- A8. **Order.** `libs/agents/src/legacy-order.ts` holds today's three orders (install page, matrix, navigation) and `agentOrderOf` returns them until Step 13b deletes the file and switches all three to rung then name. Until then no golden changes.
- A6. Generated paths are owned by the generator, not by a lane. Any lane may regenerate. A conflict on a generated path is resolved by rerunning `pnpm agents:generate`, never by hand.

export type DiscoveredAgent = { id: string; folder: string; facets: AgentFacet[] };

export type GeneratedFile = { path: string; content: string };
export type GenerationPlan = { writes: GeneratedFile[]; deletions: string[]; violations: string[] };
export async function planGeneratedFiles(input: { agents: DiscoveredAgent[]; readSource: (path: string) => string }): Promise<GenerationPlan>;

// libs/agents/generate/write.ts
export function writePlan(input: { plan: GenerationPlan; mode: GenerationMode }): string[];
