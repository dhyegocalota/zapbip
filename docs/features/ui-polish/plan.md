## Failure modes

| Step | What breaks | How I notice (the concrete signal) | How I back out |
|------|-------------|------------------------------------|----------------|
| 1 | The before set is taken after an edit, or on stale data | A file is missing or under 10 KB, or a before shot already shows a new token (a `#25D366` live dot) | Delete the set and retake it on a clean `main` checkout. |
| 2 | The helper changes an assertion of the existing design-rules test | Step 2's own diff shows an edited expectation, or the existing test turns red | Revert the commit; the extraction moves code only. |
| 3 | A new pair misses 4.5 (header over a dark row, `--color-text-muted` on the glow) | The contrast test names the pair and the ratio | Raise the token that the design names (header opacity, glow alpha); never lower the minimum. |
| 3, 4 | A third `:root` block or a raw colour appears in a component rule | `defines a token block for light and a second one for dark` or the raw-colour scan fails | Move the value into a token. |
| 4 | An animation sits outside the reduced-motion guard, or a keyframe loops forever | The guard scan names the declaration; the e2e `animation-name` check is not `none` | Remove it or add it to the guarded block. |
| 5 | The live dot reaches production | The production header holds `.live-dot` | Gate on `badgeKey === null` in `layout.tsx`. |
| 6 | The `h1` accessible name changes on the error pages | The text-content test differs from `404 Page not found` | Restore the joining space between the two spans. |
| 7 | A view class has no rule, or a rule has no emitter | The coverage test names the class | Add the rule, or delete the class from the view. |
| 8 | A fourth query, a per-card query or a write slips in | The spy count is not 1 batch with 4 `SELECT`s | Remove it; the batch is the whole data access of the home page. |
| 8 | The metrics merge changed `dailySeries` or `utcDay` | `typecheck` fails in `home-sparklines.ts` | Adapt to the merged signature; do not copy the helper. |
| 9 | A flat line is the only signal for a zero series | The all-zero test finds a polyline | Draw the baseline only and show `SparklineEmpty`. |
| 13 | CSP, a `style=` or a `<script>` drifts | The byte-equal pin or the scan fails | Revert the offending change; `CONTENT_SECURITY_POLICY` is never edited. |
| 14 | A page scrolls sideways at 375 (long mono target, filter bar, sparkline) | `scrollWidth` is above 375, naming the page | Fix the CSS (`min-width: 0`, wrapping); never `overflow-x: hidden` on `body`. |
| 14 | Two boxes overlap (chart label over a bar, hero copy over the phone) | The overlap helper names both selectors | Fix the layout; the helper is not loosened. |
| 17 | The pinned client rejects a `docs.json` key | `mint dev` prints a schema error | Remove the key the client rejects and record it in a learning. |
| 19 | Mintlify 0.0.4077 does not inject `zapbip.css` | The step 21 spec finds no `style[data-custom-css-path]` | The hero reads as stacked text and links; the lead picks inline styles for the hero and the CSS file shrinks to the typing keyframes. |
| 18, 20 | A pt-BR twin drifts from the English one | The Hero props parity test names the prop | Fix the pt-BR copy. |
| 21 | The docs walk breaks on a changed selector | An existing spec fails | Undo the change that moved the selector; the walk is not edited. |

**Steps with no backout:** none. Every step is a code or docs change on a branch; no migration, no data write, no deploy. Step 1 writes only git-ignored screenshots.
