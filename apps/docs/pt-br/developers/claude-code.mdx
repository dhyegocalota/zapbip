---
title: Conectar o Claude Code
description: Conecte o Claude Code a um zapbip local, do zero.
---

<Note>Este guia usa a pilha local do [Início rápido](/pt-br/developers/quickstart). A URL hospedada chega depois.</Note>

<Steps>
  <Step title="Pegue a URL do agente">
    O seed imprime `<agent> <secret>`. A URL é:

    ```text
    http://localhost:8787/c/<secret>/mcp
    ```

    O segredo na URL é a conexão. Mantenha-o privado.

  </Step>
  <Step title="Adicione o servidor">
    ```bash
    claude mcp add --transport http alpha http://localhost:8787/c/<secret>/mcp
    ```
  </Step>
  <Step title="Confira">
    ```bash
    claude mcp list
    ```

    O `alpha` aparece como conectado.

  </Step>
  <Step title="Use">
    Inicie o `claude` e escreva:

    ```text
    Use o alpha para me enviar "olá do Claude Code".
    ```

    O Claude Code pede aprovação da ferramenta na primeira vez. Depois a mensagem aparece na tela do simulador.

  </Step>
</Steps>

As ferramentas aparecem como `mcp__alpha__send_message`, `mcp__alpha__ask` e assim por diante. Veja a [referência das ferramentas](/pt-br/mcp-reference/send-message).
