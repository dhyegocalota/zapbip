---
title: Início rápido local
description: Rode o zapbip localmente, conecte o Claude Code e troque a primeira mensagem.
---

<Note>
  Hoje o zapbip roda na sua máquina com um WhatsApp falso: um simulador de desenvolvimento faz o papel do seu celular. O cadastro hospedado,
  em que você manda uma mensagem para o número do zapbip, chega numa versão futura.
</Note>

Você precisa de Node 24, pnpm e do [Claude Code](https://claude.com/claude-code).

<Steps>
  <Step title="Instale e configure">
    Na raiz do repositório:

    ```bash
    pnpm install
    printf 'MEDIA_LINK_SIGNING_KEY=%s\nUPLOAD_LINK_SIGNING_KEY=%s\n' "$(openssl rand -hex 32)" "$(openssl rand -hex 32)" > apps/api/.dev.vars
    pnpm --filter @zapbip/api exec wrangler d1 migrations apply CONNECTIONS --local
    ```

  </Step>
  <Step title="Cadastre um dono e dois agentes">
    ```bash
    pnpm --silent --filter @zapbip/api dev:seed --phone 5511999990000 --agents alpha,beta
    ```

    Ele imprime uma linha por agente, `alpha <secret>` e `beta <secret>`. O segredo aparece uma vez só. Cadastrar o mesmo telefone duas vezes falha.

  </Step>
  <Step title="Inicie o Worker">
    ```bash
    pnpm --filter @zapbip/api dev
    curl http://localhost:8787/health
    ```

    A chamada de saúde responde `{"ok":true}`.

  </Step>
  <Step title="Conecte o Claude Code">
    ```bash
    claude mcp add --transport http alpha http://localhost:8787/c/<alpha-secret>/mcp
    ```

    Mais em [Conectar o Claude Code](/pt-br/developers/claude-code).

  </Step>
  <Step title="Abra a janela">
    O simulador é o seu celular. O WhatsApp só deixa o zapbip escrever livremente depois que você escreve, então comece com uma mensagem para o `alpha`:

    ```bash
    curl -X POST http://localhost:8787/dev/owner/5511999990000/messages \
      -H 'Content-Type: application/json' \
      -d '{"kind":"text","text":"@alpha hello"}'
    ```

  </Step>
  <Step title="Envie uma mensagem pelo agente">
    No Claude Code, rode `claude` e escreva:

    ```text
    Use o servidor MCP alpha para me enviar "zapbip funciona" e me perguntar "Subir a v2?" com as opções Sim e Não.
    ```

  </Step>
  <Step title="Veja na tela do celular">
    ```bash
    curl http://localhost:8787/dev/owner/5511999990000/screen
    ```

    As entradas trazem `zapbip funciona` e a pergunta com suas opções.

  </Step>
  <Step title="Responda">
    ```bash
    curl -X POST http://localhost:8787/dev/owner/5511999990000/messages \
      -H 'Content-Type: application/json' \
      -d '{"kind":"text","text":"Sim"}'
    ```

    A chamada em espera no Claude Code devolve a sua resposta.

  </Step>
</Steps>

## Em breve

O serviço hospedado, em que você manda mensagem para o número do zapbip e recebe a URL do seu agente no WhatsApp, ainda não está disponível. Até lá, tudo acima é a porta de entrada.
