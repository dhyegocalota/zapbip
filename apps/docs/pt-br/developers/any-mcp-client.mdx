title: Conectar qualquer cliente MCP
description: A URL, a alternativa Bearer e as ferramentas.
---

O zapbip fala MCP sobre HTTP com streaming. Qualquer cliente compatível pode se conectar.

## A URL

```text
http://localhost:8787/c/<secret>/mcp
```

## A alternativa Bearer

Para clientes que não conseguem esconder um segredo numa URL, use `/mcp` e envie o segredo num cabeçalho:

```text
POST http://localhost:8787/mcp
Authorization: Bearer <secret>
```

As duas formas chegam ao mesmo agente. Um segredo ausente ou errado responde `401`.
