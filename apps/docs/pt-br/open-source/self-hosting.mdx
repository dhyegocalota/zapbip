O zapbip é código aberto. O código, as decisões por trás dele e o processo que o constrói são públicos no [repositório do GitHub](https://github.com/dhyegocalota/zapbip). As licenças estão na página [Licença](/pt-br/open-source/license).

## Rode sua própria cópia

| Opção             | Ideal para                                        | Guia                                                        |
| ----------------- | ------------------------------------------------- | ----------------------------------------------------------- |
| No seu computador | Experimentar o zapbip e trabalhar nele            | [Rodar o zapbip localmente](/pt-br/open-source/run-locally) |
| Docker            | Um comando, com seus dados guardados em um volume | [Rodar o zapbip localmente](/pt-br/open-source/run-locally) |
| Cloudflare        | Produção com o seu próprio número de WhatsApp     | [Publicar na Cloudflare](/pt-br/open-source/deploy)         |

## Contribua

- Leia primeiro o [CONTRIBUTING](https://github.com/dhyegocalota/zapbip/blob/main/.github/CONTRIBUTING.md). Abra uma issue antes de uma mudança maior.
- Testes são obrigatórios, e toda contribuição vem sob o [Contrato de Licença do Contribuidor](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md).
- Reporte vulnerabilidades em privado, como o [SECURITY](https://github.com/dhyegocalota/zapbip/blob/main/.github/SECURITY.md) explica, nunca em uma issue pública.
- Todos seguem o [código de conduta](https://github.com/dhyegocalota/zapbip/blob/main/.github/CODE_OF_CONDUCT.md).
