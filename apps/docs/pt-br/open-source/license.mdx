O zapbip é código aberto sob duas licenças, uma para cada parte do código.

| Parte                                       | Licença                                                                         |
| ------------------------------------------- | ------------------------------------------------------------------------------- |
| O servidor, o site e as bibliotecas         | [GNU AGPL v3.0](https://github.com/dhyegocalota/zapbip/blob/main/LICENSE)       |
| O conector local e os plugins de canal      | [MIT](https://github.com/dhyegocalota/zapbip/blob/main/apps/connector/LICENSE)  |

Os plugins de canal para [OpenClaw](https://github.com/dhyegocalota/zapbip/blob/main/apps/openclaw-plugin/LICENSE) e [Hermes](https://github.com/dhyegocalota/zapbip/blob/main/apps/hermes-plugin/LICENSE) também são MIT, e cada pacote traz o seu próprio arquivo `LICENSE`.

## Contribuições
