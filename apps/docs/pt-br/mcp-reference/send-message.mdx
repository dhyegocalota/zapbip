Envia uma mensagem de texto ao dono.

## Entrada

| Campo      | Tipo             | Notas                                                                   |
| ---------- | ---------------- | ----------------------------------------------------------------------- |
| `text`     | string           | Até 4096 caracteres. A formatação do WhatsApp e os emojis são mantidos. |
| `reply_to` | string, opcional | Id da mensagem a citar.                                                 |

## Saída

`{ "message_id": string, "delivery": "sent" | "queued" }`. `queued` quer dizer que a [janela de 24 horas](/pt-br/concepts/24-hour-window) está fechada.
