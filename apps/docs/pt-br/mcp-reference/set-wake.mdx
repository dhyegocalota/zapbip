title: 'set_wake'
description: 'Diz ao zapbip como alcançar este agente quando ele não está ouvindo.'
---

Salva como esta conexão é acordada quando você escreve e nenhuma chamada está esperando. Veja o [guia de despertar por webhook](/pt-br/guides/webhook-wake) e a [escada de despertar](/pt-br/concepts/wake-ladder).

## Entrada

| Campo   | Tipo             | Notas                                                                                                                                                                                     |
| ------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mode`  | string           | `webhook` salva um webhook; `local` acorda pelo [conector](/pt-br/developers/local-connector); `none` limpa o despertar. `scheduled` e `standby` respondem "wake mode not available yet". |
| `url`   | string, opcional | Obrigatório para `webhook`. `https`, sem usuário e senha, sem fragmento, porta 443 ou ausente, até 512 caracteres. O host escolhe o provedor.                                             |
| `token` | string, opcional | Obrigatório para `webhook`. Imprimível, sem espaços, de 16 a 512 caracteres. Em um webhook genérico é a chave de assinatura, com pelo menos 32 caracteres.                                |

## Provedores

O provedor é escolhido pelo host da URL, nunca por um campo.

| Provedor         | Host                          | Caminho                                      | Autenticação                                                        |
| ---------------- | ----------------------------- | -------------------------------------------- | ------------------------------------------------------------------- |
| `grok_routine`   | `api2.cursor.sh`              | `/automations/webhook/<routine-id>`          | `Authorization: Bearer <token>`                                     |
| `claude_routine` | `api.anthropic.com`           | `/v1/claude_code/routines/<trigger-id>/fire` | `Authorization: Bearer <token>`                                     |
| `generic`        | qualquer host `https` público | qualquer                                     | `X-Zapbip-Timestamp` e `X-Zapbip-Signature`, nenhum segredo enviado |

## Saída

`{ "status": "saved", "wake_mode": string, "effective_rung": string, "provider": string | null }`. `provider` vem preenchido só para `webhook`. `effective_rung` é `inbox` para `local` enquanto nenhum conector está conectado, porque a mensagem então espera na caixa de entrada. A URL, o token e o host nunca são devolvidos.

## Erros

Um erro da ferramenta nomeia o campo inválido (`url`, `token` ou `mode`) e nunca repete o valor. Nada é salvo e o despertar anterior continua. O zapbip não chama o provedor ao salvar: um token errado aparece no primeiro despertar, como um aviso para você no WhatsApp.
