## Provedores

O provedor é escolhido pelo host da URL, nunca por um campo.

| Provedor         | Host                          | Caminho                                      | Autenticação                                                        |
| ---------------- | ----------------------------- | -------------------------------------------- | ------------------------------------------------------------------- |
| `grok_routine`   | `api2.cursor.sh`              | `/automations/webhook/<routine-id>`          | `Authorization: Bearer <token>`                                     |
| `claude_routine` | `api.anthropic.com`           | `/v1/claude_code/routines/<trigger-id>/fire` | `Authorization: Bearer <token>`                                     |
| `generic`        | qualquer host `https` público | qualquer                                     | `X-Zapbip-Timestamp` e `X-Zapbip-Signature`, nenhum segredo enviado |

## Erros

Um erro da ferramenta nomeia o campo inválido (`url`, `token` ou `mode`) e nunca repete o valor. Nada é guardado e o acordar anterior continua. O zapbip não chama o provedor ao salvar: um token errado aparece no primeiro acordar, como um aviso ao dono.
