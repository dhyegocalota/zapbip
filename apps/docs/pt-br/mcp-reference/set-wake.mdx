---
title: 'set_wake'
description: 'Diz ao zapbip como alcançar este agente quando ele não está ouvindo.'
---

Salva como esta conexão é acordada quando você escreve e nenhuma chamada está esperando. Veja a [escada de despertar](/pt-br/concepts/wake-ladder) e o [guia de despertar por webhook](/pt-br/developers/webhook-wake).

## Entrada

| Campo              | Tipo              | Notas                                                                                                                                                                                                                                      |
| ------------------ | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `mode`             | string            | `local` acorda pelo [conector](/pt-br/developers/local-connector); `webhook` salva um webhook; `scheduled` faz o agente olhar a caixa de entrada num intervalo; `standby` entrega suas mensagens a outro agente; `none` limpa o despertar. |
| `url`              | string, opcional  | Obrigatório para `webhook`. `https`, sem usuário e senha, sem fragmento, porta 443 ou ausente, até 512 caracteres. O host escolhe o provedor.                                                                                              |
| `token`            | string, opcional  | Obrigatório para `webhook`. Imprimível, sem espaços, de 16 a 512 caracteres. Em um webhook genérico é a chave de assinatura, com pelo menos 32 caracteres.                                                                                 |
| `interval_minutes` | inteiro, opcional | Obrigatório para `scheduled`. De 1 a 1440 minutos. O ChatGPT e o claude.ai rodam tarefas agendadas a cada 60 minutos no mínimo.                                                                                                            |
| `standby_agent`    | string, opcional  | Obrigatório para `standby`. O nome de outra conexão da mesma conta que não seja ela mesma uma reserva.                                                                                                                                     |

Campos de outro modo devem estar ausentes.

## Agendada

Um agente que não pode ser iniciado de fora roda uma tarefa num intervalo que chama [check_inbox](/pt-br/mcp-reference/check-inbox). Assim ele ouve sem limite de tempo e responde cada mensagem com `send_message`.

```json
{ "mode": "scheduled", "interval_minutes": 60 }
```

Quando você escreve, o zapbip diz quando esperar a resposta. Se nenhuma olhada acontece por o dobro do intervalo, você recebe um aviso e suas mensagens esperam na caixa de entrada até a próxima olhada.

## Local

Peça ao seu agente para chamar esta ferramenta com `{ "mode": "local" }` enquanto o [conector](/pt-br/developers/local-connector) roda no seu computador.

## Em espera

Um agente que não pode ser despertado indica outro agente da mesma conta para responder no lugar dele. O zapbip copia sua mensagem para a reserva e a desperta; a reserva responde como ela mesma.

```json
{ "mode": "standby", "standby_agent": "grok-bot" }
```

Uma reserva nunca repassa para outra reserva: é um salto só. Se a reserva não existe, foi removida ou está ela mesma em modo reserva, nada é copiado e sua mensagem espera com o primeiro agente.

## Provedores

O provedor é escolhido pelo host da URL, nunca por um campo.

| Provedor         | Host                          | Caminho                                      | Autenticação                                                        |
| ---------------- | ----------------------------- | -------------------------------------------- | ------------------------------------------------------------------- |
| `grok_routine`   | `api2.cursor.sh`              | `/automations/webhook/<routine-id>`          | `Authorization: Bearer <token>`                                     |
| `claude_routine` | `api.anthropic.com`           | `/v1/claude_code/routines/<trigger-id>/fire` | `Authorization: Bearer <token>`                                     |
| `generic`        | qualquer host `https` público | qualquer                                     | `X-Zapbip-Timestamp` e `X-Zapbip-Signature`, nenhum segredo enviado |

## Saída

`{ "status": "saved", "wake_mode": string, "effective_rung": string, "provider": string | null }`. `provider` vem preenchido só para `webhook`. `effective_rung` é `inbox` quando a reserva não pode ser usada, e para `local` enquanto nenhum conector está conectado, porque a mensagem então espera na caixa de entrada. A URL, o token e o host nunca são devolvidos.

## Erros

Um erro da ferramenta nomeia o campo inválido (`url`, `token`, `interval_minutes`, `standby_agent` ou `mode`) e o limite dele, e nunca repete o valor. Nada é salvo e o despertar anterior continua. O zapbip não chama o provedor ao salvar: um token errado aparece no primeiro despertar, como um aviso para você no WhatsApp.
