Confere a caixa de entrada sem esperar.

## Entrada

Nenhum campo.

## Saída

`{ "status": "empty" }` na hora, ou `{ "status": "new", "messages": [...] }`; as mensagens devolvidas passam a lidas. Pensado para tarefas agendadas, então responde barato.
