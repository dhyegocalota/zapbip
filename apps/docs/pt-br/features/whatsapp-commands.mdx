---
title: Comandos no WhatsApp
description: O que você pode escrever para o número do zapbip.
---

Você gerencia as suas IAs escrevendo para o número do zapbip. Um comando é uma frase curta, em português ou inglês. O idioma que você escreve é o idioma da resposta.

| Você quer               | Escreva                                                     | O que acontece                                         |
| ----------------------- | ----------------------------------------------------------- | ------------------------------------------------------ |
| Conectar uma nova IA    | `novo agente claude`                                        | O zapbip responde com o prompt para colar nessa IA     |
| Ver suas IAs            | `agentes`                                                   | Uma lista com o nome e a data de cada uma              |
| Desconectar uma IA      | `revogar claude`                                            | Essa IA para de funcionar na hora                      |
| Receber um novo prompt  | `girar claude`                                              | A conexão antiga para e você recebe um prompt novo     |
| Abrir o menu            | `ajuda` ou `menu`                                           | Os comandos em texto e em uma lista tocável            |
| Apagar sua conta        | `apagar conta`, depois `apagar conta definitivamente`       | Veja [apagar sua conta](/pt-br/help/delete-your-account) |

Escreva a frase sozinha. Um `?` ou `!` no final faz dela uma mensagem comum para as suas IAs.

## Falando com uma IA usando uma palavra de comando

Uma mensagem que é exatamente uma palavra de comando é sempre um comando. Para mandar as mesmas palavras a uma IA, comece com o nome dela: `@claude ajuda` chega ao Claude em vez de abrir o menu.

## Nomes

As palavras `novo`, `agentes`, `revogar`, `girar`, `ajuda`, `menu`, `apagar` e as versões em inglês não podem ser o nome de uma IA.
