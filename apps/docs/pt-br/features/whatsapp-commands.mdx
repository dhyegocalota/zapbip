Você gerencia as suas IAs escrevendo para o número do zapbip. Um comando é uma frase curta, em português ou inglês. O idioma que você escreve é o idioma da resposta. Cada linha mostra as duas versões.

| Você quer              | Escreva em português                                  | Ou em inglês                                        | O que acontece                                                                         |
| ---------------------- | ----------------------------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Conectar uma nova IA   | `novo agente claude`                                  | `new agent claude`                                  | O zapbip responde com o prompt para colar nessa IA                                     |
| Ver suas IAs           | `agentes`                                             | `agents`                                            | Uma lista com o nome e a data de cada uma                                              |
| Desconectar uma IA     | `revogar claude`                                      | `revoke claude`                                     | Essa IA para de funcionar na hora                                                      |
| Receber um novo prompt | `renovar claude`                                      | `rotate claude`                                     | A conexão antiga para e você recebe um prompt novo                                     |
| Entrar no app web      | `entrar`                                              | `login`                                             | Um link que funciona uma vez por 10 minutos, veja [o app web](/pt-br/features/web-app) |
| Abrir o menu           | `ajuda` ou `menu`                                     | `help` or `menu`                                    | Os comandos em texto e em uma lista tocável                                            |
| Apagar sua conta       | `apagar conta`, depois `apagar conta definitivamente` | `delete account`, then `delete account permanently` | Veja [apagar sua conta](/pt-br/help/delete-your-account)                               |

Escreva a frase sozinha. Um `?` ou `!` no final faz dela uma mensagem comum para as suas IAs.

## Exemplo

## Falando com uma IA usando uma palavra de comando

Uma mensagem que é exatamente uma palavra de comando é sempre um comando. Para mandar as mesmas palavras a uma IA, comece com o nome dela: `@claude ajuda` chega ao Claude em vez de abrir o menu.

## Nomes

As palavras `novo`, `agentes`, `revogar`, `renovar`, `ajuda`, `menu`, `entrar`, `apagar` e as versões em inglês são reservadas: não podem ser o nome de uma IA.

## Mensagens encaminhadas

Uma mensagem encaminhada nunca é um comando, mesmo que o texto seja uma palavra de comando. Ela vai para as suas IAs como qualquer outra mensagem.
