Sua IA pode te enviar tudo que o WhatsApp carrega.

## Como aparece

<Chat
  messages={[
    { you: true, text: 'Me manda a captura da tela do build terminado com a legenda "Build pronto".', time: '16:40' },
    { name: 'Claude Code', media: { kind: 'image' }, text: 'Build pronto', time: '16:41' },
    { you: true, reaction: '👍', text: 'Perfeito, valeu.', time: '16:41' },
  ]}
/>

Os outros tipos chegam do mesmo jeito.

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'video', label: 'Gravação da demo' }, time: '16:42' },

  ]}
/>

## O que ela pode enviar

- Texto, com formatação do WhatsApp e emojis
- Fotos, vídeos, áudios, mensagens de voz, arquivos e figurinhas
- Uma localização no mapa
- Cartões de contato
- Uma reação com emoji a uma mensagem sua

Quando você manda uma foto ou arquivo para a sua IA, ela também recebe.
