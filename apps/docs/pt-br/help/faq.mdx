---
title: Perguntas frequentes
description: Respostas curtas.
---

<AccordionGroup>
  <Accordion title="Já dá para usar hoje no meu celular?">
    Dá. Mande uma mensagem para o número do zapbip no WhatsApp e veja [Como começar](/pt-br/get-started/how-to-start).
  </Accordion>
  <Accordion title="Posso usar meu próprio número de WhatsApp?">
    Ainda não. Toda IA fala com você pelo número do zapbip, e você usa o seu WhatsApp de sempre, então não há nada para registrar.
  </Accordion>
  <Accordion title="Quais IAs funcionam?">Veja [IAs compatíveis](/pt-br/agents/supported-agents).</Accordion>
  <Accordion title="Ele fala com outras pessoas?">Não. O zapbip fala só com você, pela API oficial do WhatsApp.</Accordion>
  <Accordion title="Várias IAs podem dividir um número?">
    Podem. Veja [Várias IAs em um número](/pt-br/features/many-agents-on-one-number).
  </Accordion>
  <Accordion title="Por que minha mensagem não chegou na hora?">
    A janela de 24 horas fechou. Veja [A janela de 24 horas](/pt-br/concepts/24-hour-window).
  </Accordion>
  <Accordion title="Preciso ser desenvolvedor?">Não. O zapbip é para quem usa IA. As páginas para desenvolvedores são opcionais.</Accordion>
  <Accordion title="E se a minha conta estiver na lista de espera?">
    A conta fica retida até a equipe do zapbip ativá-la. Você espera; não há mais nada a fazer. Quando o acesso abrir, envie `ajuda` para
    ver os comandos.
  </Accordion>
  <Accordion title="Como paro uma IA?">
    Escreva `revogar` e o nome dela. Veja [revogar e renovar](/pt-br/help/revoke-and-rotate-keys).
  </Accordion>
  <Accordion title="Como apago tudo?">
    Escreva `apagar conta` no WhatsApp. Veja [apagar sua conta](/pt-br/help/delete-your-account).
  </Accordion>
  <Accordion title="O que o zapbip guarda?">Veja [privacidade e segurança](/pt-br/help/privacy-and-security).</Accordion>
  <Accordion title="Quais mensagens do WhatsApp funcionam?">
    Texto, fotos, vídeos, áudios, arquivos, figurinhas, localizações, cartões de contato, reações e toques em botões ou listas. Veja
    [Mensagens suportadas](/pt-br/features/supported-messages).
  </Accordion>
  <Accordion title="Posso usar uma ferramenta não oficial do WhatsApp?">
    Não. O zapbip usa somente a API oficial WhatsApp Cloud, da Meta. Veja [Mensagens suportadas](/pt-br/features/supported-messages).
  </Accordion>
</AccordionGroup>
