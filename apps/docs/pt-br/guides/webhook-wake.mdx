---
title: 'Acordar por webhook'
description: 'Acorde uma IA que não está ouvindo com um webhook.'
---

Quando o dono escreve e nenhuma chamada está esperando, o zapbip pode chamar um webhook que inicia a IA. A IA então lê a mensagem com [check_inbox](/pt-br/mcp-reference/check-inbox) ou [get_messages](/pt-br/mcp-reference/get-messages) e responde. Configure com [set_wake](/pt-br/mcp-reference/set-wake).

A chamada não leva o texto do dono: o corpo é sempre `{"event":"inbox_has_messages"}`. Mensagens que chegam em sequência dividem um único acordar, enviado alguns segundos depois da primeira.

## Rotina do Grok Bot

Crie uma rotina com gatilho de webhook e salve:

```json
{ "mode": "webhook", "url": "https://api2.cursor.sh/automations/webhook/<routine-id>", "token": "<token>" }
```

O zapbip envia `Authorization: Bearer <token>`.

## Tarefa agendada do claude.ai

Crie uma tarefa agendada com gatilho de API e salve:

```json
{ "mode": "webhook", "url": "https://api.anthropic.com/v1/claude_code/routines/<trigger-id>/fire", "token": "<token>" }
```

O zapbip envia `Authorization: Bearer <token>` e os cabeçalhos beta das rotinas.

## Seu próprio serviço

Qualquer host `https` público serve. O token é a sua chave de assinatura, com pelo menos 32 caracteres, e nunca é enviado. Cada chamada leva `X-Zapbip-Timestamp` (segundos Unix) e `X-Zapbip-Signature`, `sha256=` seguido do HMAC-SHA256 em hexadecimal de `<timestamp>.<body>`. Rejeite um timestamp com mais de 300 segundos.

```js
import { createHmac, timingSafeEqual } from 'node:crypto';

const TOLERANCE_SECONDS = 300;

export function isValidWake({ timestamp, signature, body, token }) {
  const ageSeconds = Math.abs(Date.now() / 1000 - Number(timestamp));
  if (!(ageSeconds <= TOLERANCE_SECONDS)) return false;
  const expected = `sha256=${createHmac('sha256', token).update(`${timestamp}.${body}`).digest('hex')}`;
  const received = Buffer.from(signature);
  const wanted = Buffer.from(expected);
  return received.length === wanted.length && timingSafeEqual(received, wanted);
}
```

## Quando um acordar falha

- `408`, `425`, `429`, `5xx`, um tempo esgotado ou um erro de rede é repetido em até 5 tentativas, esperando 5, 10, 20 e 40 segundos e respeitando `Retry-After` em `429` e `503`, até 60 segundos.
- Redirecionamentos e outras respostas `4xx` são recusados na hora e não são repetidos.
- Quando um acordar é recusado ou desiste, o dono recebe um aviso de que a mensagem espera na caixa de entrada, e a conexão fica `failing`. Chame [set_wake](/pt-br/mcp-reference/set-wake) de novo para corrigir o destino; o próximo acordar entregue volta a conexão para `active`.
- Se a IA ler as mensagens antes de o acordar disparar, nenhuma chamada é enviada.
