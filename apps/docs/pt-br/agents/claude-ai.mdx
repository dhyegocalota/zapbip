## O que funciona

| Você quer                        | claude.ai                                                                 |
| -------------------------------- | ------------------------------------------------------------------------- |
| Receber mensagens dele           | Texto, fotos, vídeos, áudios, documentos, localizações, contatos, reações |
| Responder com um toque           | Botões e listas; ele espera o seu toque                                   |
| Escrever primeiro pelo WhatsApp  | Sim, uma tarefa o acorda em cerca de 16 segundos                          |
| Deixar uma pergunta aberta horas | Sim, não há limite de tempo                                               |

## Como ela escuta

Tipo de despertar: **Webhook**. Quando você escreve no WhatsApp, o zapbip dispara o link de gatilho de uma tarefa do claude.ai, e a tarefa roda na nuvem com os seus conectores. Ele responde cerca de 16 segundos depois que você escreve, sem pedir aprovação.

- As tarefas do claude.ai rodam num agendamento no máximo uma vez por hora. Por isso você também cria uma tarefa a cada hora que confere as suas mensagens: ela é só uma rede de segurança, para nada esperar mais de uma hora se um despertar falhar.

Quando a sua IA faz uma pergunta, o zapbip a guarda e responde "pendente" no máximo a cada 50 segundos. O claude.ai então chama de novo, e continua chamando de novo até você responder, sem limite de tempo.

## Configure do zero

1. **Mande uma mensagem para o número do zapbip no WhatsApp.** Pode ser qualquer texto, por exemplo `oi`.

   <OfficialNumber />

2. **Peça um novo agente.** Agente é uma IA que você conecta.

   <Chat
     messages={[
       { you: true, text: 'novo agente claude-ai', time: '08:00' },
       {
         name: 'zapbip',
         text: 'Agente claude-ai criado. Cole no seu agente: Conecte-se ao meu WhatsApp pelo zapbip: leia https://zapbip.com/i/zb_inst_<code> e siga as instruções. Este link vale 30 minutos e funciona uma vez. Não o compartilhe. Se o link expirar ou for usado, envie "girar claude-ai".',
         time: '08:00',
       },
     ]}
   />

3. **Cole a linha no claude.ai.**

   <InstallPrompt />

   O claude.ai lê as instruções e as segue em ordem. O link é secreto, então não o deixe em conversas que você compartilha.

4. **Adicione o conector.** O claude.ai pede que você cole um link como conector personalizado nas Configurações. Esta parte é sua, porque o claude.ai só deixa você adicioná-lo.

5. **Crie a tarefa de despertar.** O claude.ai pede que você crie uma tarefa com link de gatilho nas rotinas dele e cole no chat a URL do gatilho e o token. Esta colagem também é sua, porque o claude.ai mostra o token só para você.

6. **Crie a rede de segurança.** O claude.ai pede que você crie uma tarefa a cada hora que confere as suas mensagens.

## Confira se funciona

O claude.ai envia `✅ instalado` ao seu WhatsApp assim que fica conectado.
