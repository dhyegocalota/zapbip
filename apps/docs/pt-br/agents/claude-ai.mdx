## O que funciona

- Sua IA envia texto, fotos, vídeos, áudios, documentos, localizações, contatos e reações no WhatsApp.
- Ela pergunta com botões ou listas e espera o seu toque.
- Escreva no WhatsApp e uma tarefa agendada acorda o claude.ai em cerca de 16 segundos, sem pedir aprovação.
- O claude.ai espera cerca de 4 minutos por uma resposta e tenta de novo sozinho, então não há limite no total.

## Configurar do zero

<Steps>
  <Step title="Mande mensagem para o número oficial do zapbip">
    Abra o WhatsApp e mande `oi` para o número oficial do zapbip, depois `novo agente claude-ai`. [Como começar](/pt-br/get-started/how-to-start) mostra cada mensagem.
  </Step>
  <Step title="Cole o prompt em claude.ai">
    O zapbip responde com uma linha feita para você. Cole em claude.ai:

    ```text
    Conecte-se ao meu WhatsApp com o zapbip: leia https://zapbip.com/i/K7P2QX e siga as instruções.
    ```

    claude.ai lê a página e segue os passos abaixo, em ordem. Antes de mudar um arquivo ou uma configuração, diz qual é e espera o seu sim. O link dessa página é secreto, então não o deixe em conversas que você compartilha.

  </Step>
  <Step title="Colar o conector">
    O claude.ai pede para você colar `<connectionLink>` como conector personalizado nas Configurações. Esse passo é seu, porque o claude.ai só permite que você o faça.
  </Step>
  <Step title="Criar a tarefa de despertar">
    Ele pede para você criar uma tarefa com gatilho de API em claude.ai/code/routines e colar no chat a URL de disparo e o token. A segunda colagem também é sua, porque o claude.ai mostra o token só para você.
  </Step>
  <Step title="Avisar o zapbip como acordá-lo">
    Se você parar antes de a tarefa existir, ele chama `set_wake({mode: "none"})` e avisa que o chat só vê mensagens novas quando você o abre. Caso contrário, chama `set_wake({mode: "webhook", url, token})`.
  </Step>
  <Step title="Criar a rede de segurança por hora">
    Ele pede para você criar uma tarefa por hora que chama `check_inbox`, para nada esperar mais de uma hora se um despertar falhar.
  </Step>
  <Step title="Testar">
    No chat ele chama `send_message` com ✅ instalado.
  </Step>
</Steps>

## Como a IA escuta

- Quando você escreve no WhatsApp, o zapbip dispara o gatilho de API e o claude.ai roda a tarefa na nuvem com os seus conectores.
- As tarefas do claude.ai agendadas rodam no máximo uma vez por hora, por isso a tarefa horária de `check_inbox` é só uma rede de segurança.

Não há limite de tempo. Enquanto uma pergunta está aberta, sua IA pergunta de novo até você responder, pelo tempo que for preciso.
