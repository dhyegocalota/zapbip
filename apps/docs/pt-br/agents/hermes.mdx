## O que funciona

| Você pode                                       | Hermes |
| ----------------------------------------------- | ------ |
| Receber texto, fotos, vídeo, áudio e documentos | Sim    |
| Receber localizações, contatos e reações        | Sim    |
| Receber perguntas com botões ou lista e esperar | Sim    |
| Começar a conversa quando você escreve primeiro | Sim    |

## Como ela escuta

Nível: Local. Um pequeno plugin do zapbip mantém uma conexão aberta com o zapbip dentro do Hermes, e cada mensagem do WhatsApp chega à sessão assim que você envia. Se a rede cair, o plugin reconecta sozinho e recebe todas as mensagens que você enviou nesse meio tempo.

Se o plugin não puder ser instalado, o Hermes executa uma tarefa agendada a cada minuto que confere a caixa de entrada. A sua mensagem espera então até um minuto.

Enquanto uma pergunta está aberta, o Hermes espera até 50 segundos por vez. Se você ainda não respondeu, a espera termina como pendente e o Hermes chama de novo, quantas vezes for preciso, sem limite de tempo.

Use um ouvinte por vez: o plugin ou `npx zapbip@0.1.0 listen`, nunca os dois. Um segundo ouvinte substitui o primeiro.

## Configure do zero

1. **Mande uma mensagem para o número do zapbip no WhatsApp.** Envie `novo agente hermes`. [Como começar](/pt-br/get-started/how-to-start) mostra cada mensagem.

   <Chat
     messages={[
       { you: true, text: 'novo agente hermes', time: '09:00' },
       { name: 'zapbip', text: 'Agente hermes criado. Cole no seu agente.', time: '09:00' },
     ]}
   />

2. **Cole a linha no Hermes.** O zapbip responde com uma linha feita para você:

   <InstallPrompt />

3. **Diga sim a cada mudança.** O Hermes diz qual configuração vai mudar e espera o seu sim. Mantenha o link fora de conversas que você compartilha.

4. **Deixe que ele instale o plugin.** O Hermes executa `pip install zapbip-platform==0.1.0` para poder iniciar a plataforma do zapbip. Depois, só você pode falar com ele, e o seu link fica no ambiente dele.

   ```bash
   pip install zapbip-platform==0.1.0
   ```

5. **Proteja o arquivo que guarda o seu link.** O link funciona como uma senha. Se ele ficar em um arquivo, só o seu usuário pode lê-lo:

   ```bash
   chmod 600 <arquivo>
   ```

6. **Ou use a alternativa agendada.** Só se o plugin não puder ser instalado, e nunca junto com ele, o Hermes cria uma tarefa a cada minuto que chama `check_inbox`. Uma tarefa que consulta gasta chamadas do modelo, e o Hermes avisa você.

## Confira se funciona

Peça ao Hermes para enviar `✅ instalado` no WhatsApp. Quando chegar, a conexão funciona.

<Chat messages={[{ name: 'Hermes', text: '✅ instalado', time: '09:03' }]} />

Depois escreva algo no WhatsApp. O Hermes responde assim que ouve você.
