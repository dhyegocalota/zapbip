| Receber mensagens dele           | Texto, fotos, vídeos, áudios, documentos, localizações, contatos, reações |

## Como ela escuta

Tipo de despertar: **Local**. Um conector no seu computador acorda o Claude Code, que responde cerca de 7 segundos depois que você escreve.

- Inicie o Claude Code com `claude --dangerously-load-development-channels server:zapbip-channel`. O canal do zapbip passa a empurrar cada mensagem do WhatsApp para a sessão aberta assim que ela chega.
- Se a sessão estiver fechada, o conector a retoma em cerca de 7 segundos. Ficar parado não gasta tokens; cada mensagem custa um turno.
- Mantenha o ouvinte rodando. Para ele continuar vivo depois de fechar o terminal, siga [Rode o conector como serviço](/pt-br/developers/background-running).

Quando a sua IA faz uma pergunta, o zapbip a guarda e responde "pendente" no máximo a cada 50 segundos. Sua IA então chama de novo, e continua chamando de novo até você responder, sem limite de tempo.

Use um escutador só, nunca dois juntos. Se o canal não estiver ligado, o Claude Code mantém `npx zapbip@0.1.0 listen` rodando e o acompanha com a ferramenta `Monitor`. Cada acompanhamento dura no máximo 30 minutos, então o Claude Code rearma a cada aviso de tempo esgotado.

## Configure do zero

1. **Mande uma mensagem para o número do zapbip no WhatsApp.** Pode ser qualquer texto, por exemplo `oi`.

   <OfficialNumber />

2. **Peça um novo agente.** Agente é uma IA que você conecta.

   <Chat
     messages={[
       { you: true, text: 'novo agente claude-code', time: '15:00' },
       {
         name: 'zapbip',
         text: 'Agente claude-code criado. Cole no seu agente: Conecte-se ao meu WhatsApp pelo zapbip: leia https://mcp.zapbip.com/i/zb_inst_<code> e siga as instruções. Este link vale 30 minutos e funciona uma vez. Não o compartilhe. Se o link expirar ou for usado, envie "girar claude-code".',
         time: '15:00',
       },
     ]}
   />

3. **Cole a linha no Claude Code.**

   <InstallPrompt />

   O Claude Code lê as instruções e as segue em ordem. Antes de mudar um arquivo ou uma configuração, ele diz qual é e espera o seu sim. O link é secreto, então não o deixe em conversas que você compartilha.

4. **Diga sim.** O Claude Code faz o resto, nesta ordem.

5. **Adicionar o zapbip ao Claude Code.** Se já existir um `zapbip` ou `zapbip-channel` antigo, o Claude Code o remove com `claude mcp remove --scope user zapbip` ou `claude mcp remove --scope user zapbip-channel`. Depois roda `claude mcp add --transport http --scope user zapbip <connectionLink>` para as ferramentas e `claude mcp add --scope user zapbip-channel -e ZAPBIP_CONNECTION_URL=<connectionLink> -- npx zapbip@0.1.0 channel` para o canal ao vivo.

6. **Salvar a skill do zapbip.** Depois do seu sim, ele grava `~/.claude/skills/zapbip/SKILL.md`, para que toda sessão saiba usar o WhatsApp, inclusive quando chamar `check_inbox`.

7. **Escolher um só escutador.** Uma conexão tem um escutador só e um segundo substitui o primeiro, então ele usa exatamente um destes, nunca dois juntos. Para uma sessão parada, roda `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 connect --client claude-code` em segundo plano. O conector acorda a sessão quando você escreve com o Claude Code parado e retoma uma sessão fechada com `claude -p --resume`.

8. **Só se os canais não estiverem disponíveis.** Ele roda `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 listen` em segundo plano e o acompanha com a ferramenta `Monitor`, rearmando a cada aviso de tempo esgotado.

9. **Testar.** Em um processo novo ele roda `claude -p "Call send_message with the text '✅ instalado'" --allowedTools=mcp__zapbip__send_message`. Um `send_message` com ✅ instalado chega ao seu WhatsApp. Se o comando falhar, ele para e mostra as últimas 20 linhas. Depois reinicie o Claude Code para usar as ferramentas do zapbip.

## Confira se funciona

Peça ao Claude Code para enviar `✅ instalado` ao seu WhatsApp. Deve chegar em poucos segundos.
