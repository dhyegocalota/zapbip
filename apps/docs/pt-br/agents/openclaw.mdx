O OpenClaw fica ouvindo seu WhatsApp por um pequeno canal do zapbip. Você escreve primeiro ou responde uma pergunta depois, e a mensagem chega na sessão do OpenClaw.

<Chat
  contact="OpenClaw"
  messages={[
    { you: true, text: 'Me lembre de enviar a fatura amanhã às 9.', time: '18:02' },
    { name: 'OpenClaw', text: 'Feito. Vou te lembrar amanhã às 9:00.', time: '18:02' },
  ]}
/>

## O que você precisa

- O OpenClaw 2026.10.10 ou mais novo, com o gateway rodando.
- Seu link de conexão, o mesmo link `https://.../c/<secret>/mcp` que sua IA usa para falar com o zapbip. Trate-o como uma senha.

## Instale o canal

O plugin lê as suas mensagens para este agente no zapbip e publica as respostas do agente de volta. Ele não faz mais nada. Sua IA diz isso a você e espera o seu sim antes de instalar.

```bash
openclaw plugins install @zapbip/openclaw-plugin@0.1.0 --force --accept-capabilities
```

Depois defina o link no canal `zapbip` e ative o plugin no `openclaw.json`:

```json
{
  "channels": { "zapbip": { "connectionLink": "https://<host>/c/<secret>/mcp" } },
  "plugins": { "entries": { "zapbip": { "enabled": true } } }
}
```

O arquivo que guarda seu link de conexão funciona como uma senha. Dê a ele a permissão `600`, para que só o seu usuário consiga ler, e nunca o compartilhe nem o envie para o Git:

```bash
chmod 600 <arquivo>
```

Reinicie o gateway.

Depois da instalação, sua IA chama `set_wake({mode: "local"})`. Se o plugin não puder ser instalado, ela consulta em vez disso: cria uma tarefa a cada minuto que chama `check_inbox` e chama `set_wake({mode: "scheduled", interval_minutes: 1})`. Ela termina com `send_message`.

## Como ele escuta

O canal mantém uma conexão aberta com o zapbip, sem limite de tempo. Se a rede cair, ele reconecta sozinho, esperando um pouco mais a cada tentativa que falha (1 segundo no começo, 30 segundos no máximo). As mensagens que você enviar nesse meio tempo esperam na sua caixa de entrada do zapbip, e o canal pega todas as que ficaram sem resposta assim que volta.

Rode apenas um listener por agente: o plugin ou `npx zapbip@0.1.0 listen`, nunca os dois. Um segundo listener substitui o primeiro.

## Como o OpenClaw responde

As respostas do OpenClaw às suas mensagens voltam pelo próprio canal, sem configuração extra. Se o envio de uma resposta falhar, o canal escreve `plugin_reply_failed` no log do gateway e não tenta de novo, então essa resposta pode se perder.

Adicione o zapbip como servidor MCP para o OpenClaw também puxar conversa com você, fazer uma pergunta com botões e esperar a resposta, e usar a consulta periódica abaixo:

```json
{
  "mcp": {
    "servers": {
      "zapbip": { "url": "https://<host>/c/<secret>/mcp", "transport": "streamable-http" }
    }
  }
}
```

Depois peça ao OpenClaw no WhatsApp para enviar `✅ instalado`. Se essa mensagem chegar, está funcionando.

<Chat
  contact="zapbip"
  messages={[
    { you: true, text: 'Envie ✅ instalado quando estiver instalado.', time: '18:10' },
    { name: 'OpenClaw', text: '✅ instalado', time: '18:10' },
  ]}
/>

## Mensagens encaminhadas

Uma mensagem que você encaminhou de outra pessoa chega ao OpenClaw com um aviso de que não foi você quem escreveu, e ela não consegue executar comandos.

## Se o canal não puder ser instalado

O OpenClaw pode consultar a caixa de entrada. Adicione o servidor MCP acima e crie uma tarefa a cada 1 minuto que chama `check_inbox`. Suas mensagens esperam até um minuto, e a resposta volta do mesmo jeito.

## Quando algo não funciona

| O que você vê                             | O que significa                                                                                                           |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Nenhuma resposta à sua mensagem           | O gateway não está rodando, `channels.zapbip` não tem `connectionLink`, ou `plugins.entries.zapbip.enabled` não é `true`. |
| O canal para sozinho                      | Outro canal ou conector começou para a mesma conexão e o substituiu.                                                      |
| O OpenClaw ouve, mas a resposta não chega | O log do gateway mostra `plugin_reply_failed`: o envio da resposta falhou e não é repetido. Escreva de novo.              |
| O OpenClaw não puxa conversa nem pergunta | O servidor MCP `zapbip` não está em `mcp.servers`.                                                                        |
| O canal para com erro                     | O link é desconhecido ou a conexão foi revogada. Peça um novo.                                                            |
