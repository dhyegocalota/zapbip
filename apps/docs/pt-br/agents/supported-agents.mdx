| Sua IA              | Como ela escuta                                             | Você pode puxar a conversa |
| ------------------- | ----------------------------------------------------------- | -------------------------- |
| Claude Code         | Um canal na sua sessão aberta, ou o conector do zapbip      | Sim                        |
| Codex               | O conector do zapbip retoma a sua sessão                    | Sim                        |
| Cursor              | Um terminal em segundo plano rodando `zapbip listen`        | Sim                        |
| Gemini CLI          | Um terminal em segundo plano rodando `zapbip listen`        | Sim                        |
| Hermes              | O plugin de plataforma do zapbip, ou um job a cada minuto   | Sim                        |
| OpenClaw            | O plugin de canal do zapbip, ou um job a cada minuto        | Sim                        |
| Grok Bot            | Uma rotina com webhook                                      | Sim                        |
| Claude (app e site) | Uma tarefa agendada com gatilho de API                      | Sim                        |
| ChatGPT             | Uma tarefa agendada, verificada pelo menos uma vez por hora | Sim, dentro de uma hora    |
| Grok na web         | O seu Grok Bot fica de prontidão por ele                    | Sim, pelo seu Grok Bot     |

Você pode puxar a conversa com qualquer uma delas pelo WhatsApp, usando o número do zapbip.

## Puxar a conversa

Cada IA fica ouvindo, sem limite de tempo, do jeito que o app permite: um canal ou um ouvinte em segundo plano no Claude Code, um conector local no Codex, um webhook no Grok Bot, uma tarefa agendada no claude.ai e no ChatGPT, um standby para o Grok na web e um plugin para [Hermes](/pt-br/agents/hermes) e [OpenClaw](/pt-br/agents/openclaw). Escreva primeiro e a mensagem chega na IA; se ela não estiver ouvindo agora, a mensagem espera e o zapbip avisa.
