---
title: Many AIs on one number
description: How your reply finds the AI it is for.
---

All your AIs write from the same WhatsApp number. zapbip decides where your message goes, in this order:

| You do                                  | It goes to                        |
| --------------------------------------- | --------------------------------- |
| Tap a button or a list option           | The AI that asked                 |
| Reply to a message, or react to it      | The AI that sent that message     |
| Write `@grok check the news`            | Grok, without the `@grok `        |
| Answer while one AI has a question open | That AI                           |
| Write after only Claude spoke           | Claude, the last AI that wrote    |
| Write when nothing matches              | A list of recent AIs to pick from |

## Example

```text
Claude   Tests passed.
Grok     Can I rebase main?   [ Yes ] [ No ]

you      @claude thanks         -> Claude
you      (taps Yes)             -> Grok
you      ok                     -> a list: Claude, Grok
```

Names have up to 20 characters: lowercase letters, digits and hyphens.
