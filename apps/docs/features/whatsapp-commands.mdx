---
title: Commands on WhatsApp
description: What you can type to the zapbip number.
---

You manage your AIs by writing to the zapbip number. A command is a short phrase, in Portuguese or English. The language you write is the language of the answer.

| You want to             | Write                                                       | What happens                                           |
| ----------------------- | ----------------------------------------------------------- | ------------------------------------------------------ |
| Connect a new AI        | `new agent claude`                                          | zapbip answers with the prompt to paste into that AI   |
| See your AIs            | `agents`                                                    | A list with the name and the date of each one          |
| Disconnect an AI        | `revoke claude`                                             | That AI stops working at once                          |
| Get a new prompt        | `rotate claude`                                             | The old connection stops and you get a fresh prompt    |
| Open the menu           | `help` or `menu`                                            | The commands as text and as a tappable list            |
| Delete your account     | `delete account`, then `delete account permanently`         | See [delete your account](/help/delete-your-account)   |

Write the phrase alone. A trailing `?` or `!` makes it a normal message for your AIs.

## Talking to an AI with a command word

A message that is exactly a command word is always a command. To send the same words to an AI, start with its name: `@claude help` reaches Claude instead of opening the menu.

## Names

The words `new`, `agents`, `revoke`, `rotate`, `help`, `menu`, `delete` and their Portuguese versions cannot be the name of an AI.
