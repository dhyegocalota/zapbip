zapbip is open source under two licenses, one for each part of the code.

| Part                                        | License                                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| The server, the site and the libraries      | [GNU AGPL v3.0](https://github.com/dhyegocalota/zapbip/blob/main/LICENSE)                               |
| The local connector and the channel plugins | [MIT](https://github.com/dhyegocalota/zapbip/blob/main/apps/connector/LICENSE)                          |

The channel plugins for [OpenClaw](https://github.com/dhyegocalota/zapbip/blob/main/apps/openclaw-plugin/LICENSE) and [Hermes](https://github.com/dhyegocalota/zapbip/blob/main/apps/hermes-plugin/LICENSE) are MIT too, and each package carries its own `LICENSE` file.
