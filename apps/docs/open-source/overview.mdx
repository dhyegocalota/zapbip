## Contribute

- Read [CONTRIBUTING](https://github.com/dhyegocalota/zapbip/blob/main/.github/CONTRIBUTING.md) first. Open an issue before a larger change.
- Tests are mandatory, and every contribution comes under the [Contributor License Agreement](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md).
- Report vulnerabilities privately, as [SECURITY](https://github.com/dhyegocalota/zapbip/blob/main/.github/SECURITY.md) explains, never in a public issue.
- Everyone follows the [code of conduct](https://github.com/dhyegocalota/zapbip/blob/main/.github/CODE_OF_CONDUCT.md).
