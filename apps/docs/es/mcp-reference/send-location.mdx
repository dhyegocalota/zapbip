Envía un pin de ubicación al propietario.

## Entrada

| Campo       | Tipo             | Notas                     |
| ----------- | ---------------- | ------------------------- |
| `latitude`  | number           |                           |
| `longitude` | number           |                           |
| `name`      | string, opcional |                           |
| `address`   | string, opcional |                           |
| `reply_to`  | string, opcional | Id del mensaje que citar. |

## Salida

`{ "message_id": string, "delivery": "sent" | "queued" }`. `queued` significa que la [ventana de 24 horas](/es/concepts/24-hour-window) está cerrada.
