## Qué funciona

| Puedes                                           | Gemini CLI                          |
| ------------------------------------------------ | ----------------------------------- |
| Recibir texto, fotos, vídeo, audio y documentos  | Sí                                  |
| Recibir ubicaciones, contactos y reacciones      | Sí                                  |
| Que te pregunte con botones o una lista y espere | Sí                                  |
| Empezar una conversación cuando escribes primero | Sí, mientras la sesión esté abierta |

## Cómo escucha

Peldaño: Local. Gemini CLI ejecuta el listener de zapbip en un terminal en segundo plano y lo mantiene en marcha. Cuando escribes en WhatsApp, aparece allí una línea nueva y despierta la sesión. Mantén ese terminal abierto: Gemini CLI no tiene opción programada.

```bash
npx zapbip@0.1.0 listen
```

Mientras una pregunta está abierta, Gemini CLI espera hasta 50 segundos cada vez. Si no has respondido, la espera termina como pendiente y Gemini CLI vuelve a llamar otra vez, tantas veces como haga falta, sin límite de tiempo.

Ejecuta un solo listener a la vez. Un segundo listener reemplaza al primero.

## Configúralo desde cero

1. **Escribe al número de zapbip en WhatsApp.** Envía `nuevo agente gemini-cli`. [Cómo empezar](/es/get-started/how-to-start) muestra cada mensaje. Los comandos y las respuestas de zapbip están en español; también entiende los mismos comandos en inglés.

   <Chat
     messages={[
       { you: true, text: 'nuevo agente gemini-cli', time: '09:00' },
       { name: 'zapbip', text: 'Agent gemini-cli created. Paste this into your agent.', time: '09:00' },
     ]}
   />

2. **Pega la línea en Gemini CLI.** zapbip responde con una línea hecha para ti:

   <InstallPrompt />

3. **Di que sí a cada cambio.** Gemini CLI te dice qué ajuste cambia y espera tu sí. Mantén el enlace fuera de los chats que compartes.

4. **Añade zapbip a Gemini CLI.** Tras tu sí, ejecuta `gemini mcp add --transport http --scope user zapbip <connectionLink>`.

5. **Empieza a escuchar.** Ejecuta `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 listen` en un terminal en segundo plano y mantiene ese terminal en marcha, sin límite de tiempo. Cada vez que aparece una línea nueva allí, llama a `check_inbox` y responde.

6. **Pruébalo.** En un proceso nuevo ejecuta `gemini -p "Call send_message with the text '✅ listo'"`. Un `send_message` con ✅ listo llega a tu WhatsApp. Si el comando falla, se detiene y muestra las últimas 20 líneas. Después reinicia Gemini CLI.

## Comprueba que funciona

Pide a Gemini CLI que envíe `✅ listo` por WhatsApp. Cuando llegue, la conexión funciona.

<Chat messages={[{ name: 'Gemini CLI', text: '✅ listo', time: '09:03' }]} />

Si no llega, reinicia Gemini CLI y vuelve a pedírselo.
