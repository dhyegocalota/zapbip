## El mensaje de mi IA no llegó

Lo más probable es que la [ventana de 24 horas](/es/features/the-24-hour-window) esté cerrada. Escribe cualquier cosa al número de zapbip y los mensajes en espera llegan en orden. Los avisos de zapbip están en inglés, el idioma del producto hoy.

<Chat
  messages={[
    { notice: true, text: 'The agent claude-code has a message for you: Migration finished ✅', time: '07:12' },
    { you: true, text: 'ok', time: '07:30' },
    { name: 'Claude Code', text: 'Migración terminada ✅', time: '07:30' },
    { name: 'Grok', text: 'Encontré 3 fuentes.', time: '07:30' },
  ]}
/>

## Escribí y mi IA no respondió

Tu IA no estaba escuchando. Tu mensaje la espera, y zapbip te avisa de que la IA no está escuchando ahora mismo.

<Chat
  messages={[
    { you: true, text: '@claude ¿el build está en verde?', time: '14:20' },
    { notice: true, text: 'The agent claude is not listening right now. Your message waits in the inbox.', time: '14:20' },
  ]}
/>

Abre la IA y pídele que revise sus mensajes, y mira cómo sigue escuchando cada una en [IAs compatibles](/es/agents/supported-agents).

## Mi mensaje fue a la IA equivocada

Empiézalo con `@nombre`, por ejemplo `@grok mira las noticias`, o responde directamente al mensaje de la IA.

<Chat
  messages={[
    { name: 'Grok', text: 'Encontré 3 fuentes.', time: '11:05' },
    { you: true, text: '@grok mira las noticias', time: '11:06' },
    { you: true, quote: { name: 'Grok', text: 'Encontré 3 fuentes.' }, text: '¿Cuáles?', time: '11:07' },
  ]}
/>

Mira [Muchas IAs con un solo número](/es/features/many-agents-on-one-number).

## Envié un mensaje y no volvió nada

Puede que tu cuenta esté en la lista de espera. Se queda retenida hasta que el equipo de zapbip la active. Espera, y envía `help` cuando se abra el acceso.

## El enlace de mi prompt no funciona

El enlace funciona una vez, durante 30 minutos. Escribe `rotate` y el nombre de la IA, por ejemplo `rotate claude`, para obtener un prompt nuevo. Mira [revocar y renovar](/es/help/revoke-and-rotate-keys).

## zapbip rechazó el nombre de mi IA

Un nombre tiene de 1 a 20 letras minúsculas, números o guiones, empieza por una letra o un número y no puede empezar como un comando. Envía `new agent` con otro nombre.

## zapbip dice que llegué al límite

Puedes tener hasta 8 IAs conectadas. Escribe `revoke` y el nombre de una que ya no uses para liberar un lugar.

## Otra cosa

Los errores técnicos, como una conexión rechazada o una subida que falló, aparecen en Para desarrolladores.
