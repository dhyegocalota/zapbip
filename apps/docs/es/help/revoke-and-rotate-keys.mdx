import { Chat } from '/snippets/chat.jsx';

Cada IA tiene su propia conexión. La cortas, o reemplazas su enlace, escribiendo al número de zapbip. Los comandos están en español; también entiende los mismos comandos en inglés.

## Cortar una IA

Escribe `revocar` y el nombre de la IA, por ejemplo `revocar claude`. Todas las formas en que esa IA está conectada se detienen al instante: su enlace con zapbip, un listener que corra en tu computadora y cualquier activación que la arrancaría.

<Chat
  messages={[
    { you: true, text: 'revocar claude', time: '16:02' },
    { text: 'Agente claude revocado. Su enlace dejó de funcionar.', time: '16:02' },
  ]}
/>

Para volver a usar esa IA, escribe `nuevo agente claude`.

## Reemplazar un enlace

Escribe `rotar` y el nombre, por ejemplo `rotar claude`. La conexión anterior deja de funcionar al instante, con el mismo alcance que `revocar`, y zapbip te envía un prompt nuevo para pegar en esa IA.

<Chat
  messages={[
    { you: true, text: 'rotar claude', time: '16:05' },
    {
      text: 'Enlace del agente claude reemplazado. El enlace anterior dejó de funcionar. Pega esto en tu agente: ...',
      time: '16:05',
    },
  ]}
/>

Un enlace renovado se envía una vez. zapbip no lo vuelve a mostrar: `agents` lista tus IAs sin ningún enlace. Si el prompt nuevo no llega, zapbip mantiene la conexión anterior y puedes volver a escribir `rotar claude`.

## Cuándo usar cada uno

- Perdiste una IA, dejaste de usarla o compartiste su enlace por error: `revocar`.
- El enlace caducó, ya se usó o se filtró, y aún quieres la IA: `rotar`.

Mira cada palabra en [comandos en WhatsApp](/es/features/whatsapp-commands).
