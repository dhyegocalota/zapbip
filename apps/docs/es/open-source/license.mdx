zapbip es de código abierto bajo dos licencias, una para cada parte del código.

| Parte                                    | Licencia                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------------ |
| El servidor, el sitio y las bibliotecas  | [GNU AGPL v3.0](https://github.com/dhyegocalota/zapbip/blob/main/LICENSE)      |
| El conector local y los plugins de canal | [MIT](https://github.com/dhyegocalota/zapbip/blob/main/apps/connector/LICENSE) |

Los plugins de canal para [OpenClaw](https://github.com/dhyegocalota/zapbip/blob/main/apps/openclaw-plugin/LICENSE) y [Hermes](https://github.com/dhyegocalota/zapbip/blob/main/apps/hermes-plugin/LICENSE) también son MIT, y cada paquete incluye su propio archivo `LICENSE`.

## Contribuciones

Toda contribución se hace bajo el [Acuerdo de Licencia de Contribuidor](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md), que nombra a la empresa de abajo. Léelo antes de tu primer pull request.
