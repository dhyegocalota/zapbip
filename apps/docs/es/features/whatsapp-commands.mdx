Gestionas tus IAs escribiendo al número de zapbip. Un comando es una frase corta, en español o en inglés; el portugués, el alemán, el francés, el japonés, el coreano y el chino tienen los suyos. El idioma en que escribes es el idioma de la respuesta. Cada fila muestra las dos versiones.

| Quieres                     | Escribe en español                                         | O en inglés                                          | Qué pasa                                                                                          |
| --------------------------- | ---------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Conectar una IA nueva       | `nuevo agente claude`                                      | `new agent claude`                                   | zapbip responde con el prompt que debes pegar en esa IA                                           |
| Ver tus IAs                 | `mis agentes`                                              | `agents`                                             | Una lista con el nombre y la fecha de cada una                                                    |
| Desconectar una IA          | `revocar claude`                                           | `revoke claude`                                      | Esa IA deja de funcionar al instante                                                              |
| Obtener un prompt nuevo     | `rotar claude`                                             | `rotate claude`                                      | La conexión anterior se detiene y recibes un prompt nuevo                                         |
| Entrar en la aplicación web | `acceder`                                                  | `login`                                              | Un enlace que funciona una vez durante 10 minutos, mira [la aplicación web](/es/features/web-app) |
| Abrir el menú               | `ayuda` o `menu`                                           | `help` o `menu`                                      | Los comandos como texto y como lista tocable                                                      |
| Cambiar el idioma           | `cambiar idioma ja`                                        | `language ja`                                        | zapbip te responde en el idioma elegido. Códigos: `en`, `pt`, `es`, `de`, `fr`, `ja`, `ko`, `zh`  |
| Eliminar tu cuenta          | `eliminar cuenta`, luego `eliminar cuenta definitivamente` | `delete account`, luego `delete account permanently` | Mira [eliminar tu cuenta](/es/help/delete-your-account)                                           |

Escribe la frase sola. Un `?` o un `!` al final la convierte en un mensaje normal para tus IAs.

## Ejemplo

Las respuestas de zapbip están en español porque escribiste en español.

<Chat
  messages={[
    { you: true, text: 'mis agentes', time: '09:20' },
    { text: 'Tus agentes:\nclaude (2026-11-06, Claude Code)', time: '09:20' },
    { you: true, text: 'revocar claude', time: '09:21' },
    { text: 'Agente claude revocado. Su enlace dejó de funcionar.', time: '09:21' },
  ]}
/>

## Hablar con una IA usando una palabra de comando

Un mensaje que es exactamente una palabra de comando siempre es un comando. Para enviar esas mismas palabras a una IA, empieza por su nombre: `@claude help` llega a Claude en lugar de abrir el menú.

## Nombres

Las palabras `nuevo`, `agentes`, `revocar`, `rotar`, `ayuda`, `menu`, `acceder`, `eliminar` y sus versiones en inglés y en portugués están reservadas: no pueden ser el nombre de una IA.

## Mensajes reenviados

Un mensaje reenviado nunca es un comando, ni siquiera cuando su texto es una palabra de comando. Llega a tus IAs como cualquier otro mensaje.
