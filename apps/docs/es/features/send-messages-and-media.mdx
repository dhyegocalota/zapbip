Tu IA puede enviarte todo lo que WhatsApp puede transportar.

## Cómo se ve

<Chat
  messages={[
    { you: true, text: 'Envíame la captura de pantalla de la compilación terminada con el pie "Compilación terminada".', time: '16:40' },
    { name: 'Claude Code', media: { kind: 'image' }, text: 'Compilación terminada', time: '16:41' },
    { you: true, reaction: '👍', text: 'Perfecto, gracias.', time: '16:41' },
  ]}
/>

Los demás tipos llegan igual.

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'video', label: 'Grabación de la demo' }, time: '16:42' },
    { name: 'Claude Code', media: { kind: 'voice', label: '0:24' }, time: '16:42' },
    { name: 'Claude Code', media: { kind: 'document', label: 'release-notes.pdf' }, text: 'Notas de la versión', time: '16:43' },
  ]}
/>

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'sticker' }, time: '16:43' },
    { name: 'Claude Code', media: { kind: 'location', label: 'Café Brasileira, Chiado' }, time: '16:44' },
    { name: 'Claude Code', media: { kind: 'contact', label: 'Marta Souza', action: 'Enviar mensaje' }, time: '16:44' },
  ]}
/>

## Qué puede enviar

| Lo que ves en tu teléfono                    | Tipo       |
| -------------------------------------------- | ---------- |
| Un texto, con formato de WhatsApp y emojis   | `text`     |
| Una foto                                     | `image`    |
| Un vídeo                                     | `video`    |
| Un archivo de audio o una nota de voz        | `audio`    |
| Un archivo, como un PDF                      | `document` |
| Un sticker                                   | `sticker`  |
| Un pin en el mapa                            | `location` |
| Una o más tarjetas de contacto               | `contacts` |
| Una reacción con emoji a uno de tus mensajes | `reaction` |
| Botones o una lista para elegir              | `choice`   |

Cualquiera de ellos puede citar uno de tus mensajes. Cuando tú envías una foto o un archivo a tu IA, ella también lo recibe.
