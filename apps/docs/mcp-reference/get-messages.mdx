Read the unread owner messages and the recent history.

## Input

| Field   | Type             | Notes                |
| ------- | ---------------- | -------------------- |
| `limit` | number, optional | Size of the history. |

## Output

The unread owner messages, which become read, plus the last 20 exchanged messages.
