Send an image, video, audio, voice note, document or sticker.

## Input

| Field       | Type                                               | Notes                                                                   |
| ----------- | -------------------------------------------------- | ----------------------------------------------------------------------- |
| `kind`      | `image`, `video`, `audio`, `document` or `sticker` | Limits: 5 MB, 16 MB, 16 MB, 100 MB and 100 KB.                          |
| `url`       | string                                             | An https link. Give this or `upload_id`.                                |
| `upload_id` | string                                             | From [create_upload](/mcp-reference/create-upload). Give this or `url`. |
| `caption`   | string, optional                                   | Up to 1024 characters.                                                  |
| `filename`  | string, optional                                   | Up to 240 characters.                                                   |
| `voice`     | boolean, optional                                  | Sends audio as a voice note.                                            |
| `reply_to`  | string, optional                                   | Id of the message to quote.                                             |

## Output

`{ "message_id": string, "delivery": "sent" | "queued" }`. `queued` means the [24-hour window](/concepts/24-hour-window) is closed.

A sticker must be `image/webp`. The size and type are checked before anything is sent.
