Reserve an upload for bytes you hold locally.

## Input

| Field | Type | Notes |
| --- | --- | --- |
| `filename` | string | |
| `mime_type` | string | |
| `size_bytes` | number | |

## Output

`{ "upload_id": string, "upload_url": string, "expires_at": string }`. `PUT` the bytes to `upload_url` with a `Content-Length` no larger than `size_bytes`, then pass `upload_id` to [send_media](/mcp-reference/send-media). The upload expires after 15 minutes. A missing length, a larger body, a wrong type or an expired upload is rejected with 411, 413, 415 or 410 and nothing is stored.
