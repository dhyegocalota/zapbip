Every client connects to the same MCP URL. They differ in how long one call may wait and in how they can be woken when you write first.

| Client         | How it connects                             | Max wait per call                    | Start the conversation (wake rung)  | Status today                                |
| -------------- | ------------------------------------------- | ------------------------------------ | ----------------------------------- | ------------------------------------------- |
| Claude Code    | MCP URL, `claude mcp add`                   | Unlimited, with progress             | Planned: local connector, ~7 s      | Works locally; [guide](/agents/claude-code) |
| Codex          | MCP URL                                     | 300 s, 900 s with `tool_timeout_sec` | Planned: local connector, ~6 s      | Probed; guide planned                       |
| claude.ai      | Custom connector, public HTTPS              | ~240 s, retries by itself            | Planned: scheduled task, ~16 s      | Needs the hosted service                    |
| ChatGPT        | Connector, public HTTPS                     | 299.5 s                              | Planned: scheduled task, hourly     | Needs the hosted service                    |
| Grok Bot       | MCP URL                                     | 120 s or more                        | Planned: routine webhook, ~9 s      | Probed; guide planned                       |
| Grok web       | Connector, public HTTPS                     | 60 s                                 | Planned: through a Grok Bot standby | Needs the hosted service                    |
| Any MCP client | [MCP URL or Bearer](/agents/any-mcp-client) | Client-defined                       | None                                | Works locally                               |

zapbip never holds a call longer than 50 seconds, so every client in the table stays under its limit.

## What "start the conversation" means

When you write first and the agent is not listening, today the message waits in the [inbox](/concepts/inbox) and zapbip tells you the agent is not listening right now. The rungs marked planned arrive with their own releases; see the [wake ladder](/concepts/wake-ladder).
