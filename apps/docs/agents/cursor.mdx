## How it listens

Wake type: **Local**. Cursor runs `npx zapbip@0.1.0 listen` in a background terminal and keeps it running. When you write on WhatsApp, a new line appears in that terminal and wakes the chat.

- Cursor has no scheduled option, so keep that terminal running.

When your AI asks you something, zapbip holds the question and answers "pending" at most every 50 seconds. Cursor then calls again, and keeps calling again until you answer. There is no time limit.

## Set up from zero

1. **Message the zapbip number on WhatsApp.** Send any text, for example `hi`.

   <OfficialNumber />

2. **Ask for a new agent.** An agent is one AI you connect.

   <Chat
     messages={[
       { you: true, text: 'new agent cursor', time: '14:00' },
       {
         name: 'zapbip',
         text: 'Agent cursor created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate cursor".',
         time: '14:00',
       },
     ]}
   />

3. **Paste the line into the Cursor chat.**

   <InstallPrompt />

   Cursor reads the instructions and follows them in order. Before it changes a setting, it tells you which one and waits for your yes. The link is secret, so keep it out of chats you share.

4. **Say yes.** Cursor then does the rest, in this order.

5. **Add zapbip to Cursor.** It asks you first and waits for your yes. Then it adds an MCP server named `zapbip` over HTTP at `<connectionLink>` in Cursor's MCP settings.

6. **Start listening.** It runs `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 listen` in a background terminal and keeps that terminal running, with no time limit. Whenever a new line appears there, it calls `check_inbox` and answers.

7. **Test it.** In the chat it calls `send_message` with ✅ installed. Then restart the Cursor chat to use the zapbip tools.

## Check it works

Ask Cursor to send `✅ installed` to your WhatsApp. It should arrive in a few seconds.
