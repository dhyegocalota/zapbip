## How it listens

Wake type: **Scheduled**. ChatGPT reads your WhatsApp messages once an hour, the shortest interval the app allows, so a message can wait up to an hour.

- An hourly task runs on your computer and posts into one dedicated chat. Each run reads what you wrote since the last one.
- Keep that chat and your computer on, so the task can run.

When your AI asks you something, zapbip holds the question and answers "pending" at most every 50 seconds. ChatGPT then calls again, and keeps calling again until you answer. There is no time limit.

ChatGPT waits about 5 minutes for a single answer and asks again, so there is no limit overall.

## Set up from zero

1. **Message the zapbip number on WhatsApp.** Send any text, for example `hi`.

   <StartLink />

2. **Ask for a new agent.** An agent is one AI you connect.

   <Chat
     messages={[
       { you: true, text: 'new agent chatgpt', time: '16:00' },
       {
         name: 'zapbip',
         text: 'Agent chatgpt created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate chatgpt".',
         time: '16:00',
       },
     ]}
   />

3. **Paste the line into ChatGPT.**

   <InstallPrompt />

   ChatGPT reads the instructions and follows them in order. The link is secret, so keep it out of chats you share.

4. **Add the app.** ChatGPT asks you to turn on developer mode and add an app by URL with `<connectionLink>`, choosing "No authentication". You do this one yourself.

5. **Create the hourly task.** It asks you to create an hourly "Run on this computer" task that calls `check_inbox`, in one dedicated chat, and to choose "Always allow" once for each tool.

6. **Tell zapbip it polls.** It calls `set_wake({mode: "scheduled", interval_minutes: 60})`.

7. **Test it.** In the chat it calls `send_message` with ✅ installed.

## Check it works

ChatGPT sends `✅ installed` to your WhatsApp once it is connected.

<Chat messages={[{ name: 'ChatGPT', text: '✅ installed', time: '16:05' }]} />
