---
title: Jeden MCP-Client verbinden
description: Die Verbindungs-URL, die Bearer-Alternative und die Werkzeuge.
---

zapbip spricht MCP über Streamable HTTP. Jeder Client, der es unterstützt, kann sich mit der Verbindungs-URL verbinden, die zapbip deinem Agent gibt.

## Die Verbindungs-URL

```text
https://<zapbip-host>/c/<secret>/mcp
```

Das Geheimnis in der URL ist die Verbindung. Halte es privat.

## Die Bearer-Alternative

Für Clients, die kein Geheimnis in einer URL verbergen können, nutze `/mcp` und sende das Geheimnis als Header:

```text
POST https://<zapbip-host>/mcp
Authorization: Bearer <secret>
```

Beide Formen erreichen denselben Agent. Ein fehlendes oder falsches Geheimnis antwortet mit `401`.
