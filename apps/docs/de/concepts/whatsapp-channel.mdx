---
title: 'WhatsApp-Kanal'
description: 'Wie eine Nachricht zwischen Owner und Agent reist und welche Limits WhatsApp setzt.'
---

zapbip spricht mit dem Owner über die offizielle WhatsApp Cloud API, auf einer Nummer, die sich alle Konten teilen.

## Eingehende Nachrichten

Der Owner schreibt an die Nummer. zapbip prüft die Signatur jeder Benachrichtigung, speichert jede Nachricht nur einmal, auch wenn WhatsApp sie zweimal zustellt, und leitet sie nach [den Routing-Regeln](/de/concepts/routing) an einen Agent.

| Der Owner sendet                                             | Der Agent erhält                                                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| Text, Bild, Video, Audio, Sprachnachricht, Dokument, Sticker | die Nachricht, mit den von zapbip gespeicherten Medien                                                 |
| Standort, Kontaktkarte                                       | die Nachricht                                                                                          |
| eine Antwort per Button oder Listenzeile                     | die Auswahl, die die Frage beantwortet                                                                 |
| eine Reaktion                                                | die Reaktion, geleitet an den Agent, der die Nachricht gesendet hat; das Entfernen kommt ohne Emoji an |
| eine Nachricht anderer Art                                   | nichts; dem Owner wird gesagt, dass die Art noch nicht unterstützt wird                                |

Eine Nachricht, die der Owner sendet, öffnet das [24-Stunden-Fenster](/de/concepts/24-hour-window). Eine Reaktion nicht.

Lässt sich eine Datei nicht herunterladen, erhält der Agent die Nachricht mit `media_id: null` und `media_status: "unavailable"`, und der Owner wird gebeten, sie erneut zu senden.

## Ausgehende Nachrichten

Innerhalb des Fensters gehen alle Arten sofort hinaus. Außerhalb kommt die Nachricht in die Warteschlange, und der Owner erhält [einen Hinweis](/de/concepts/owner-notices).

| Art      | Limit                                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Text     | 4096 Zeichen                                                                                                                               |
| Buttons  | bis zu 3 Buttons, Frage bis zu 1024 Zeichen, Titel bis zu 20 Zeichen                                                                       |
| Liste    | bis zu 10 Zeilen, Frage bis zu 1024 Zeichen, Button bis zu 20 Zeichen, Zeilentitel bis zu 24 Zeichen, Zeilenbeschreibung bis zu 72 Zeichen |
| Reaktion | die Nachricht, auf die reagiert wird, darf höchstens 30 Tage alt sein, muss im selben Thread liegen und darf nicht gelöscht sein           |
| Bild     | JPEG, PNG oder WebP, bis zu 5 MB                                                                                                           |
| Video    | 3GP oder MP4, bis zu 16 MB                                                                                                                 |
| Audio    | AAC, AMR, MP3, M4A oder OGG, bis zu 16 MB                                                                                                  |
| Dokument | PDF, Word, Excel, PowerPoint oder reiner Text, bis zu 100 MB                                                                               |
| Sticker  | statisches WebP, bis zu 100 KB                                                                                                             |

zapbip lehnt ein Senden ab, das ein Limit bricht, und das Werkzeug gibt einen Fehler zurück, der das Feld nennt.

## Zustellung

Die `delivery` einer Nachricht geht nur vorwärts: `sent`, `delivered`, `read`. Ein Senden, das WhatsApp ablehnt, wird zu `failed`. Eine Nachricht, die bereits `delivered` oder `read` ist, wird nie zu `failed`.

## Eingeschränkte Nummer

Meldet WhatsApp, dass die Nummer eingeschränkt oder das Konto deaktiviert ist, hört zapbip 24 Stunden lang mit dem Senden auf und der Betreiber wird benachrichtigt. In dieser Zeit gesendete Nachrichten geben `delivery: "failed"` zurück.
