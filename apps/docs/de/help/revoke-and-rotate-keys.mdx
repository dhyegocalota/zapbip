title: Eine Verbindung widerrufen und erneuern
description: Trenne eine KI oder ersetze ihren Link.

import { Chat } from '/snippets/chat.jsx';

Jede KI hat ihre eigene Verbindung. Du trennst sie oder ersetzt ihren Link, indem du der zapbip-Nummer schreibst. Die Befehle sind auf Deutsch; dieselben versteht es auch auf Englisch.

## Eine KI trennen

Schreib `widerrufen` und den Namen der KI, zum Beispiel `widerrufen claude`. Jeder Weg, auf dem diese KI verbunden ist, endet sofort: ihr Link zu zapbip, ein Listener auf deinem Computer und jedes Wecken, das sie starten würde.

<Chat
  messages={[
    { you: true, text: 'widerrufen claude', time: '16:02' },
    { text: 'Agent claude widerrufen. Sein Link funktioniert nicht mehr.', time: '16:02' },
  ]}
/>

Um diese KI wieder zu nutzen, schreib `neuer agent claude`.

## Einen Link ersetzen

Schreib `erneuern` und den Namen, zum Beispiel `erneuern claude`. Die alte Verbindung funktioniert sofort nicht mehr, mit derselben Reichweite wie `widerrufen`, und zapbip schickt dir einen neuen Prompt zum Einfügen in diese KI.

<Chat
  messages={[
    { you: true, text: 'erneuern claude', time: '16:05' },
    {
      text: 'Link des Agenten claude ersetzt. Der alte Link funktioniert nicht mehr. Füge das in deinen Agenten ein: ...',
      time: '16:05',
    },
  ]}
/>

Ein erneuerter Link wird einmal gesendet. zapbip zeigt ihn nie wieder: `agents` listet deine KIs ohne jeden Link auf. Kommt der neue Prompt nicht an, behält zapbip die alte Verbindung, und du kannst `erneuern claude` erneut schreiben.

## Wann was

- Du hast eine KI verloren, nutzt sie nicht mehr oder hast ihren Link versehentlich geteilt: `widerrufen`.
- Der Link ist abgelaufen, wurde schon benutzt oder ist durchgesickert, und du willst die KI weiter nutzen: `erneuern`.

Alle Wörter findest du unter [Befehle in WhatsApp](/de/features/whatsapp-commands).
