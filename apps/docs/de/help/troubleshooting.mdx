## Die Nachricht meiner KI ist nicht angekommen

Wahrscheinlich ist das [24-Stunden-Fenster](/de/features/the-24-hour-window) geschlossen. Schreib irgendetwas an die zapbip-Nummer, und die wartenden Nachrichten kommen der Reihe nach an. Die Hinweise von zapbip sind in deiner Sprache.

<Chat
  messages={[
    { notice: true, text: 'Der Agent claude-code hat eine Nachricht für dich: Migration abgeschlossen ✅', time: '07:12' },
    { you: true, text: 'ok', time: '07:30' },
    { name: 'Claude Code', text: 'Migration abgeschlossen ✅', time: '07:30' },
    { name: 'Grok', text: '3 Quellen gefunden.', time: '07:30' },
  ]}
/>

## Ich habe geschrieben und meine KI hat nicht geantwortet

Deine KI hat nicht zugehört. Deine Nachricht wartet auf sie, und zapbip sagt dir, dass die KI gerade nicht zuhört.

<Chat
  messages={[
    { you: true, text: '@claude ist der Build grün?', time: '14:20' },
    { notice: true, text: 'Der Agent claude hört gerade nicht zu. Deine Nachricht wartet im Posteingang.', time: '14:20' },
  ]}
/>

Öffne die KI und bitte sie, ihre Nachrichten abzurufen, und sieh unter [Unterstützte KIs](/de/agents/supported-agents), wie jede KI zuhört.

## Meine Nachricht ging an die falsche KI

Beginne sie mit `@name`, zum Beispiel `@grok schau dir die Nachrichten an`, oder antworte direkt auf die Nachricht der KI.

<Chat
  messages={[
    { name: 'Grok', text: '3 Quellen gefunden.', time: '11:05' },
    { you: true, text: '@grok schau dir die Nachrichten an', time: '11:06' },
    { you: true, quote: { name: 'Grok', text: '3 Quellen gefunden.' }, text: 'Welche?', time: '11:07' },
  ]}
/>

Siehe [Viele KIs mit einer Nummer](/de/features/many-agents-on-one-number).

## Ich habe eine Nachricht geschickt und nichts kam zurück

Dein Konto steht vielleicht auf der Warteliste. Es wird zurückgehalten, bis das zapbip-Team es freischaltet. Warte und sende `help`, wenn der Zugang offen ist.

## Der Link in meinem Prompt funktioniert nicht

Der Link funktioniert einmal, 30 Minuten lang. Schreib `erneuern` und den Namen der KI, zum Beispiel `erneuern claude`, um einen neuen Prompt zu bekommen. Siehe [Widerrufen und erneuern](/de/help/revoke-and-rotate-keys).

## zapbip hat den Namen meiner KI abgelehnt

Ein Name hat 1 bis 20 Kleinbuchstaben, Ziffern oder Bindestriche, beginnt mit einem Buchstaben oder einer Ziffer und darf nicht wie ein Befehl beginnen. Sende `neuer agent` mit einem anderen Namen.

## zapbip sagt, ich hätte das Limit erreicht

Du kannst bis zu 8 KIs verbunden haben. Schreib `widerrufen` und den Namen einer KI, die du nicht mehr nutzt, um einen Platz freizugeben.

## Etwas anderes

Technische Fehler, etwa eine abgelehnte Verbindung oder ein fehlgeschlagener Upload, stehen unter Für Entwickler.
