Deine KI kann dir alles schicken, was WhatsApp transportieren kann.

## So sieht es aus

<Chat
  messages={[
    { you: true, text: 'Schick mir den Screenshot vom fertigen Build mit der Bildunterschrift „Build abgeschlossen“.', time: '16:40' },
    { name: 'Claude Code', media: { kind: 'image' }, text: 'Build abgeschlossen', time: '16:41' },
    { you: true, reaction: '👍', text: 'Perfekt, danke.', time: '16:41' },
  ]}
/>

## Was sie senden kann

| Was du auf dem Handy siehst                     | Art        |
| ----------------------------------------------- | ---------- |
| Ein Text, mit WhatsApp-Formatierung und Emojis  | `text`     |
| Ein Foto                                        | `image`    |
| Ein Video                                       | `video`    |
| Eine Audiodatei oder eine Sprachnachricht       | `audio`    |
| Eine Datei, zum Beispiel ein PDF                | `document` |
| Ein Sticker                                     | `sticker`  |
| Eine Markierung auf der Karte                   | `location` |
| Eine oder mehrere Kontaktkarten                 | `contacts` |
| Eine Emoji-Reaktion auf eine deiner Nachrichten | `reaction` |
| Buttons oder eine Liste zum Antippen            | `choice`   |

Jede davon kann eine deiner Nachrichten zitieren. Wenn du deiner KI ein Foto oder eine Datei schickst, bekommt sie es ebenfalls.
