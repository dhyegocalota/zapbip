Du verwaltest deine KIs, indem du der zapbip-Nummer schreibst. Ein Befehl ist eine kurze Formulierung, auf Deutsch oder Englisch; Portugiesisch, Spanisch, Französisch, Japanisch, Koreanisch und Chinesisch haben ihre eigenen. Die Sprache, in der du schreibst, ist die Sprache der Antwort. Jede Zeile zeigt beide Versionen.

| Du willst                | Auf Deutsch schreiben                           | Oder auf Englisch                                   | Was passiert                                                                                         |
| ------------------------ | ----------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Eine neue KI verbinden   | `neuer agent claude`                            | `new agent claude`                                  | zapbip antwortet mit dem Prompt zum Einfügen in diese KI                                             |
| Deine KIs ansehen        | `meine agenten`                                 | `agents`                                            | Eine Liste mit Name und Datum jeder KI                                                               |
| Eine KI trennen          | `widerrufen claude`                             | `revoke claude`                                     | Diese KI hört sofort auf zu arbeiten                                                                 |
| Einen neuen Prompt holen | `erneuern claude`                               | `rotate claude`                                     | Die alte Verbindung endet und du bekommst einen frischen Prompt                                      |
| In der Web-App anmelden  | `anmelden`                                      | `login`                                             | Ein Link, der einmal 10 Minuten lang funktioniert, siehe [die Web-App](/de/features/web-app)         |
| Das Menü öffnen          | `hilfe` oder `menü`                             | `help` oder `menu`                                  | Die Befehle als Text und als antippbare Liste                                                        |
| Die Sprache ändern       | `sprache ja`                                    | `language ja`                                       | zapbip antwortet dir in der gewählten Sprache. Codes: `en`, `pt`, `es`, `de`, `fr`, `ja`, `ko`, `zh` |
| Dein Konto löschen       | `konto löschen`, dann `konto endgültig löschen` | `delete account`, dann `delete account permanently` | Siehe [dein Konto löschen](/de/help/delete-your-account)                                             |

Schreib die Formulierung allein. Ein angehängtes `?` oder `!` macht daraus eine normale Nachricht an deine KIs.

## Beispiel

Die Antworten von zapbip sind auf Deutsch, weil du auf Deutsch geschrieben hast.

  messages={[
    { you: true, text: 'meine agenten', time: '09:20' },
    { text: 'Deine Agenten:\nclaude (2026-11-06, Claude Code)', time: '09:20' },
    { you: true, text: 'widerrufen claude', time: '09:21' },

  ]}
/>

## Mit einer KI über ein Befehlswort sprechen

Eine Nachricht, die genau ein Befehlswort ist, ist immer ein Befehl. Um dieselben Wörter an eine KI zu senden, beginne mit ihrem Namen: `@claude help` erreicht Claude, statt das Menü zu öffnen.

## Namen

Die Wörter `neuer`, `agenten`, `widerrufen`, `erneuern`, `hilfe`, `menü`, `anmelden`, `konto` und ihre englischen und portugiesischen Versionen sind reserviert: Sie können nicht der Name einer KI sein.

## Weitergeleitete Nachrichten

Eine weitergeleitete Nachricht ist nie ein Befehl, auch wenn ihr Text ein Befehlswort ist. Sie geht wie jede andere Nachricht an deine KIs.
