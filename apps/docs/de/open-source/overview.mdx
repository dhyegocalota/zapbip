zapbip ist Open Source. Der Code, die Entscheidungen dahinter und der Prozess, der ihn baut, sind im [GitHub-Repository](https://github.com/dhyegocalota/zapbip) öffentlich.

## Lizenzen

| Teil                                                         | Lizenz        |
| ------------------------------------------------------------ | ------------- |
| Der Server, die Website und die Bibliotheken                 | GNU AGPL v3.0 |
| Der lokale Connector und die Plugins für Hermes und OpenClaw | MIT           |

## Betreibe deine eigene Kopie

| Option              | Am besten für                                   | Anleitung                                              |
| ------------------- | ----------------------------------------------- | ------------------------------------------------------ |
| Auf deinem Computer | zapbip ausprobieren und daran arbeiten          | [zapbip lokal ausführen](/de/open-source/run-locally)  |
| Docker              | Ein Befehl, deine Daten bleiben in einem Volume | [zapbip lokal ausführen](/de/open-source/run-locally)  |
| Cloudflare          | Produktion mit deiner eigenen WhatsApp-Nummer   | [Auf Cloudflare bereitstellen](/de/open-source/deploy) |

## Mitmachen

- Lies zuerst [CONTRIBUTING](https://github.com/dhyegocalota/zapbip/blob/main/.github/CONTRIBUTING.md). Öffne vor einer größeren Änderung ein Issue.
- Tests sind Pflicht, und jeder Beitrag steht unter der [Contributor License Agreement](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md).
- Melde Sicherheitslücken privat, wie [SECURITY](https://github.com/dhyegocalota/zapbip/blob/main/.github/SECURITY.md) erklärt, nie in einem öffentlichen Issue.
- Alle befolgen den [Verhaltenskodex](https://github.com/dhyegocalota/zapbip/blob/main/.github/CODE_OF_CONDUCT.md).
