zapbip ist Open Source unter zwei Lizenzen, eine für jeden Teil des Codes.

| Teil                                         | Lizenz                                                                          |
| -------------------------------------------- | ------------------------------------------------------------------------------- |
| Der Server, die Website und die Bibliotheken | [GNU AGPL v3.0](https://github.com/dhyegocalota/zapbip/blob/main/LICENSE)       |
| Der lokale Connector und die Kanal-Plugins   | [MIT](https://github.com/dhyegocalota/zapbip/blob/main/apps/connector/LICENSE)  |

Die Kanal-Plugins für [OpenClaw](https://github.com/dhyegocalota/zapbip/blob/main/apps/openclaw-plugin/LICENSE) und [Hermes](https://github.com/dhyegocalota/zapbip/blob/main/apps/hermes-plugin/LICENSE) sind ebenfalls MIT, und jedes Paket bringt seine eigene `LICENSE`-Datei mit.

## Beiträge

Jeder Beitrag steht unter der [Contributor License Agreement](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md), die das Unternehmen unten nennt. Lies sie vor deinem ersten Pull Request.

## Unternehmen
