---
title: Connect Claude Code
description: Connect Claude Code to a local zapbip, from zero.
---

<Note>This guide uses the local stack from the [Quickstart](/developers/quickstart). The hosted URL arrives later.</Note>

<Steps>
  <Step title="Get the agent URL">
    Seeding prints `<agent> <secret>`. The URL is:

    ```text
    http://localhost:8787/c/<secret>/mcp
    ```

    The secret in the URL is the connection. Keep it private.

  </Step>
  <Step title="Add the server">
    ```bash
    claude mcp add --transport http alpha http://localhost:8787/c/<secret>/mcp
    ```
  </Step>
  <Step title="Check it">
    ```bash
    claude mcp list
    ```

    `alpha` shows as connected.

  </Step>
  <Step title="Use it">
    Start `claude` and write:

    ```text
    Use alpha to send me "hello from Claude Code".
    ```

    Claude Code asks to approve the tool the first time. Then the message shows on the simulator screen.

  </Step>
</Steps>

The tools appear as `mcp__alpha__send_message`, `mcp__alpha__ask` and so on. See the [tool reference](/mcp-reference/send-message).
