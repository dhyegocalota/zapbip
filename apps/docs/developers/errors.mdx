## 401 unauthorized

The secret is missing, wrong or from another stack. Copy the URL again from the seed output, and check that the Worker you started is the one that was seeded. With the Bearer form, the header is `Authorization: Bearer <secret>`.

## Nothing on the simulator screen

The screen is keyed by the owner phone you seeded. Use the same digits in `/dev/owner/<phone>/screen`. A `404` means that phone has no owner.

## The message is queued

`delivery: "queued"` means the [24-hour window](/features/the-24-hour-window) is closed. Locally, send `@alpha hello` through the simulator and the queue flushes in order.

## Upload errors

The bytes are rejected before anything is stored:

| Status | Cause                                               |
| ------ | --------------------------------------------------- |
| 411    | `PUT` without a `Content-Length`                    |
| 413    | Body larger than the declared `size_bytes`          |
| 415    | A type that does not match the declared `mime_type` |
| 410    | The upload expired after 15 minutes                 |

See [create_upload](/mcp-reference/create-upload).
