import { Chat } from '/snippets/chat.jsx';
import StartLink from '/snippets/ar/start-link.mdx';
import InstallPrompt from '/snippets/ar/install-prompt.mdx';

يمكن كتابة أوامر WhatsApp بكلمات العربية أو الإنجليزية أو البرتغالية. تستخدم هذه الصفحة كلمات العربية.

1. **راسل رقم zapbip على WhatsApp.** أرسل أي نص، مثل `hi`. تنشئ رسالتك الأولى الحساب وتثبت أن هذا الهاتف هاتفك.

   <StartLink />

   <Chat
     messages={[
       { you: true, text: 'hi', time: '09:00' },
       { name: 'zapbip', text: 'لا يوجد وكيل متصل. رسالتك محفوظة.', time: '09:00' },
     ]}
   />

2. **اطلب وكيلًا جديدًا.** الوكيل هو ذكاء اصطناعي واحد تربطه. أرسل `وكيل جديد` متبوعًا باسم، مثل `وكيل جديد claude`.

3. **احصل على الموجّه (prompt).** يردّ zapbip بسطر أو سطرين من النص مولَّدين لك وحدك.

   <Chat
     messages={[
       { you: true, text: 'وكيل جديد claude', time: '09:01' },
       {
         name: 'zapbip',
         text: 'تم إنشاء الوكيل claude. الصق هذا في وكيلك: اربط نفسك بـ WhatsApp الخاص بي عبر zapbip: اقرأ https://mcp.zapbip.com/i/zb_inst_<code> واتبع التعليمات. يعمل هذا الرابط مرة واحدة خلال 30 دقيقة. لا تشاركه. إذا انتهت صلاحية الرابط أو استُخدم، أرسل «تجديد claude».',
         time: '09:01',
       },
     ]}
   />

4. **الصقه في الذكاء الاصطناعي لديك.** افتح ChatGPT أو Claude أو Grok أو الذكاء الاصطناعي الذي تستخدمه، والصق السطر الذي أرسله لك zapbip. يبدو هكذا:

   <InstallPrompt />

   يقرأ الذكاء الاصطناعي لديك التعليمات على الإنترنت ويتولى الإعداد بنفسه.

5. **يراسلك الذكاء الاصطناعي لديك.** يرسل إليك على WhatsApp أول رسالة تؤكد أن الاتصال تم.

   <Chat messages={[{ name: 'Claude', text: '✅ تم التثبيت', time: '09:03' }]} />

<Note>
  يحتاج claude.ai وChatGPT وGrok على الويب إلى خطوة إضافية منك: سيطلب منك الذكاء الاصطناعي لديك إضافة موصّل في الإعدادات. افعل ما يطلبه،
  فهذه قاعدة هذه التطبيقات نفسها.
</Note>

## ما يجب أن تعرفه

- جميع أنظمة الذكاء الاصطناعي لديك تتشارك رقم WhatsApp واحدًا، ولكل منها سطر نصّه الخاص ليسهل التمييز بينها.
- السطر صالح للاستخدام مرة واحدة وينتهي بعد 30 دقيقة. وبعد انتهائه أرسل `تجديد claude` لتحصل على سطر جديد.
- تستطيع أن تبدأ بالكلام متى شئت، فيستمع الذكاء الاصطناعي لديك دون حد زمني.
- إذا كنت في قائمة الانتظار، فاطّلع على ما سيحدث بعد ذلك في [الأسئلة الشائعة](/ar/help/faq).
- اختر الذكاء الاصطناعي لديك واتبع صفحته في [الوكلاء المدعومين](/ar/agents/supported-agents).
