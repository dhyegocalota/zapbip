---
title: عدة وكلاء على رقم واحد
description: كيف يجد ردّك الذكاء الاصطناعي المقصود.
---

import { Chat } from '/snippets/chat.jsx';

كل أنظمة الذكاء الاصطناعي لديك تراسلك من رقم WhatsApp واحد. ويقرر zapbip وجهة رسالتك بهذا الترتيب:

| ما تفعله                                       | إلى أين تذهب                    |
| ---------------------------------------------- | ------------------------------- |
| الرد بزر أو بخيار من قائمة                     | الذكاء الاصطناعي الذي سأل       |
| الرد على رسالة، أو التفاعل معها                | الذكاء الاصطناعي الذي أرسلها    |
| إرسال `@grok check the news`                   | Grok، مع حذف `@grok `           |
| الإجابة عندما يكون لدى ذكاء اصطناعي سؤال معلّق | ذلك الذكاء الاصطناعي            |
| الكتابة بعد أن تحدّث Claude وحده               | Claude، أي آخر من تحدّث         |
| الكتابة حين لا تنطبق أي قاعدة                  | قائمة بأحدث الأنظمة لتختار منها |

## أمثلة

<Chat
  messages={[
    { name: 'Claude', text: 'نجحت الاختبارات.', time: '10:02' },
    { name: 'Grok', text: 'هل أجري rebase على main؟', options: ['نعم', 'لا'], time: '10:03' },
    { you: true, text: '@claude شكرًا', time: '10:04' },
    { you: true, text: 'نعم', time: '10:04' },
  ]}
/>

تذهب `@claude شكرًا` إلى Claude، ويذهب ردّك «نعم» إلى Grok.

<Chat
  messages={[
    { you: true, text: 'ok', time: '10:05' },
    { name: 'zapbip', text: 'إلى أي ذكاء اصطناعي تقصد؟ Claude، Grok', options: ['Claude', 'Grok'], time: '10:05' },
  ]}
/>

كلمة `ok` وحدها تعرض قائمة بأحدث الأنظمة لتختار منها.

الرد على رسالة يحادث الذكاء الاصطناعي الذي أرسلها:

<Chat
  messages={[
    { name: 'Claude', text: 'نجحت الاختبارات.', time: '10:02' },
    { name: 'Grok', text: 'وجدت 3 مصادر.', time: '10:03' },
    { you: true, quote: { name: 'Grok', text: 'وجدت 3 مصادر.' }, text: 'أيّها؟', time: '10:04' },
    { name: 'Grok', text: 'ورقتان وتقرير. سأرسل لك الروابط.', time: '10:04' },
  ]}
/>

الأسماء حتى 20 حرفًا: أحرف لاتينية صغيرة وأرقام وشرطات.
