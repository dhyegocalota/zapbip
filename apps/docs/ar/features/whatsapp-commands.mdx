تدير وكلاءك بمراسلة رقم zapbip. الأمر عبارة قصيرة بالعربية أو الإنجليزية؛ وللبرتغالية والإسبانية والألمانية والفرنسية واليابانية والكورية والصينية أوامرها الخاصة أيضًا. ويأتي الرد باللغة التي كتبت بها. وفي كل صف الصيغتان.

| ما تريده               | اكتب بالعربية                        | أو اكتب بالإنجليزية                               | ما الذي يحدث                                                                                  |
| ---------------------- | ------------------------------------ | ------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| ربط ذكاء اصطناعي جديد  | `وكيل جديد claude`                   | `new agent claude`                                | يردّ zapbip بالموجّه الذي تلصقه في ذلك الذكاء الاصطناعي                                       |
| عرض وكلائك             | `وكلائي`                             | `agents`                                          | قائمة بكل ذكاء اصطناعي واسمه وتاريخه                                                          |
| فصل ذكاء اصطناعي       | `إبطال claude`                       | `revoke claude`                                   | يتوقف ذلك الذكاء الاصطناعي فورًا                                                              |
| الحصول على موجّه جديد  | `تجديد رابط claude`                  | `rotate claude`                                   | يتوقف الاتصال القديم ويصلك موجّه جديد                                                         |
| الدخول إلى تطبيق الويب | `دخول`                               | `login`                                           | رابط يعمل مرة واحدة لمدة 10 دقائق، راجع [تطبيق الويب](/ar/features/web-app)                   |
| فتح القائمة            | `مساعدة` أو `القائمة`                | `help` أو `menu`                                  | تعرض هذه الأوامر نصًا وقائمة يمكن الاختيار منها                                               |
| تغيير اللغة            | `تغيير اللغة ja`                     | `language ja`                                     | يردّ zapbip باللغة التي اخترتها. الرموز: `en` و`pt` و`es` و`de` و`fr` و`ja` و`ko` و`zh` و`ar` |
| حذف حسابك              | `حذف الحساب`، ثم `حذف الحساب نهائيا` | `delete account`، ثم `delete account permanently` | راجع [حذف حسابك](/ar/help/delete-your-account)                                                |

اكتب العبارة وحدها. وإذا انتهت بـ `؟` أو `!` فهي رسالة عادية إلى الذكاء الاصطناعي لديك.

لا تهمّ علامات التشكيل ولا التطويل ولا الفرق بين الهمزات في الأوامر العربية: `ابطال` و`إبطال` أمر واحد.

## مثال

يردّ zapbip بالعربية لأنك كتبت بالعربية.

<Chat
  messages={[
    { you: true, text: 'وكلائي', time: '09:20' },
    { text: 'وكلاؤك:\nclaude (2026-11-06, Claude Code)', time: '09:20' },
    { you: true, text: 'إبطال claude', time: '09:21' },
    { text: 'تم إبطال الوكيل claude. لم يعد رابطه يعمل.', time: '09:21' },
  ]}
/>

## قول كلمة أمر للذكاء الاصطناعي

الرسالة التي هي كلمة أمر بالضبط تكون أمرًا دائمًا. ولإرسال الكلمة نفسها إلى ذكاء اصطناعي، ابدأ باسمه: `@claude help` تصل إلى Claude ولا تفتح القائمة.

## الأسماء

الكلمات `وكيل` و`جديد` و`إبطال` و`تجديد` و`مساعدة` و`القائمة` و`دخول` و`الحساب` ونظائرها بالإنجليزية والبرتغالية محجوزة، ولا يجوز استخدامها اسمًا لذكاء اصطناعي.

## الرسائل المعاد توجيهها

الرسالة المعاد توجيهها ليست أمرًا أبدًا، حتى لو كان نصها كلمة أمر. وتصل إلى الذكاء الاصطناعي لديك كأي رسالة أخرى.
