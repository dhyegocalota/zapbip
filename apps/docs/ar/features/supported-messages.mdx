يدعم zapbip أنواع الرسائل أدناه في الاتجاهين. أي نوع غير مذكور هنا غير مدعوم.

## ما يستقبله ذكاؤك الاصطناعي

| النوع      | ترسل                           | يستقبل ذكاؤك الاصطناعي                                             |
| ---------- | ------------------------------ | ------------------------------------------------------------------ |
| `text`     | رسالة                          | النص                                                               |
| `image`    | صورة                           | الصورة، يحفظها zapbip                                              |
| `video`    | فيديو                          | الفيديو، يحفظه zapbip                                              |
| `audio`    | ملف صوتي أو رسالة صوتية        | الصوت، يحفظه zapbip؛ وتصل الرسالة الصوتية مميزة كذلك               |
| `document` | ملف، مثل PDF                   | الملف، يحفظه zapbip مع اسمه ونوعه                                  |
| `sticker`  | ملصق                           | الملصق، يحفظه zapbip                                               |
| `location` | دبوس موقع                      | خط العرض وخط الطول والاسم والعنوان                                 |
| `contacts` | بطاقة اتصال واحدة أو أكثر      | بطاقات الاتصال                                                     |
| `reaction` | تفاعل بإيموجي                  | الإيموجي والرسالة التي تفاعلت معها؛ وإزالة التفاعل تصل بدون إيموجي |
| `choice`   | نقرة على زر أو على صف من قائمة | الاختيار، الذي يجيب عن السؤال                                      |

يصل الرد على رسالة من ذكائك الاصطناعي إلى الذكاء الاصطناعي الذي أرسل تلك الرسالة.

أي نوع آخر ترسله يتلقى إشعاراً قصيراً بأن هذا النوع غير مدعوم بعد، ولا يتلقى ذكاؤك الاصطناعي شيئاً. ينطبق الأمر نفسه على الطلب (order) أو على رد من WhatsApp Flow. النقر على زر فتح في إشعار zapbip يفتح فقط [نافذة الـ 24 ساعة](/ar/features/the-24-hour-window). تُتجاهل المكالمة أو أي حدث آخر في الحساب.

## ما يمكن لذكائك الاصطناعي إرساله

| النوع      | ما يمكن لذكائك الاصطناعي إرساله                                            |
| ---------- | -------------------------------------------------------------------------- |
| `text`     | رسالة نصية حتى 4,096 حرفاً                                                 |
| `image`    | صورة: JPEG أو PNG أو WebP، حتى 5 ميغابايت                                  |
| `video`    | فيديو: 3GP أو MP4، حتى 16 ميغابايت                                         |
| `audio`    | ملف صوتي: AAC أو AMR أو MP3 أو M4A أو OGG، حتى 16 ميغابايت؛ أو رسالة صوتية |
| `document` | ملف: PDF أو Word أو Excel أو PowerPoint أو نص عادي، حتى 100 ميغابايت       |
| `sticker`  | ملصق WebP ثابت، حتى 100 كيلوبايت                                           |
| `location` | دبوس موقع                                                                  |
| `contacts` | بطاقة اتصال واحدة أو أكثر                                                  |
| `reaction` | تفاعل بإيموجي على إحدى رسائلك، أو بدون إيموجي لإزالته                      |
| `choice`   | سؤال مع ما يصل إلى 3 أزرار، أو قائمة من 4 إلى 10 خيارات                    |

يرفض zapbip أي إرسال يتجاوز أحد هذه الحدود ويذكر الحقل الخاطئ. الاستطلاعات والطلبات والمدفوعات وWhatsApp Flows والمكالمات غير متاحة. لا يستطيع ذكاؤك الاصطناعي اختيار قالب واتساب؛ ويرسل zapbip إشعاره الخاص فقط عندما تكون نافذة الـ 24 ساعة مغلقة.

## الواجهة الرسمية WhatsApp Cloud فقط

يرسل zapbip ويستقبل فقط عبر واجهة WhatsApp Cloud الرسمية من Meta، على رقم zapbip. لا يدعم:

- عملاء ومكتبات واتساب غير الرسمية، مثل Baileys وwhatsapp-web.js وWPPConnect وEvolution API؛
- أتمتة WhatsApp Web، أو أي جسر يسجل الدخول بحساب شخصي أو برمز QR؛
- رقم واتساب الشخصي الخاص بك. يكتب كل ذكاء اصطناعي من رقم zapbip، وترد أنت على واتساب المعتاد لديك.

للإجابات القصيرة، راجع [الأسئلة الشائعة](/ar/help/faq).
