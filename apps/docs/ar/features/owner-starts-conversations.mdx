import { Chat } from '/snippets/chat.jsx';

لا تحتاج إلى انتظار أن يبدأ الذكاء الاصطناعي. أرسل رسالة إلى zapbip، فتصل إلى الذكاء الاصطناعي الذي سمّيته، أو إلى آخر من تحدّث.

<Chat
  messages={[
    { you: true, text: '@claude هل نجح البناء؟', time: '09:00' },
    { name: 'Claude', text: 'نعم، نجحت كل الاختبارات الـ 212.', time: '09:00' },
  ]}
/>

## كيف يسمعك الذكاء الاصطناعي لديك

لا يجيب الذكاء الاصطناعي إلا إذا أُوقظ. ويستخدم zapbip أفضل طريقة يسمح بها كل منها:

| نوع الإيقاظ           | ما الذي يحدث                                    | الانتظار المعتاد                              |
| --------------------- | ----------------------------------------------- | --------------------------------------------- |
| موصّل على حاسوبك      | تُستأنف الجلسة على حاسوبك فورًا.                | 7 ثوانٍ لـ Claude Code، و6 لـ Codex           |
| Webhook               | يستدعي zapbip رابط الذكاء الاصطناعي نفسه فيبدأ. | 9 ثوانٍ لـ Grok Bot، و16 لـ claude.ai         |
| مهمة مجدولة           | يفحص الذكاء الاصطناعي رسائلك بحسب مؤقّت.        | حتى فاصل مجدول واحد، وساعة لـ ChatGPT         |
| ذكاء اصطناعي آخر لديك | يجيب ذكاؤك الثاني نيابةً عنه.                   | بحسب ذلك الذكاء الاصطناعي، مثل Grok على الويب |
| صندوق الوارد فقط      | تنتظر رسالتك حتى يفحصها الذكاء الاصطناعي.       | حتى يفحص الذكاء الاصطناعي                     |

لا تضيع رسالتك. وإذا تعذّر إيقاظ هذا الذكاء الاصطناعي، تنتظر الرسالة في صندوق وارده.

## عندما لا يستمع الذكاء الاصطناعي لديك

يخبرك zapbip فورًا لتعرف أن الرسالة تنتظر.

<Chat
  messages={[
    { you: true, text: '@claude هل نجح البناء؟', time: '09:00' },
    {
      notice: true,
      text: 'الوكيل claude لا يستمع الآن. رسالتك تنتظر في صندوق الوارد.',
      time: '09:00',
    },
  ]}
/>

## عندما تُغلق نافذة الـ24 ساعة

لا يسمح WhatsApp لـ zapbip بمراسلتك بحرية إلا خلال 24 ساعة من رسالتك الأخيرة. وبعد إغلاق النافذة، يرسل zapbip إشعارًا واحدًا لكل نافذة مغلقة، ويحتفظ بالباقي. اكتب أي شيء فتُفتح النافذة من جديد. وينطبق الأمر نفسه على تنبيهات zapbip.

<Chat
  messages={[
    { you: true, text: '@claude هل نجح البناء؟', time: 'أمس 09:00' },
    { notice: true, text: 'لدى الوكيل claude رسالة لك: نعم، نجحت كل الاختبارات الـ 212.', time: '10:30' },
    { you: true, text: 'ok', time: '10:31' },
    { name: 'Claude', text: 'نعم، نجحت كل الاختبارات الـ 212.', time: '10:31' },
  ]}
/>
