---
title: 'تشغيل الموصّل كخدمة'
description: 'شغّل الموصّل عند إقلاع الجهاز بـ launchd أو systemd، دون طرفية.'
---

إذا أغلقت الطرفية يتوقف [الموصّل](/ar/developers/local-connector)، ولا يعود الذكاء الاصطناعي لديك يسمعك. ولإبقائه يعمل، دع حاسوبك يشغّله عنك. هذا اختياري، ولا يثبّته zapbip عنك: تنشئ الملفات بنفسك.

بعد إعادة التشغيل أو انقطاع الاتصال، يعيد الموصّل الاتصال ويجلب كل الرسائل التي لم يُجَب عنها.

يحمل هذا الملف رابط اتصالك، وهو يعادل كلمة مرور. اجعل صلاحياته `600` ليقرأه مستخدمك وحده، ولا تشاركه ولا ترفعه إلى commit.

استبدل `<path to npx>` بناتج `which npx`، و`<your folder>` بالمجلد الذي يعمل فيه الذكاء الاصطناعي لديك، و`<host>` و`<secret>` بالجزأين المقابلين من رابط اتصالك. وإذا كان الذكاء الاصطناعي لديك Codex، فاستخدم `codex` بدل `claude-code`.

## macOS (launchd)

أنشئ الملف أولًا بالصلاحيات الصحيحة، ثم املأه:

```bash
install -m 600 /dev/null ~/Library/LaunchAgents/com.zapbip.connector.plist
```

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <key>Label</key>
    <string>com.zapbip.connector</string>
    <key>ProgramArguments</key>
    <array>
      <string><path to npx></string>
      <string>zapbip</string>
      <string>connect</string>
      <string>--client</string>
      <string>claude-code</string>
    </array>
    <key>WorkingDirectory</key>
    <string><your folder></string>
    <key>EnvironmentVariables</key>
    <dict>
      <key>ZAPBIP_CONNECTION_URL</key>
      <string>https://<host>/c/<secret>/mcp</string>
      <key>PATH</key>
      <string>/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin</string>
    </dict>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
  </dict>
</plist>
```

يجب أن يضم `PATH` المجلد الذي ثُبّت فيه `claude` أو `codex`.

شغّله، ثم أوقفه لاحقًا:

```bash
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.zapbip.connector.plist
launchctl bootout gui/$(id -u)/com.zapbip.connector
```

## Linux (systemd)

احفظ الرابط في ملف منفصل بصلاحيات `600`:

```bash
mkdir -p ~/.config/zapbip ~/.config/systemd/user
install -m 600 /dev/null ~/.config/zapbip/connector.env
```

اكتب في `~/.config/zapbip/connector.env` سطرًا واحدًا:

```text
ZAPBIP_CONNECTION_URL=https://<host>/c/<secret>/mcp
```

أنشئ `~/.config/systemd/user/zapbip-connector.service`:

```ini
[Unit]
Description=zapbip connector
After=network-online.target

[Service]
EnvironmentFile=%h/.config/zapbip/connector.env
Environment=PATH=%h/.local/bin:/usr/local/bin:/usr/bin:/bin
WorkingDirectory=<your folder>
ExecStart=<path to npx> zapbip connect --client claude-code
Restart=always
RestartSec=5

[Install]
WantedBy=default.target
```

شغّله، واجعله يعمل حتى وأنت غير مسجّل الدخول:

```bash
systemctl --user daemon-reload
systemctl --user enable --now zapbip-connector
loginctl enable-linger $USER
```

اطّلع على سجلاته بـ `journalctl --user -u zapbip-connector`. لا تحتوي السجلات نص الرسائل ولا الرابط.

## الرابط المُبطَل

إذا أُبطل الرابط، يخرج الموصّل بخطأ وتواصل الخدمة إعادة تشغيله. أوقف الخدمة، واكتب الرابط الجديد في الملف، ثم شغّلها من جديد.
