أرسل رسالة نصية إلى المالك.

## المدخلات

| الحقل      | النوع           | الوصف                                                   |
| ---------- | --------------- | ------------------------------------------------------- |
| `text`     | string          | حتى 4096 حرفًا. يُحفظ تنسيق WhatsApp والرموز التعبيرية. |
| `reply_to` | string، اختياري | معرّف الرسالة المراد اقتباسها.                          |

## المخرجات

`{ "message_id": string, "delivery": "sent" | "queued" }`. ويعني `queued` أن [نافذة الـ24 ساعة](/ar/concepts/24-hour-window) مغلقة.
