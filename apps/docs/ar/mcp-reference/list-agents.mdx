description: 'اعرض الوكلاء المربوطين بهذا الحساب.'
---

يعرض الوكلاء المربوطين بهذا الحساب، ليرى الوكيل من هو متصل قبل أن يغيّر أي شيء. للقراءة فقط: لا يحتاج إلى موافقة ولا يُحتسب ضمن أي حد. راجع [دع الذكاء الاصطناعي لديك يدير zapbip](/ar/features/let-your-ai-manage-zapbip).

## المدخلات

لا شيء.

## المخرجات

`{ "agents": [{ "name": string, "client": string | null, "created_at": string, "last_active_at": string | null }] }`. الطوابع الزمنية بصيغة ISO 8601. و`client` هو التطبيق الذي يتصل منه الوكيل، وتكون له قيمة بعد الاتصال. ولا يظهر في القائمة أي سرّ أو بصمة أو رابط.
