يحفظ كيف يُوقَظ هذا الاتصال عندما تكتب ولا يكون أي استدعاء ينتظر. راجع [سلّم الإيقاظ](/ar/concepts/wake-ladder) و[دليل إيقاظ webhook](/ar/developers/webhook-wake).

## المدخلات

| الحقل              | النوع            | الوصف                                                                                                                                                                                           |
| ------------------ | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mode`             | string           | `local` يوقظ عبر [الموصّل](/ar/developers/local-connector)؛ `webhook` يحفظ webhook؛ `scheduled` يجعل الوكيل يفحص صندوق الوارد بمؤقّت؛ `standby` يسلّم رسائلك إلى وكيل آخر؛ `none` يمسح الإيقاظ. |
| `url`              | string، اختياري  | مطلوب مع `webhook`. `https` دون userinfo ودون جزء، والمنفذ 443 أو محذوف، حتى 512 حرفًا. ويحدد مضيفه المزوّد.                                                                                    |
| `token`            | string، اختياري  | مطلوب مع `webhook`. أحرف قابلة للطباعة دون مسافات، من 16 إلى 512 حرفًا. وهو لـ webhook العام مفتاح التوقيع، 32 حرفًا على الأقل.                                                                 |
| `interval_minutes` | integer، اختياري | مطلوب مع `scheduled`. من 1 إلى 1440 دقيقة. ويشغّل ChatGPT وclaude.ai المهام المجدولة كل 60 دقيقة على الأقل.                                                                                     |
| `standby_agent`    | string، اختياري  | مطلوب مع `standby`. اسم اتصال آخر في الحساب نفسه، وليس هو نفسه احتياطيًا.                                                                                                                       |

يجب حذف حقول الأوضاع الأخرى.

## مجدول

الوكيل الذي لا يمكن تشغيله من الخارج يشغّل مهمة بمؤقّت تستدعي [check_inbox](/ar/mcp-reference/check-inbox). فيستطيع الاستماع دون حد زمني والرد على كل رسالة بـ `send_message`.

```json
{ "mode": "scheduled", "interval_minutes": 60 }
```

وعندما تكتب، يخبرك zapbip متى ستصلك الإجابة. وإذا مضى ضعف الفاصل دون فحص، تصلك رسالة تنبيه وتنتظر رسائلك في صندوق الوارد حتى الفحص التالي.

## محلي

بينما يعمل [الموصّل](/ar/developers/local-connector) على حاسوبك، دع وكيلك يستدعي هذه الأداة بـ `{ "mode": "local" }`.

## احتياطي

الوكيل الذي لا يمكن إيقاظه يعيّن وكيلًا آخر من الحساب نفسه ليجيب نيابةً عنه. ينسخ zapbip رسائلك إلى الوكيل الاحتياطي ويوقظه؛ ويجيب الوكيل الاحتياطي بصفته هو.

```json
{ "mode": "standby", "standby_agent": "grok-bot" }
```

لا يُحوَّل اتصال احتياطي أبدًا إلى اتصال احتياطي آخر: قفزة واحدة فقط. وإذا لم يوجد الاتصال الاحتياطي، أو أُزيل، أو كان هو نفسه في وضع احتياطي، فلا يُنسخ شيء وتنتظر رسائلك عند الوكيل الأول.

## المزوّدون

يحدد مضيف الرابط المزوّد، ولا يحدده حقل أبدًا.

| المزوّد          | المضيف              | المسار                                       | المصادقة                                                    |
| ---------------- | ------------------- | -------------------------------------------- | ----------------------------------------------------------- |
| `grok_routine`   | `api2.cursor.sh`    | `/automations/webhook/<routine-id>`          | `Authorization: Bearer <token>`                             |
| `claude_routine` | `api.anthropic.com` | `/v1/claude_code/routines/<trigger-id>/fire` | `Authorization: Bearer <token>`                             |
| `generic`        | أي مضيف `https` عام | أي مسار                                      | `X-Zapbip-Timestamp` و`X-Zapbip-Signature`، دون إرسال السرّ |

## المخرجات

`{ "status": "saved", "wake_mode": string, "effective_rung": string, "provider": string | null }`. ويُضبط `provider` مع `webhook` فقط. وعندما لا يتوفر الوكيل الاحتياطي، ومع `local` بينما لا يتصل أي موصّل، يكون `effective_rung` هو `inbox`، لأن الرسائل تنتظر في صندوق الوارد. ولا تُعاد أبدًا عناوين URL ولا الرموز ولا المضيفات.

## الأخطاء

يسمّي خطأ الأداة الحقل غير الصالح (`url` أو `token` أو `interval_minutes` أو `standby_agent` أو `mode`) وحدّه، ولا يردد قيمته أبدًا. ولا يُخزَّن شيء ويبقى إعداد الإيقاظ السابق كما هو. ولا يستدعي zapbip المزوّد عند الحفظ: فالرمز الخاطئ يظهر عند أول إيقاظ، في صورة رسالة تنبيه إليك على WhatsApp.
