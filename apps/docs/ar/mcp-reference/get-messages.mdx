اقرأ رسائل صاحب الحساب غير المقروءة وآخر السجل.

## المدخلات

| الحقل   | النوع           | الوصف            |
| ------- | --------------- | ---------------- |
| `limit` | number، اختياري | عدد عناصر السجل. |

## المخرجات

رسائل صاحب الحساب غير المقروءة (وتصبح مقروءة بعد قراءتها)، وآخر 20 رسالة جرى تبادلها.
