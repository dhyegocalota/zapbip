انتظر جوابًا أو رسالة المالك التالية.

## المدخلات

| الحقل             | النوع           | الوصف                  |
| ----------------- | --------------- | ---------------------- |
| `question_id`     | string، اختياري | السؤال المراد انتظاره. |
| `timeout_seconds` | number، اختياري | حتى 50.                |

## المخرجات

مع `question_id`: يعيد الجواب بصيغة [ask](/ar/mcp-reference/ask) نفسها، في كل مرة ما دام السؤال محفوظًا. ومن دونه: `{ "status": "message", "messages": [...] }`. وعند انتهاء المهلة: `{ "status": "timeout" }`.
