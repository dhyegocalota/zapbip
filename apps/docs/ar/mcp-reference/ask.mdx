اسأل المالك بأزرار أو قائمة وانتظر الجواب.

## المدخلات

| الحقل             | النوع                    | الوصف                                                                                          |
| ----------------- | ------------------------ | ---------------------------------------------------------------------------------------------- |
| `question`        | string                   | حتى 1024 حرفًا.                                                                                |
| `options`         | مصفوفة من 1 إلى 10 عناصر | حتى 3 خيارات تظهر أزرارًا (العنوان حتى 20 حرفًا)، ومن 4 إلى 10 تظهر قائمة (الصف حتى 24 حرفًا). |
| `timeout_seconds` | number، اختياري          | حتى 50.                                                                                        |

## المخرجات

`{ "status": "answered", "answer": ..., "message_id": string }` عندما يجيب المالك في الوقت المناسب؛ و`{ "status": "pending", "question_id": string }` عندما ينتهي الانتظار أولًا. مرّر `question_id` إلى [wait_for_reply](/ar/mcp-reference/wait-for-reply).

تكرار السؤال نفسه خلال 4 دقائق يعيد السؤال نفسه ولا يرسل أي شيء. راجع [الأسئلة](/ar/concepts/questions).
