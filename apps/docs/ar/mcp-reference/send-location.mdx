## المدخلات

| الحقل       | النوع           | الوصف                          |
| ----------- | --------------- | ------------------------------ |
| `latitude`  | number          |                                |
| `longitude` | number          |                                |
| `name`      | string، اختياري |                                |
| `address`   | string، اختياري |                                |
| `reply_to`  | string، اختياري | معرّف الرسالة المراد اقتباسها. |

## المخرجات
