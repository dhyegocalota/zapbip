## ما الذي يعمل

| ما تستطيعه                                       | Gemini CLI                 |
| ------------------------------------------------ | -------------------------- |
| استقبال النصوص والصور والفيديو والصوت والمستندات | نعم                        |
| استقبال المواقع وجهات الاتصال والتفاعلات         | نعم                        |
| سؤالك بأزرار أو قوائم وانتظار جوابك              | نعم                        |
| بدء محادثة عندما تراسله أولًا                    | نعم، ما دامت الجلسة مفتوحة |

## كيف يستمع

نوع الإيقاظ: محلي. يشغّل Gemini CLI مستمع zapbip في الطرفية الخلفية ويُبقيه قيد التشغيل. وعندما تكتب على WhatsApp يظهر هناك سطر جديد ويوقظ الجلسة. أبقِ تلك الطرفية مفتوحة: ليس في Gemini CLI خيار جدولة.

```bash
npx zapbip@0.1.0 listen
```

عندما يكون هناك سؤال معلّق، ينتظر Gemini CLI 50 ثانية على الأكثر في كل مرة. وإذا لم تجب بعد، ينتهي هذا الانتظار بحالة «قيد الانتظار» (pending)، فيستدعي Gemini CLI مرة أخرى، بقدر ما يلزم، دون حد زمني.

شغّل مستمعًا واحدًا فقط في كل مرة. المستمع الثاني يحل محل الأول.

## الإعداد من الصفر

1. **راسل رقم zapbip على WhatsApp.** أرسل `وكيل جديد gemini-cli`. يعرض لك [دليل البدء](/ar/get-started/how-to-start) كل رسالة.

   <Chat
     messages={[
       { you: true, text: 'وكيل جديد gemini-cli', time: '09:00' },
       { name: 'zapbip', text: 'تم إنشاء الوكيل gemini-cli. الصق هذا في وكيلك.', time: '09:00' },
     ]}
   />

2. **الصق السطر في Gemini CLI.** يردّ zapbip بسطر مولَّد لك وحدك:

   <InstallPrompt />

3. **وافق على كل تغيير.** يخبرك Gemini CLI بالإعداد الذي سيغيّره وينتظر موافقتك. أبقِ الرابط بعيدًا عن المحادثات التي تشاركها.

4. **أضف zapbip إلى Gemini CLI.** بعد موافقتك ينفّذ `gemini mcp add --transport http --scope user zapbip <connectionLink>`.

5. **ابدأ الاستماع.** ينفّذ في الطرفية الخلفية `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 listen` ويُبقي هذه الطرفية قيد التشغيل بلا حد زمني. وكلما ظهر سطر جديد هناك يستدعي `check_inbox` ويجيب.

6. **اختبره.** في عملية جديدة ينفّذ `gemini -p "Call send_message with the text '✅ تم التثبيت'"`. تصل إلى WhatsApp رسالة `send_message` بالنص ✅ تم التثبيت. إذا فشل الأمر، يتوقف ويعرض آخر 20 سطرًا. ثم أعد تشغيل Gemini CLI.

## تحقق من أنه يعمل

اطلب من Gemini CLI أن يرسل `✅ تم التثبيت` على WhatsApp. إذا وصلت الرسالة فالاتصال سليم.

<Chat messages={[{ name: 'Gemini CLI', text: '✅ تم التثبيت', time: '09:03' }]} />

إذا لم تصل، فأعد تشغيل Gemini CLI وحاول مرة أخرى.
