---
title: 'قناة WhatsApp'
description: 'كيف تنتقل الرسائل بين صاحب الحساب والوكلاء، والحدود التي يفرضها WhatsApp.'
---

يتحدث zapbip مع صاحب الحساب عبر واجهة WhatsApp Cloud API الرسمية، برقم واحد تتشاركه كل الحسابات.

## الرسائل الواردة

يراسل صاحب الحساب الرقم. يتحقق zapbip من توقيع كل إشعار، ويحفظ كل رسالة مرة واحدة حتى لو سلّمها WhatsApp مرتين، ويوجّهها إلى وكيل واحد وفق [قواعد التوجيه](/ar/concepts/routing).

| ما يرسله صاحب الحساب                           | ما يتلقاه الوكيل                                                                            |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------- |
| نص، صورة، فيديو، صوت، رسالة صوتية، مستند، ملصق | الرسالة نفسها، مع حفظ zapbip للوسائط                                                        |
| موقع، بطاقة جهة اتصال                          | الرسالة نفسها                                                                               |
| رد بزر أو بصف من قائمة                         | الاختيار، ويجيب عن السؤال المقابل                                                           |
| تفاعل                                          | ذلك التفاعل، موجَّهًا إلى الوكيل الذي أرسل الرسالة المتفاعَل معها؛ وسحب التفاعل يصل دون رمز |
| أي نوع آخر من الرسائل                          | لا شيء؛ ويُخبَر صاحب الحساب أن هذا النوع غير مدعوم بعد                                      |

تفتح رسالة صاحب الحساب [نافذة الـ24 ساعة](/ar/concepts/24-hour-window). أما التفاعل فلا يفتحها.

إذا تعذّر تنزيل ملف، تصل الرسالة إلى الوكيل مع `media_id: null` و`media_status: "unavailable"`، ويُطلب من صاحب الحساب إعادة الإرسال.

## الرسائل الصادرة

داخل النافذة تُرسل كل الأنواع فورًا. وخارجها تنتظر الرسالة في طابور، ويتلقى صاحب الحساب [إشعارًا](/ar/concepts/owner-notices).

| النوع | الحد                                                                                                       |
| ----- | ---------------------------------------------------------------------------------------------------------- |
| نص    | 4,096 حرفًا                                                                                                |
| أزرار | حتى 3 أزرار، والسؤال حتى 1,024 حرفًا، والعنوان حتى 20 حرفًا                                                |
| قائمة | حتى 10 صفوف، والسؤال حتى 1,024 حرفًا، والزر حتى 20 حرفًا، وعنوان الصف حتى 24 حرفًا، ووصف الصف حتى 72 حرفًا |
| تفاعل | يجب ألا يتجاوز عمر الرسالة المتفاعَل معها 30 يومًا، وأن تكون في المحادثة نفسها وغير محذوفة                 |
| صورة  | JPEG أو PNG أو WebP، حتى 5 MB                                                                              |
| فيديو | 3GP أو MP4، حتى 16 MB                                                                                      |
| صوت   | AAC أو AMR أو MP3 أو M4A أو OGG، حتى 16 MB                                                                 |
| مستند | PDF أو Word أو Excel أو PowerPoint أو نص عادي، حتى 100 MB                                                  |
| ملصق  | WebP ثابت، حتى 100 KB                                                                                      |

يرفض zapbip الإرسال الذي يخالف الحدود، وتعيد الأداة خطأ يسمّي الحقل.

## حالة التسليم

لا يتقدم `delivery` في الرسالة إلا إلى الأمام: `sent` ثم `delivered` ثم `read`. والإرسال الذي يرفضه WhatsApp يصبح `failed`. أما الرسالة التي صارت `delivered` أو `read` فلا تعود `failed`.

## الأرقام المقيّدة

عندما يبلّغ WhatsApp أن الرقم مقيّد أو أن الحساب مُعطَّل، يوقف zapbip الإرسال 24 ساعة وينبّه المشغّلين. وتعيد الرسائل المرسلة خلال ذلك `delivery: "failed"`.
