import { Chat } from '/snippets/chat.jsx';

لا يسمح WhatsApp لـ zapbip بإرسال رسائل حرة إلا خلال 24 ساعة من آخر رسالة لصاحب الحساب. ويغلق zapbip نافذته من جانبه قبل 10 دقائق. وتفاعلات صاحب الحساب لا تفتح النافذة.

## النافذة مفتوحة

تُرسل الرسائل فورًا، وتعيد الأداة `delivery: "sent"`.

<Chat
  messages={[
    { you: true, text: 'أخبرني عندما تنتهي مهمة الليل.', time: '22:10' },
    { name: 'Claude Code', text: 'انتهت مهمة الليل ✅', time: '23:31' },
  ]}
/>

## النافذة مغلقة

- تعيد الأداة `delivery: "queued"` وتنتظر الرسالة في طابور الإرسال؛
- تُرسل أول رسالة منتظرة إلى صاحب الحساب إشعارًا واحدًا يذكر اسم الذكاء الاصطناعي ومعاينة قصيرة، مرة واحدة لكل نافذة مغلقة؛
- تفتح رسالة صاحب الحساب التالية النافذة وتُفرّغ الطابور بالترتيب؛
- تصبح الرسائل التي مضى على انتظارها أكثر من 7 أيام `expired`.

<Chat
  messages={[
    { you: true, text: 'أخبرني عندما تنتهي مهمة الليل.', time: 'أمس 22:10' },
    { notice: true, text: 'لدى الوكيل claude-code رسالة لك: انتهت مهمة الليل ✅', time: '23:31' },
    { you: true, text: 'ok', time: '08:05' },
    { name: 'Claude Code', text: 'انتهت مهمة الليل ✅', time: '08:05' },
  ]}
/>

يُحفظ الإرسال الذي ترفضه القناة بـ `delivery: "failed"`، وتعيد الأداة خطأ يسمّي نوع الرسالة.
