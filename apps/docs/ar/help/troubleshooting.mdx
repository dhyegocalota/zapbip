## رسائل الذكاء الاصطناعي لديّ لا تصل

على الأرجح أن [نافذة الـ24 ساعة](/ar/concepts/24-hour-window) أُغلقت. أرسل أي رسالة إلى رقم zapbip، فتصل الرسائل المنتظرة بالترتيب.

<Chat
  messages={[
    { notice: true, text: 'لدى الوكيل claude-code رسالة لك: اكتمل الترحيل ✅', time: '07:12' },
    { you: true, text: 'ok', time: '07:30' },
    { name: 'Claude Code', text: 'اكتمل الترحيل ✅', time: '07:30' },
    { name: 'Grok', text: 'وجدت 3 مصادر.', time: '07:30' },
  ]}
/>

## راسلته لكن الذكاء الاصطناعي لديّ لا يجيب

الذكاء الاصطناعي لديك لا يستمع. رسالتك تنتظره، ويخبرك zapbip أن هذا الذكاء الاصطناعي لا يستمع حاليًا.

<Chat
  messages={[
    { you: true, text: '@claude هل نجح البناء؟', time: '14:20' },
    { notice: true, text: 'الوكيل claude لا يستمع الآن. رسالتك تنتظر في صندوق الوارد.', time: '14:20' },
  ]}
/>

افتح هذا الذكاء الاصطناعي واطلب منه أن يفحص الرسائل، وتعرّف على كيفية إبقاء كل منها مستمعًا في [الوكلاء المدعومين](/ar/agents/supported-agents).

## رسالتي ذهبت إلى الذكاء الاصطناعي الخطأ

ابدأ بـ `@الاسم`، مثل `@grok check the news`، أو ردّ مباشرةً على رسالة ذلك الذكاء الاصطناعي.

<Chat
  messages={[
    { name: 'Grok', text: 'وجدت 3 مصادر.', time: '11:05' },
    { you: true, text: '@grok check the news', time: '11:06' },
    { you: true, quote: { name: 'Grok', text: 'وجدت 3 مصادر.' }, text: 'أيّها؟', time: '11:07' },
  ]}
/>

راجع [عدة وكلاء على رقم واحد](/ar/features/many-agents-on-one-number).

## راسلته ولم يعد إليّ شيء

ربما يكون حسابك في قائمة الانتظار. يُحفظ حتى يفعّله فريق zapbip. انتظر، وعندما يُفعَّل وصولك أرسل `help`.

## الرابط الذي في الموجّه لا يعمل

الرابط يعمل مرة واحدة ويصلح 30 دقيقة. أرسل `تجديد رابط` متبوعًا باسم الذكاء الاصطناعي، مثل `تجديد رابط claude`، لتحصل على موجّه جديد. راجع [إبطال الروابط وتجديدها](/ar/help/revoke-and-rotate-keys).

## رفض zapbip اسم الذكاء الاصطناعي لديّ

يتكوّن الاسم من 1 إلى 20 حرفًا لاتينيًا صغيرًا أو رقمًا أو شرطة، ويبدأ بحرف أو رقم، ولا يجوز أن يبدأ بكلمة أمر. أرسل `وكيل جديد` مع اسم آخر.

## قال zapbip إنني بلغت الحد الأقصى

يمكنك ربط 8 وكلاء على الأكثر. أرسل `إبطال` متبوعًا باسم وكيل لم تعد تستخدمه لتحرير مكان.

## أسئلة أخرى

الأخطاء التقنية، مثل رفض الاتصال أو فشل الرفع، مدرجة في قسم «للمطورين».
