import { Chat } from '/snippets/chat.jsx';

لكل ذكاء اصطناعي اتصاله الخاص. تقطعه أو تستبدل رابطه بمراسلة رقم zapbip. يمكن كتابة الأوامر بكلمات العربية أو الإنجليزية أو البرتغالية، وتستخدم هذه الصفحة كلمات العربية. وتعمل بالإنجليزية أيضًا: `revoke claude` و`rotate claude`.

## اقطع ذكاءً اصطناعيًا

أرسل `إبطال` متبوعًا باسم هذا الذكاء الاصطناعي، مثل `إبطال claude`. تتوقف فورًا كل طرق اتصاله: رابطه إلى zapbip، والمستمع الذي يعمل على حاسوبك، وأي إيقاظ يشغّله.

<Chat
  messages={[
    { you: true, text: 'إبطال claude', time: '16:02' },
    { text: 'تم إبطال الوكيل claude. لم يعد رابطه يعمل.', time: '16:02' },
  ]}
/>

ولاستخدام هذا الذكاء الاصطناعي من جديد، أرسل `وكيل جديد claude`.

## استبدل الرابط

أرسل `تجديد رابط` متبوعًا بالاسم، مثل `تجديد رابط claude`. يتوقف الاتصال القديم فورًا، بالنطاق نفسه الذي يتوقف به عند `إبطال`، ويرسل لك zapbip موجّهًا جديدًا تلصقه في ذلك الذكاء الاصطناعي.

<Chat
  messages={[
    { you: true, text: 'تجديد رابط claude', time: '16:05' },
    {
      text: 'تم استبدال رابط الوكيل claude. الرابط القديم لم يعد يعمل. الصق هذا في وكيلك: ...',
      time: '16:05',
    },
  ]}
/>

يُرسَل الرابط المستبدَل مرة واحدة فقط. ولا يعرضه zapbip مرة أخرى: فالأمر `agents` يسرد أنظمتك دون أي رابط. وإذا لم يصل الموجّه الجديد، يُبقي zapbip الاتصال القديم ويمكنك إرسال `تجديد رابط claude` مرة أخرى.

## متى تستخدم أيًّا منهما

- فقدت ذكاءً اصطناعيًا، أو لم تعد تستخدمه، أو شاركت رابطه عن غير قصد: `إبطال`.
- انتهت صلاحية الرابط أو سبق استخدامه أو تسرّب، وما زلت تريد الاستمرار مع هذا الذكاء الاصطناعي: `تجديد`.

وجميع كلمات الأوامر في [أوامر WhatsApp](/ar/features/whatsapp-commands).
