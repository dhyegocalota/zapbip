import { Chat } from '/snippets/chat.jsx';

Chaque IA a sa propre connexion. Vous la coupez, ou vous remplacez son lien, en écrivant au numéro de zapbip. Les commandes sont en français ; il comprend aussi les mêmes commandes en anglais.

## Couper une IA

Écrivez `révoquer` et le nom de l'IA, par exemple `révoquer claude`. Toutes les façons dont cette IA est connectée s'arrêtent aussitôt : son lien vers zapbip, un listener qui tourne sur votre ordinateur et tout réveil qui la démarrerait.

<Chat
  messages={[
    { you: true, text: 'révoquer claude', time: '16:02' },
    { text: 'Agent claude révoqué. Son lien ne fonctionne plus.', time: '16:02' },
  ]}
/>

Pour réutiliser cette IA, écrivez `nouvel agent claude`.

## Remplacer un lien

Écrivez `renouveler` et le nom, par exemple `renouveler claude`. L'ancienne connexion cesse de fonctionner aussitôt, avec la même portée que `révoquer`, et zapbip vous envoie un nouveau prompt à coller dans cette IA.

<Chat
  messages={[
    { you: true, text: 'renouveler claude', time: '16:05' },
    {
      text: 'Lien de l’agent claude remplacé. L’ancien lien ne fonctionne plus. Collez ceci dans votre agent : ...',
      time: '16:05',
    },
  ]}
/>

Un lien renouvelé n'est envoyé qu'une fois. zapbip ne l'affiche jamais de nouveau : `agents` liste vos IA sans aucun lien. Si le nouveau prompt n'arrive pas, zapbip conserve l'ancienne connexion, et vous pouvez écrire `renouveler claude` de nouveau.

## Lequel utiliser

- Vous avez perdu une IA, vous ne l'utilisez plus ou vous avez partagé son lien par erreur : `révoquer`.
- Le lien a expiré, a déjà été utilisé ou a fuité, et vous voulez garder l'IA : `renouveler`.

Retrouvez chaque mot dans [commandes sur WhatsApp](/fr/features/whatsapp-commands).
