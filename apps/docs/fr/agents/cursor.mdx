## Comment elle écoute

Type de réveil : **Local**. Cursor exécute `npx zapbip@0.2.0 listen` dans un terminal en arrière-plan et le garde en marche. Quand vous écrivez sur WhatsApp, une nouvelle ligne apparaît dans ce terminal et réveille le chat.

- Cursor n'a pas d'option planifiée, gardez donc ce terminal en marche.

Quand votre IA vous demande quelque chose, zapbip garde la question et répond « en attente » au plus toutes les 50 secondes. Cursor rappelle alors, et continue de rappeler à nouveau jusqu'à ce que vous répondiez, sans limite de temps.

## Configurer de zéro

1. **Écrivez au numéro de zapbip sur WhatsApp.** Envoyez n'importe quel texte, par exemple `hi`.

   <StartLink />

2. **Demandez un nouvel agent.** Un agent est une IA que vous connectez.

   <Chat
     messages={[
       { you: true, text: 'nouvel agent cursor', time: '14:00' },
       {
         name: 'zapbip',
         text: 'Agent cursor created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate cursor".',
         time: '14:00',
       },
     ]}
   />

   Les commandes et les réponses de zapbip sont en français ; il comprend aussi les mêmes commandes en anglais.

3. **Collez la ligne dans le chat Cursor.**

   <InstallPrompt />

   Cursor lit les instructions et les suit dans l'ordre. Avant de modifier un réglage, il vous dit lequel et attend votre accord. Le lien est secret : ne le laissez pas dans des conversations que vous partagez.

4. **Dites oui.** Cursor fait alors le reste, dans cet ordre.

5. **Ajoutez zapbip à Cursor.** Il vous demande d'abord et attend votre accord. Puis il ajoute un serveur MCP nommé `zapbip` via HTTP à `<connectionLink>` dans les réglages MCP de Cursor.

6. **Commencez à écouter.** Il exécute `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.2.0 listen` dans un terminal en arrière-plan et garde ce terminal en marche, sans limite de temps. Chaque fois qu'une nouvelle ligne y apparaît, il appelle `check_inbox` et répond.

7. **Testez.** Dans le chat, il appelle `send_message` avec ✅ installé. Redémarrez ensuite le chat Cursor pour utiliser les outils zapbip.

## Vérifier que ça marche

Demandez à Cursor d'envoyer `✅ installé` à votre WhatsApp. Il devrait arriver en quelques secondes.
