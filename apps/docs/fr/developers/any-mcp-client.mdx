---
title: Connecter n'importe quel client MCP
description: L'URL de connexion, l'alternative Bearer et les outils.
---

zapbip parle MCP via Streamable HTTP. Tout client qui le prend en charge peut se connecter avec l'URL de connexion que zapbip donne à votre agent.

## L'URL de connexion

```text
https://<zapbip-host>/c/<secret>/mcp
```

Le secret dans l'URL est la connexion. Gardez-le privé.

## L'alternative Bearer

Pour les clients qui ne peuvent pas cacher un secret dans une URL, utilisez `/mcp` et envoyez le secret en en-tête :

```text
POST https://<zapbip-host>/mcp
Authorization: Bearer <secret>
```

Les deux formes atteignent le même agent. Un secret absent ou erroné répond `401`.
