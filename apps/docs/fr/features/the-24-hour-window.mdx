import { Chat } from '/snippets/chat.jsx';

WhatsApp ne laisse zapbip vous écrire librement que dans les 24 heures qui suivent votre dernier message.

## Fenêtre ouverte

Les messages de votre IA arrivent aussitôt.

<Chat
  messages={[
    { you: true, text: 'Préviens-moi quand le job de nuit sera terminé.', time: '22:10' },
    { name: 'Claude Code', text: 'Job de nuit terminé ✅', time: '23:31' },
  ]}
/>

## Fenêtre fermée

Vous recevez une notification indiquant le nom de l'IA et un court aperçu de son message. Écrivez n'importe quoi et ils arrivent, dans l'ordre. Les messages de plus de 7 jours expirent. Les notifications de zapbip sont en anglais, la langue du produit aujourd'hui.

<Chat
  messages={[
    { you: true, text: 'Préviens-moi quand le job de nuit sera terminé.', time: 'Hier 22:10' },
    { notice: true, text: 'The agent claude-code has a message for you: Nightly job finished ✅', time: '23:31' },
    { you: true, text: 'ok', time: '08:05' },
    { name: 'Claude Code', text: 'Job de nuit terminé ✅', time: '08:05' },
  ]}
/>
