import { Chat } from '/snippets/chat.jsx';

Votre IA peut vous envoyer tout ce que WhatsApp peut transporter.

## À quoi ça ressemble

<Chat
  messages={[
    { you: true, text: 'Envoie-moi la capture d’écran du build terminé avec la légende « Build terminé ».', time: '16:40' },
    { name: 'Claude Code', media: { kind: 'image' }, text: 'Build terminé', time: '16:41' },
    { you: true, reaction: '👍', text: 'Parfait, merci.', time: '16:41' },
  ]}
/>

Les autres types arrivent de la même façon.

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'video', label: 'Enregistrement de la démo' }, time: '16:42' },
    { name: 'Claude Code', media: { kind: 'voice', label: '0:24' }, time: '16:42' },
    { name: 'Claude Code', media: { kind: 'document', label: 'release-notes.pdf' }, text: 'Notes de version', time: '16:43' },
  ]}
/>

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'sticker' }, time: '16:43' },
    { name: 'Claude Code', media: { kind: 'location', label: 'Café Brasileira, Chiado' }, time: '16:44' },
    { name: 'Claude Code', media: { kind: 'contact', label: 'Marta Souza', action: 'Message' }, time: '16:44' },
  ]}
/>

## Ce qu'elle peut envoyer

| Ce que vous voyez sur votre téléphone                  | Type       |
| ------------------------------------------------------ | ---------- |
| Un texte, avec la mise en forme WhatsApp et des emojis | `text`     |
| Une photo                                              | `image`    |
| Une vidéo                                              | `video`    |
| Un fichier audio ou un message vocal                   | `audio`    |
| Un fichier, comme un PDF                               | `document` |
| Un sticker                                             | `sticker`  |
| Une épingle sur la carte                               | `location` |
| Une ou plusieurs cartes de contact                     | `contacts` |
| Une réaction par emoji à l'un de vos messages          | `reaction` |
| Des boutons ou une liste à toucher                     | `choice`   |

N'importe lequel peut citer l'un de vos messages. Quand vous envoyez une photo ou un fichier à votre IA, elle le reçoit aussi.
