Vous gérez vos IA en écrivant au numéro de zapbip. Une commande est une courte phrase, en français ou en anglais ; le portugais, l’espagnol, l’allemand, le japonais, le coréen et le chinois ont les leurs. La langue dans laquelle vous écrivez est la langue de la réponse. Chaque ligne montre les deux versions.

| Vous voulez                        | Écrire en français                                               | Ou en anglais                                       | Ce qui se passe                                                                                          |
| ---------------------------------- | ---------------------------------------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Connecter une nouvelle IA          | `nouvel agent claude`                                            | `new agent claude`                                  | zapbip répond avec le prompt à coller dans cette IA                                                      |
| Voir vos IA                        | `mes agents`                                                     | `agents`                                            | Une liste avec le nom et la date de chacune                                                              |
| Déconnecter une IA                 | `révoquer claude`                                                | `revoke claude`                                     | Cette IA cesse de fonctionner aussitôt                                                                   |
| Obtenir un nouveau prompt          | `renouveler claude`                                              | `rotate claude`                                     | L'ancienne connexion s'arrête et vous recevez un nouveau prompt                                          |
| Vous connecter à l'application web | `connexion`                                                      | `login`                                             | Un lien qui ne fonctionne qu'une fois pendant 10 minutes, voir [l'application web](/fr/features/web-app) |
| Ouvrir le menu                     | `aide` ou `menu`                                                 | `help` ou `menu`                                    | Les commandes sous forme de texte et de liste à toucher                                                  |
| Changer de langue                  | `langue ja`                                                      | `language ja`                                       | zapbip vous répond dans la langue choisie. Codes : `en`, `pt`, `es`, `de`, `fr`, `ja`, `ko`, `zh`        |
| Supprimer votre compte             | `supprimer le compte`, puis `supprimer le compte définitivement` | `delete account`, puis `delete account permanently` | Voir [supprimer votre compte](/fr/help/delete-your-account)                                              |

Écrivez la phrase seule. Un `?` ou un `!` à la fin en fait un message normal pour vos IA.

## Exemple

Les réponses de zapbip sont en français parce que vous avez écrit en français.

    { you: true, text: 'révoquer claude', time: '09:21' },
    { text: 'Agent claude révoqué. Son lien ne fonctionne plus.', time: '09:21' },
  ]}
/>

## Parler à une IA avec un mot de commande

Un message qui est exactement un mot de commande est toujours une commande. Pour envoyer ces mêmes mots à une IA, commencez par son nom : `@claude help` atteint Claude au lieu d'ouvrir le menu.

## Noms

Les mots `nouvel`, `agents`, `révoquer`, `renouveler`, `aide`, `menu`, `connexion`, `supprimer` et leurs versions en anglais et en portugais sont réservés : ils ne peuvent pas être le nom d’une IA.

## Messages transférés

Un message transféré n'est jamais une commande, même quand son texte est un mot de commande. Il part vers vos IA comme n'importe quel autre message.
