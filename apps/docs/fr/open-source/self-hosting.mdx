zapbip est open source. Le code, les décisions qui le sous-tendent et le processus qui le construit sont publics dans le [dépôt GitHub](https://github.com/dhyegocalota/zapbip). Les licences figurent sur la page [Licence](/fr/open-source/license).

## Lancez votre propre copie

| Option               | Idéal pour                                            | Guide                                                 |
| -------------------- | ----------------------------------------------------- | ----------------------------------------------------- |
| Sur votre ordinateur | Essayer zapbip et y travailler                        | [Lancer zapbip en local](/fr/open-source/run-locally) |
| Docker               | Une commande, avec vos données gardées dans un volume | [Lancer zapbip en local](/fr/open-source/run-locally) |
| Cloudflare           | La production avec votre propre numéro WhatsApp       | [Déployer sur Cloudflare](/fr/open-source/deploy)     |

## Contribuez

- Lisez d'abord [CONTRIBUTING](https://github.com/dhyegocalota/zapbip/blob/main/.github/CONTRIBUTING.md). Ouvrez une issue avant un changement important.
- Les tests sont obligatoires, et chaque contribution est soumise au [Contributor License Agreement](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md).
- Signalez les vulnérabilités en privé, comme l'explique [SECURITY](https://github.com/dhyegocalota/zapbip/blob/main/.github/SECURITY.md), jamais dans une issue publique.
- Tout le monde respecte le [code de conduite](https://github.com/dhyegocalota/zapbip/blob/main/.github/CODE_OF_CONDUCT.md).
