## Contribuez

- Lisez d'abord [CONTRIBUTING](https://github.com/dhyegocalota/zapbip/blob/main/.github/CONTRIBUTING.md). Ouvrez une issue avant un changement important.
- Les tests sont obligatoires, et chaque contribution est soumise au [Contributor License Agreement](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md).
- Signalez les vulnérabilités en privé, comme l'explique [SECURITY](https://github.com/dhyegocalota/zapbip/blob/main/.github/SECURITY.md), jamais dans une issue publique.
- Tout le monde respecte le [code de conduite](https://github.com/dhyegocalota/zapbip/blob/main/.github/CODE_OF_CONDUCT.md).
