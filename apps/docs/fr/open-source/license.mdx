zapbip est open source sous deux licences, une pour chaque partie du code.

| Partie                                      | Licence                                                                        |
| ------------------------------------------- | ------------------------------------------------------------------------------ |
| Le serveur, le site et les bibliothèques    | [GNU AGPL v3.0](https://github.com/dhyegocalota/zapbip/blob/main/LICENSE)      |
| Le connecteur local et les plugins de canal | [MIT](https://github.com/dhyegocalota/zapbip/blob/main/apps/connector/LICENSE) |

Les plugins de canal pour [OpenClaw](https://github.com/dhyegocalota/zapbip/blob/main/apps/openclaw-plugin/LICENSE) et [Hermes](https://github.com/dhyegocalota/zapbip/blob/main/apps/hermes-plugin/LICENSE) sont aussi sous MIT, et chaque paquet contient son propre fichier `LICENSE`.

## Contributions

Chaque contribution est soumise au [Contributor License Agreement](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md), qui nomme l’entreprise ci-dessous. Lisez-le avant votre première pull request.
