---
title: 'Agents and links'
description: 'Create, list, revoke and rotate the connection of each agent.'
---

Each agent has its own connection, and each connection has one secret. The secret is the agent's credential for the zapbip MCP server. It never travels through WhatsApp: the reply carries an install link, and the install link leads to the secret.

## Create

Send `novo agente <nome>` (or `new agent <name>`). zapbip replies with two lines you paste into that agent. The name is normalised: accents are removed, it is lowercased and every run of other characters becomes one hyphen, so `Claude Code` becomes `claude-code`. The reply shows the normalised name. A name has up to 20 characters, letters, digits and hyphens, and starts with a letter or digit.

A name cannot be a [reserved word](/guides/commands#reserved-words) and must be unique among your active agents. A revoked name can be created again as a new connection. `novo agente` without a name replies with the usage line.

The second line says the install link works once for 30 minutes. Paste the two lines into your agent; the agent reads the instructions at the link and connects itself.

## The install link works once

The install link stops working after 30 minutes, or after the agent's first successful call, whichever comes first. Until then, anyone who has it can connect as that agent, so do not share it and do not paste it into a public chat or a repository. If it expires or leaks, send `girar <nome>` for a new one.

## What WhatsApp previews show

WhatsApp may show a link preview under the reply. The preview is fetched from the address in the message, so treat the chat itself as private and keep it off screen shares. If you suspect a leak, rotate the agent.

## List

Send `agentes` (or `agents`). zapbip replies with the name, the creation date and the client of every active agent, or says there are none yet. The client is the name the agent reported when it connected, or `-` until it does. It never shows a link or a secret.

## Revoke

Send `revogar <nome>` (or `revoke <name>`). The connection is revoked at once and its link stops working. It cannot be undone; create the agent again to get a new link. The explicit name is the confirmation.

## Rotate

Send `girar <nome>` (or `rotate <name>`). zapbip replaces the secret at once and replies with a new install link. The old secret stops working immediately, so give the agent the new lines. If the reply cannot be delivered, the old link is restored, so you never end up with a rotated link you did not receive.

## The limit

An account has at most 8 active agents. Revoked agents do not count. At the limit, zapbip says so and points to `revogar <nome>` as the way out.

See [commands](/guides/commands) for every command word, including the `@<agent>` escape for words meant for an agent.
