zapbip은 오픈 소스이고, 코드의 부분마다 두 가지 라이선스를 써요.

| 대상                        | 라이선스                                                                       |
| --------------------------- | ------------------------------------------------------------------------------ |
| 서버, 사이트, 라이브러리    | [GNU AGPL v3.0](https://github.com/dhyegocalota/zapbip/blob/main/LICENSE)      |
| 로컬 커넥터와 채널 플러그인 | [MIT](https://github.com/dhyegocalota/zapbip/blob/main/apps/connector/LICENSE) |

[OpenClaw](https://github.com/dhyegocalota/zapbip/blob/main/apps/openclaw-plugin/LICENSE)와 [Hermes](https://github.com/dhyegocalota/zapbip/blob/main/apps/hermes-plugin/LICENSE)의 채널 플러그인도 MIT이고, 각 패키지에 자체 `LICENSE` 파일이 있어요.

## 기여

모든 기여는 [기여자 라이선스 계약](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md)에 따라요. 이 계약에는 아래 회사가 명시되어 있어요. 첫 풀 리퀘스트 전에 읽어 주세요.

## 회사

zapbip은 Logic Bit의 제품이에요.
