zapbip은 오픈 소스예요. 코드와 그 뒤의 결정, 코드를 만드는 과정은 [GitHub 저장소](https://github.com/dhyegocalota/zapbip)에 모두 공개되어 있어요. 라이선스는 [라이선스](/ko/open-source/license) 페이지에 있어요.

## 직접 실행하기

| 방법       | 적합한 경우                       | 가이드                                                    |
| ---------- | --------------------------------- | --------------------------------------------------------- |
| 내 컴퓨터  | zapbip을 써 보거나 개발할 때      | [zapbip을 로컬에서 실행하기](/ko/open-source/run-locally) |
| Docker     | 명령 하나로, 데이터는 볼륨에 보관 | [zapbip을 로컬에서 실행하기](/ko/open-source/run-locally) |
| Cloudflare | 내 WhatsApp 번호로 하는 프로덕션  | [Cloudflare에 배포하기](/ko/open-source/deploy)           |

## 기여하기

- 먼저 [CONTRIBUTING](https://github.com/dhyegocalota/zapbip/blob/main/.github/CONTRIBUTING.md)을 읽어 주세요. 큰 변경 전에는 이슈를 열어 주세요.
- 테스트는 필수이고, 모든 기여는 [기여자 라이선스 계약](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md)에 따라요.
- 취약점은 [SECURITY](https://github.com/dhyegocalota/zapbip/blob/main/.github/SECURITY.md)의 안내대로 비공개로 제보하고, 공개 이슈에는 올리지 마세요.
- 모두 [행동 강령](https://github.com/dhyegocalota/zapbip/blob/main/.github/CODE_OF_CONDUCT.md)을 따라요.
