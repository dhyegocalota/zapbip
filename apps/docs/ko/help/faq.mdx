<AccordionGroup>
  <Accordion title="지금 내 휴대폰으로 쓸 수 있나요?">
    네. WhatsApp에서 zapbip 번호로 메시지를 보내고 [시작하기](/ko/get-started/how-to-start)를 보세요.
  </Accordion>
  <Accordion title="내 WhatsApp 번호를 쓸 수 있나요?">
    아직은 아니에요. 모든 AI는 zapbip 번호로 나에게 메시지를 보내고, 나는 평소 쓰는 WhatsApp을 그대로 쓰므로 등록할 것이 없어요.
  </Accordion>
  <Accordion title="어떤 AI가 작동하나요?">[지원하는 에이전트](/ko/agents/supported-agents)를 보세요.</Accordion>
  <Accordion title="다른 사람과도 이야기하나요?">아니요. zapbip은 공식 WhatsApp Cloud API를 통해 나하고만 이야기해요.</Accordion>
  <Accordion title="여러 AI가 하나의 번호를 공유할 수 있나요?">
    네. [여러 AI를 하나의 번호로](/ko/features/many-agents-on-one-number)를 보세요.
  </Accordion>
  <Accordion title="내 메시지가 바로 도착하지 않은 이유는 무엇인가요?">
    24시간 창이 닫혀 있어요. [24시간 창](/ko/features/the-24-hour-window)을 보세요.
  </Accordion>
  <Accordion title="개발자여야 하나요?">아니요. zapbip은 AI를 쓰는 모든 사람을 위한 서비스예요. 개발자 페이지는 선택 사항이에요.</Accordion>
  <Accordion title="계정이 대기자 명단에 있으면 어떻게 되나요?">
    zapbip 팀이 활성화할 때까지 계정이 보류돼요. 기다리면 되고, 따로 할 일은 없어요. 접근이 열리면 `help`를 보내 명령어를 확인하세요.
  </Accordion>
  <Accordion title="AI를 멈추려면 어떻게 하나요?">
    `폐기`와 AI의 이름을 쓰세요. [해제와 갱신](/ko/help/revoke-and-rotate-keys)을 보세요.
  </Accordion>
  <Accordion title="모든 것을 삭제하려면 어떻게 하나요?">
    WhatsApp에서 `계정 삭제`를 쓰세요. [계정 삭제하기](/ko/help/delete-your-account)를 보세요.
  </Accordion>
  <Accordion title="zapbip은 무엇을 보관하나요?">[개인정보 보호와 보안](/ko/help/privacy-and-security)을 보세요.</Accordion>
</AccordionGroup>
