import { Chat } from '/snippets/chat.jsx';

## AI의 메시지가 도착하지 않았어요

[24시간 창](/ko/features/the-24-hour-window)이 닫혀 있을 가능성이 높아요. zapbip 번호에 아무 메시지나 쓰면 기다리던 메시지가 순서대로 도착해요.

<Chat
  messages={[
    { notice: true, text: '에이전트 claude-code이(가) 메시지를 보냈어요: 마이그레이션이 끝났어요 ✅', time: '07:12' },
    { you: true, text: 'ok', time: '07:30' },
    { name: 'Claude Code', text: '마이그레이션이 끝났어요 ✅', time: '07:30' },
    { name: 'Grok', text: '출처를 3개 찾았어요.', time: '07:30' },
  ]}
/>

## 썼는데 AI가 답하지 않아요

AI가 듣고 있지 않았어요. 메시지는 AI를 위해 기다리고 있으며, zapbip이 그 AI가 지금 듣고 있지 않다고 알려 줘요.

<Chat
  messages={[
    { you: true, text: '@claude 빌드 통과했어?', time: '14:20' },
    { notice: true, text: '에이전트 claude이(가) 지금은 듣고 있지 않아요. 메시지는 받은 편지함에서 기다려요.', time: '14:20' },
  ]}
/>

AI를 열어 메시지를 확인하라고 요청하고, 각 AI가 계속 듣는 방법은 [지원하는 에이전트](/ko/agents/supported-agents)에서 확인하세요.

## 메시지가 엉뚱한 AI에게 갔어요

`@이름`으로 시작하세요. 예를 들어 `@grok check the news`예요. 또는 AI의 메시지에 바로 답장하세요.

<Chat
  messages={[
    { name: 'Grok', text: '출처를 3개 찾았어요.', time: '11:05' },
    { you: true, text: '@grok check the news', time: '11:06' },
    { you: true, quote: { name: 'Grok', text: '출처를 3개 찾았어요.' }, text: '어떤 거예요?', time: '11:07' },
  ]}
/>

[여러 AI를 하나의 번호로](/ko/features/many-agents-on-one-number)를 보세요.

## 메시지를 보냈는데 아무 응답이 없어요

계정이 대기자 명단에 있을 수 있어요. zapbip 팀이 활성화할 때까지 보류돼요. 기다렸다가 접근이 열리면 `help`를 보내세요.

## 프롬프트의 링크가 작동하지 않아요

링크는 30분 동안 한 번만 쓸 수 있어요. `재발급`와 AI의 이름, 예를 들어 `재발급 claude`를 써서 새 프롬프트를 받으세요. [해제와 갱신](/ko/help/revoke-and-rotate-keys)을 보세요.

## zapbip이 내 AI의 이름을 거부했어요

이름은 소문자, 숫자, 하이픈으로 1~20자여야 하고, 글자나 숫자로 시작해야 하며, 명령어처럼 시작할 수 없어요. 다른 이름으로 `새 에이전트`를 보내세요.

## 한도에 도달했다고 나와요

연결된 AI는 최대 8개까지 둘 수 있어요. 더 이상 쓰지 않는 AI의 이름과 함께 `폐기`를 써서 자리를 비우세요.

## 그 밖의 문제

연결이 거부되거나 업로드가 실패하는 것과 같은 기술적인 오류는 개발자용 항목에 정리되어 있어요.
