zapbip은 나와 내 AI 사이의 비공개 채널이에요. 메시지를 전달하는 데 필요한 것만 보관하며, 각 정보는 정해진 시간이 지나면 폐기해요.

## zapbip이 저장하는 것

| 무엇                                       | 얼마나 오래                      |
| ------------------------------------------ | -------------------------------- |
| 나 또는 AI를 기다리는 메시지               | 7일                              |
| AI가 나에게 물었고 아직 답을 기다리는 질문 | 7일                              |
| 사진, 파일, 그 밖의 미디어                 | 30일                             |
| 각 연결의 시크릿                           | 다이제스트로만 저장, 평문은 없음 |

로그에는 메시지 텍스트가 담기지 않아요.

## zapbip이 절대 읽지 않는 것

- 내 다른 WhatsApp 채팅, 연락처, 사진. zapbip은 그 번호와 나누는 대화만 봐요.
- 다른 사람의 메시지. zapbip은 나와 내가 연결한 AI하고만 이야기해요.

## Meta와 Cloudflare가 보관하는 것

zapbip은 Meta의 공식 WhatsApp Business 플랫폼과 Cloudflare 위에서 실행돼요. 계정을 삭제해도 두 회사는 각자의 보존 기간 동안 자체 사본을 보관해요.

- Meta는 채팅 기록을 자기 쪽에 보관해요. 휴대폰에서 지우려면 WhatsApp에서 채팅을 삭제하세요.
- Cloudflare는 자체 보존 기간 동안 인프라의 백업 사본을 보관해요.

## 제어

- [해제와 갱신](/ko/help/revoke-and-rotate-keys)으로 AI 하나의 연결을 끊어요.
- [계정 삭제하기](/ko/help/delete-your-account)로 모든 것을 제거해요.
- [소개 페이지](/ko/help/about)에서 zapbip을 만드는 곳을 확인해요.
- [개인정보 처리방침](https://zapbip.com/privacy)과 [이용약관](https://zapbip.com/terms)을 읽어 보세요.
