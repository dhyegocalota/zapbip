import { Chat } from '/snippets/chat.jsx';

각 AI는 자기만의 연결을 가져요. zapbip 번호에 메시지를 써서 연결을 끊거나 링크를 교체해요. 명령어는 한국어, 영어, 포르투갈어 단어로 입력할 수 있어요. 이 페이지에서는 한국어 단어를 사용해요.

## AI 연결 끊기

`폐기`와 AI의 이름을 쓰세요. 예를 들어 `폐기 claude`예요. 그 AI의 모든 연결 수단이 즉시 멈춰요. zapbip으로 가는 링크, 내 컴퓨터에서 실행 중인 리스너, 그 AI를 시작시키는 모든 웨이크가 해당돼요.

<Chat
  messages={[
    { you: true, text: '폐기 claude', time: '16:02' },
    { text: '에이전트 claude을(를) 폐기했어요. 링크는 더 이상 작동하지 않아요.', time: '16:02' },
  ]}
/>

그 AI를 다시 쓰려면 `새 에이전트 claude`를 쓰세요.

## 링크 교체하기

`재발급`와 이름을 쓰세요. 예를 들어 `재발급 claude`예요. 이전 연결은 즉시 작동을 멈추며, 범위는 `폐기`와 같아요. zapbip은 그 AI에 붙여 넣을 새 프롬프트를 보내요.

<Chat
  messages={[
    { you: true, text: '재발급 claude', time: '16:05' },
    {
      text: '에이전트 claude의 링크를 교체했어요. 이전 링크는 더 이상 작동하지 않아요. 이 내용을 에이전트에 붙여넣으세요: ...',
      time: '16:05',
    },
  ]}
/>

갱신된 링크는 한 번만 전송돼요. zapbip은 그 링크를 다시 보여 주지 않으며, `agents`는 링크 없이 AI 목록만 보여 줘요. 새 프롬프트가 도착하지 않으면 zapbip은 이전 연결을 유지하므로, `재발급 claude`를 다시 쓸 수 있어요.

## 어느 것을 쓸지

- AI를 잃어버렸거나, 쓰지 않게 되었거나, 링크를 실수로 공유했다면: `폐기`.
- 링크가 만료되었거나, 이미 사용되었거나, 유출되었지만 그 AI는 계속 쓰고 싶다면: `재발급`.

모든 단어는 [WhatsApp 명령어](/ko/features/whatsapp-commands)에서 확인하세요.
