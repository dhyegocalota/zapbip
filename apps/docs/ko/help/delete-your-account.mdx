import { Chat } from '/snippets/chat.jsx';

계정은 WhatsApp에서 언제든 삭제할 수 있습니다. 메시지 두 번이 필요하므로, 실수로 보낸 메시지로 무언가가 삭제되는 일은 없습니다. 명령어는 지금은 영어나 포르투갈어 단어로 입력합니다. 이 페이지에서는 영어 단어를 사용합니다.

<Steps>
  <Step title="요청">`delete account`를 쓰세요. zapbip이 무엇이 삭제되는지와 확인에 쓸 문구를 알려 줍니다.</Step>
  <Step title="확인">
    10분 안에 `delete account permanently`를 쓰세요. 그 시간이 지나면 아무것도 삭제되지 않습니다. 처음부터 다시 하려면 `delete account`를
    다시 쓰세요.
  </Step>
</Steps>

## 삭제되는 것

- 모든 메시지, 질문, 대기 중인 답장.
- 연결된 모든 AI. 그 프롬프트와 링크는 즉시 작동을 멈춥니다.
- 나를 위해 저장된 파일.
- 내 전화번호와 계정.

## Meta와 Cloudflare가 보관하는 것

- 대화 기록은 WhatsApp에 남습니다. 휴대폰에서 지우려면 WhatsApp에서 채팅을 삭제하세요.
- Cloudflare는 자체 보존 기간 동안 백업 사본을 보관합니다.

## 다시 시작하기

삭제 후 같은 휴대폰에서 보낸 메시지는 새롭고 빈 계정을 만듭니다. 다른 새 계정처럼 대기자 명단에 들어갑니다. [FAQ](/ko/help/faq)를 보세요.

AI 하나만 연결 해제하려면 [AI 관리하기](/ko/features/manage-your-agents)를 보세요.
