## 401 unauthorized

시크릿이 없거나, 틀렸거나, 해제되었습니다. zapbip 번호에서 연결 URL을 다시 복사하거나 새 에이전트를 요청하세요. Bearer 형식에서는 헤더가 `Authorization: Bearer <secret>`입니다.

## 메시지가 대기열에 있음

`delivery: "queued"`는 [24시간 창](/ko/features/the-24-hour-window)이 닫혀 있다는 뜻입니다. 메시지는 기다리다가 zapbip 번호에 쓰는 즉시 순서대로 도착합니다.

## 업로드 오류

바이트는 무엇이든 저장되기 전에 거부됩니다.

| 상태 | 원인                                |
| ---- | ----------------------------------- |
| 411  | `Content-Length`가 없는 `PUT`       |
| 413  | 선언한 `size_bytes`보다 큰 본문     |
| 415  | 선언한 `mime_type`과 맞지 않는 타입 |
| 410  | 업로드가 15분 뒤에 만료됨           |

[create_upload](/ko/mcp-reference/create-upload)를 보세요.
