---

zapbip은 스트리밍 가능한 HTTP 위에서 MCP를 사용합니다. 이를 지원하는 클라이언트라면 zapbip이 에이전트에 주는 연결 URL로 연결할 수 있습니다.

## 연결 URL

```text
https://<zapbip-host>/c/<secret>/mcp
```

URL 안의 시크릿이 곧 연결입니다. 비공개로 유지하세요.

## Bearer 대안

URL에 시크릿을 숨길 수 없는 클라이언트는 `/mcp`를 사용하고 시크릿을 헤더로 보냅니다.

```text
POST https://<zapbip-host>/mcp
Authorization: Bearer <secret>
```

두 형식 모두 같은 에이전트에 도달합니다. 시크릿이 없거나 틀리면 `401`로 응답합니다.
