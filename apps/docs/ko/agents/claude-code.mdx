## 지원하는 기능

| 하고 싶은 일                  | Claude Code                                            |
| ----------------------------- | ------------------------------------------------------ |
| Claude Code의 메시지 받기     | 텍스트, 사진, 동영상, 오디오, 문서, 위치, 연락처, 반응 |
| 버튼으로 답하기               | 버튼과 목록. 내 답을 기다립니다                        |
| WhatsApp에서 먼저 쓰기        | 예. 세션이 쉬고 있어도 약 7초 안에 답합니다            |
| 질문을 몇 시간 동안 열어 두기 | 예. 시간 제한이 없습니다                               |

<Chat
  messages={[
    { name: 'Claude', text: '리팩터링을 병합할 준비가 됐어요. 지금 병합할까요?', options: ['예', '아직'], time: '15:20' },
    { you: true, text: '예', time: '15:21' },
  ]}
/>

## 수신 방식

깨우기 방식: **로컬**. 내 컴퓨터의 커넥터가 Claude Code를 깨우므로, 내가 쓴 뒤 약 7초 만에 답합니다.

- Claude Code를 `claude --dangerously-load-development-channels server:zapbip-channel`로 시작하세요. 그러면 zapbip 채널이 WhatsApp 메시지가 도착하는 대로 열려 있는 세션에 밀어 넣습니다.
- 세션이 닫혀 있으면 커넥터가 약 7초 만에 다시 시작합니다. 쉬는 동안에는 토큰이 들지 않으며, 메시지 하나마다 한 턴이 듭니다.
- 리스너를 계속 실행하세요. 터미널을 닫은 뒤에도 유지하려면 [커넥터를 서비스로 실행하기](/ko/developers/background-running)를 따르세요.

AI가 나에게 무언가를 물으면 zapbip은 그 질문을 붙잡고 최대 50초마다 "보류 중"으로 답합니다. 그러면 AI가 다시 호출하고, 내가 답할 때까지 계속 호출합니다. 시간 제한 없이 기다립니다.

리스너는 하나만 쓰고, 둘을 동시에 쓰지 마세요. 채널이 켜져 있지 않으면 Claude Code는 `npx zapbip@0.1.0 listen`을 계속 실행하고 Monitor로 지켜봅니다. 감시는 최대 30분 동안 이어지므로, Claude Code는 시간 초과 알림이 올 때마다 감시를 다시 설정합니다.

## 처음부터 설정하기

1. **WhatsApp에서 zapbip 번호로 메시지를 보냅니다.** 아무 텍스트나, 예를 들어 `hi`를 보내세요.

   <StartLink />

2. **새 에이전트를 요청합니다.** 에이전트는 연결하는 AI 하나를 뜻합니다. 명령어는 한국어, 영어, 포르투갈어 단어로 입력할 수 있습니다.

   <Chat
     messages={[
       { you: true, text: '새 에이전트 claude-code', time: '15:00' },
       {
         name: 'zapbip',
         text: 'Agent claude-code created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate claude-code".',
         time: '15:00',
       },
     ]}
   />

3. **그 줄을 Claude Code에 붙여 넣습니다.**

   <InstallPrompt />

   Claude Code가 안내를 읽고 순서대로 따릅니다. 파일이나 설정을 바꾸기 전에 어느 것인지 알려 주고 내 "예"를 기다립니다. 링크는 비밀이므로 공유하는 채팅에는 올리지 마세요.

4. **"예"라고 답합니다.** 그다음은 Claude Code가 이 순서대로 나머지를 합니다.

5. **Claude Code에 zapbip을 추가합니다.** 이전의 `zapbip`이나 `zapbip-channel` 항목이 있으면 Claude Code가 `claude mcp remove --scope user zapbip` 또는 `claude mcp remove --scope user zapbip-channel`로 제거합니다. 그다음 도구용으로 `claude mcp add --transport http --scope user zapbip <connectionLink>`를, 라이브 채널용으로 `claude mcp add --scope user zapbip-channel -e ZAPBIP_CONNECTION_URL=<connectionLink> -- npx zapbip@0.1.0 channel`을 실행합니다.

   이 단계의 명령에는 내 연결 링크가 들어 있으므로 셸 기록에 남습니다. 남기지 않으려면 [커넥터를 서비스로 실행하기](/ko/developers/background-running)처럼 `ZAPBIP_CONNECTION_URL`을 env 파일에 넣으세요.

6. **zapbip 스킬을 저장합니다.** 내 "예" 뒤에 `~/.claude/skills/zapbip/SKILL.md`를 써서, 모든 세션이 `check_inbox`를 언제 호출할지를 포함해 WhatsApp을 쓰는 법을 알게 합니다.

7. **리스너 하나를 고릅니다.** 연결 하나는 리스너 하나만 가지며 두 번째가 첫 번째를 대체하므로, 다음 중 정확히 하나만 사용하고 둘을 동시에 쓰지 않습니다. 멈춘 세션에는 `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 connect --client claude-code`를 백그라운드에서 실행합니다. 커넥터는 Claude Code가 쉬는 동안 내가 쓰면 세션을 깨우고, 닫힌 세션은 `claude -p --resume`으로 다시 시작합니다.

8. **채널을 쓸 수 없을 때만.** `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 listen`을 백그라운드에서 실행하고 Monitor로 지켜보며, 시간 초과 알림이 올 때마다 다시 설정합니다.

9. **테스트합니다.** 새 프로세스에서 `claude -p "Call send_message with the text '✅ 설치 완료'" --allowedTools=mcp__zapbip__send_message`를 실행합니다. ✅ 설치 완료가 담긴 `send_message`가 내 WhatsApp에 도착합니다. 명령이 실패하면 멈추고 마지막 20줄을 보여 줍니다. 그다음 zapbip 도구를 쓰기 위해 Claude Code를 다시 시작하세요.

## 작동 확인

Claude Code에게 WhatsApp으로 `✅ 설치 완료`를 보내라고 요청하세요. 몇 초 안에 도착해야 합니다.

<Chat messages={[{ name: 'Claude', text: '✅ 설치 완료', time: '15:03' }]} />

아무것도 도착하지 않으면 [문제 해결](/ko/help/troubleshooting)을 보세요.
