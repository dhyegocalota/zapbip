## 지원하는 기능

| 하고 싶은 일                  | ChatGPT                                                |
| ----------------------------- | ------------------------------------------------------ |
| ChatGPT의 메시지 받기         | 텍스트, 사진, 동영상, 오디오, 문서, 위치, 연락처, 반응 |
| 버튼으로 답하기               | 버튼과 목록. 내 답을 기다려요                          |
| WhatsApp에서 먼저 쓰기        | 예. 한 시간 안에 내 메시지를 읽어요                    |
| 질문을 몇 시간 동안 열어 두기 | 예. 시간 제한이 없어요                                 |

<Chat
  messages={[
    { name: 'ChatGPT', text: '요약이 준비됐어요. 채널에 올릴까요?', options: ['예', '아직'], time: '17:00' },
    { you: true, text: '예', time: '17:02' },
  ]}
/>

## 수신 방식

깨우기 방식: **예약**. ChatGPT는 한 시간에 한 번 WhatsApp 메시지를 읽어요. 앱이 허용하는 가장 짧은 간격이므로 메시지는 최대 한 시간 기다릴 수 있어요.

- 한 시간마다 도는 작업이 내 컴퓨터에서 실행되어 전용 채팅 하나에 게시해요. 실행할 때마다 지난번 이후에 내가 쓴 내용을 읽어요.
- 작업이 실행될 수 있도록 그 채팅과 컴퓨터를 켜 두세요.

AI가 나에게 무언가를 물으면 zapbip은 그 질문을 붙잡고 최대 50초마다 "보류 중"으로 답해요. 그러면 ChatGPT가 다시 호출하고, 내가 답할 때까지 계속 호출해요. 시간 제한 없이 기다려요.

ChatGPT는 하나의 답을 약 5분 기다린 뒤 다시 묻기 때문에, 전체적으로는 제한이 없어요.

## 처음부터 설정하기

1. **WhatsApp에서 zapbip 번호로 메시지를 보내요.** 아무 텍스트나, 예를 들어 `hi`를 보내세요.

   <StartLink />

2. **새 에이전트를 요청해요.** 에이전트는 연결하는 AI 하나를 뜻해요. 명령어는 한국어, 영어, 포르투갈어 단어로 입력할 수 있어요.

   <Chat
     messages={[
       { you: true, text: '새 에이전트 chatgpt', time: '16:00' },
       {
         name: 'zapbip',
         text: 'Agent chatgpt created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate chatgpt".',
         time: '16:00',
       },
     ]}
   />

3. **그 줄을 ChatGPT에 붙여 넣어요.**

   <InstallPrompt />

   ChatGPT가 안내를 읽고 순서대로 따라요. 링크는 비밀이므로 공유하는 채팅에는 올리지 마세요.

4. **앱을 추가해요.** ChatGPT가 개발자 모드를 켜고 `<connectionLink>` URL로 앱을 추가하라고 안내하며, "인증 없음"을 고르게 해요. 이 단계는 직접 해요.

5. **한 시간마다 도는 작업을 만들어요.** 전용 채팅 하나에서 `check_inbox`를 호출하는, 한 시간마다 "이 컴퓨터에서 실행" 작업을 만들고, 각 도구마다 한 번씩 "항상 허용"을 고르라고 안내해요.

6. **폴링한다고 zapbip에 알려요.** `set_wake({mode: "scheduled", interval_minutes: 60})`을 호출해요.

7. **테스트해요.** 채팅에서 `send_message`를 호출해 ✅ 설치 완료를 보내요.

## 작동 확인

연결이 끝나면 ChatGPT가 내 WhatsApp으로 `✅ 설치 완료`를 보내요.

<Chat messages={[{ name: 'ChatGPT', text: '✅ 설치 완료', time: '16:05' }]} />

아무것도 도착하지 않으면 [문제 해결](/ko/help/troubleshooting)을 보세요.
