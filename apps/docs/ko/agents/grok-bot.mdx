## 지원하는 기능

| 할 수 있는 일                           | Grok Bot |
| --------------------------------------- | -------- |
| 텍스트, 사진, 동영상, 오디오, 문서 받기 | 예       |
| 위치, 연락처, 반응 받기                 | 예       |
| 버튼이나 목록으로 질문하고 기다리기     | 예       |
| 내가 먼저 쓸 때 대화 시작하기           | 예       |

## 수신 방식

단계: Webhook. WhatsApp에서 쓰면 zapbip이 Grok Bot 루틴의 웹훅을 호출하고, Grok Bot이 내 메시지와 함께 약 9초 뒤에 시작해요. 호출이 실패하면 zapbip이 WhatsApp으로 알려 줘요.

질문이 열려 있는 동안 Grok Bot은 한 번에 최대 50초 기다려요. 내가 답하지 않으면 대기가 보류 중(pending)으로 끝나고, Grok Bot은 필요한 만큼 몇 번이든 다시 호출해요. 시간 제한 없이 기다려요. Grok Bot에서는 한 번의 대기가 최소 2분 이어져요.

계속 실행되게 하려고 내가 할 일은 없어요.

## 처음부터 설정하기

1. **WhatsApp에서 zapbip 번호로 메시지를 보내요.** `새 에이전트 grok-bot`을 보내세요. 명령어는 한국어, 영어, 포르투갈어 단어로 입력할 수 있어요. 모든 메시지는 [시작하기](/ko/get-started/how-to-start)에 나와 있어요.

   <Chat
     messages={[
       { you: true, text: '새 에이전트 grok-bot', time: '09:00' },
       { name: 'zapbip', text: 'Agent grok-bot created. Paste this into your agent.', time: '09:00' },
     ]}
   />

2. **그 줄을 Grok Bot에 붙여 넣어요.** zapbip이 나를 위해 만든 한 줄로 답해요.

   <InstallPrompt />

3. **변경마다 "예"라고 답해요.** Grok Bot이 안내를 읽고, 설정을 바꾸기 전에 어느 것인지 알려 주며 내 "예"를 기다려요. 링크는 공유하는 채팅에 올리지 마세요.

4. **Grok Bot에 zapbip을 추가해요.** `<connectionLink>`를 가리키는 `zapbip`이라는 MCP 서버를 추가하라고 봇에게 요청해요. 내가 확인해요.

5. **루틴을 만들어요.** 웹훅 트리거가 있는 루틴을 만들면 URL과 키가 나와요.

6. **어떻게 깨울지 zapbip에 알려요.** 루틴의 URL과 키로 `set_wake({mode: "webhook", url, token})`을 호출해요. 오류가 나면 멈추고 보고해요.

7. **테스트해요.** 채팅에서 `send_message`를 호출해 ✅ 설치 완료를 보내요.

## 작동 확인

Grok Bot에게 WhatsApp으로 `✅ 설치 완료`를 보내라고 요청하세요. 도착하면 연결이 작동하는 것이에요.

<Chat messages={[{ name: 'Grok Bot', text: '✅ 설치 완료', time: '09:03' }]} />

그다음 WhatsApp에 무언가 쓰세요. Grok Bot이 약 9초 안에 답해요.

수동 설정이 필요한 앱은 [모든 MCP 클라이언트 연결하기](/ko/developers/any-mcp-client)를 보세요.
