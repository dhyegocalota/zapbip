## 수신 방식

깨우기 방식: **Webhook**. WhatsApp에서 쓰면 zapbip이 claude.ai 작업의 트리거 링크를 호출하고, 작업은 내 커넥터와 함께 클라우드에서 실행됩니다. 승인 요청 없이, 내가 쓴 뒤 약 16초 만에 답합니다.

- claude.ai 작업은 예약 실행이 최대 1시간에 한 번입니다. 그래서 메시지를 확인하는 1시간마다 도는 작업도 함께 만듭니다. 이것은 안전망일 뿐이며, 웨이크를 놓쳐도 1시간 넘게 기다리는 일이 없게 합니다.

AI가 나에게 무언가를 물으면 zapbip은 그 질문을 붙잡고 최대 50초마다 "보류 중"으로 답합니다. 그러면 claude.ai가 다시 호출하고, 내가 답할 때까지 계속 호출합니다. 시간 제한 없이 기다립니다.

claude.ai는 하나의 답을 약 4분 기다린 뒤 스스로 다시 시도하기 때문에, 전체적으로는 제한이 없습니다.

## 처음부터 설정하기

1. **WhatsApp에서 zapbip 번호로 메시지를 보냅니다.** 아무 텍스트나, 예를 들어 `hi`를 보내세요.

   <StartLink />

2. **새 에이전트를 요청합니다.** 에이전트는 연결하는 AI 하나를 뜻합니다. 명령어는 한국어, 영어, 포르투갈어 단어로 입력할 수 있습니다.

   <Chat
     messages={[
       { you: true, text: '새 에이전트 claude-ai', time: '08:00' },
       {
         name: 'zapbip',
         text: 'Agent claude-ai created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate claude-ai".',
         time: '08:00',
       },
     ]}
   />

3. **그 줄을 claude.ai에 붙여 넣습니다.**

   <InstallPrompt />

   claude.ai가 안내를 읽고 순서대로 따릅니다. 링크는 비밀이므로 공유하는 채팅에는 올리지 마세요.

4. **커넥터를 붙여 넣습니다.** claude.ai가 설정에서 `<connectionLink>`를 커스텀 커넥터로 붙여 넣으라고 안내합니다. claude.ai는 추가를 내가 직접 해야만 하므로, 이 단계는 직접 합니다.

5. **웨이크 작업을 만듭니다.** claude.ai/code/routines에서 API 트리거가 있는 작업을 만들고, 그 실행 URL과 토큰을 채팅에 붙여 넣으라고 안내합니다. 두 번째 붙여 넣기도 내가 해야 합니다. claude.ai가 토큰을 나에게만 보여 주기 때문입니다.

6. **어떻게 깨울지 zapbip에 알립니다.** 작업이 만들어지기 전에 멈추면 `set_wake({mode: "none"})`을 호출하고, 채팅이 새 메시지를 보는 것은 내가 채팅을 열 때뿐이라고 알려 줍니다. 그렇지 않으면 `set_wake({mode: "webhook", url, token})`을 호출합니다.

7. **1시간마다 도는 안전망을 만듭니다.** `check_inbox`를 호출하는 1시간마다 도는 작업을 만들라고 안내합니다. 웨이크를 놓쳐도 1시간 넘게 기다리는 일이 없게 하기 위해서입니다.

8. **테스트합니다.** 채팅에서 `send_message`를 호출해 ✅ 설치 완료를 보냅니다.

## 작동 확인

연결이 끝나면 claude.ai가 내 WhatsApp으로 `✅ 설치 완료`를 보냅니다.

<Chat messages={[{ name: 'Claude', text: '✅ 설치 완료', time: '08:05' }]} />

아무것도 도착하지 않으면 [문제 해결](/ko/help/troubleshooting)을 보세요.
