## 지원하는 기능

| 할 수 있는 일                           | Gemini CLI                |
| --------------------------------------- | ------------------------- |
| 텍스트, 사진, 동영상, 오디오, 문서 받기 | 예                        |
| 위치, 연락처, 반응 받기                 | 예                        |
| 버튼이나 목록으로 질문하고 기다리기     | 예                        |
| 내가 먼저 쓸 때 대화 시작하기           | 예. 세션이 열려 있는 동안 |

## 수신 방식

단계: 로컬. Gemini CLI는 백그라운드 터미널에서 zapbip 리스너를 계속 실행합니다. WhatsApp에서 쓰면 거기에 새 줄이 나타나 세션을 깨웁니다. 그 터미널을 열어 두세요. Gemini CLI에는 예약 옵션이 없습니다.

```bash
npx zapbip@0.1.0 listen
```

질문이 열려 있는 동안 Gemini CLI는 한 번에 최대 50초 기다립니다. 내가 답하지 않으면 대기가 보류 중(pending)으로 끝나고, Gemini CLI는 필요한 만큼 몇 번이든 다시 호출합니다. 시간 제한 없이 기다립니다.

리스너는 한 번에 하나만 실행하세요. 두 번째 리스너는 첫 번째를 대체합니다.

## 처음부터 설정하기

1. **WhatsApp에서 zapbip 번호로 메시지를 보냅니다.** `new agent gemini-cli`를 보내세요. 명령어는 지금은 영어나 포르투갈어 단어로 입력합니다. 모든 메시지는 [시작하기](/ko/get-started/how-to-start)에 나와 있습니다.

   <Chat
     messages={[
       { you: true, text: 'new agent gemini-cli', time: '09:00' },
       { name: 'zapbip', text: 'Agent gemini-cli created. Paste this into your agent.', time: '09:00' },
     ]}
   />

2. **그 줄을 Gemini CLI에 붙여 넣습니다.** zapbip이 나를 위해 만든 한 줄로 답합니다.

   <InstallPrompt />

3. **변경마다 "예"라고 답합니다.** Gemini CLI가 어떤 설정을 바꾸는지 알려 주고 내 "예"를 기다립니다. 링크는 공유하는 채팅에 올리지 마세요.

4. **Gemini CLI에 zapbip을 추가합니다.** 내 "예" 뒤에 `gemini mcp add --transport http --scope user zapbip <connectionLink>`를 실행합니다.

5. **듣기를 시작합니다.** 백그라운드 터미널에서 `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 listen`을 실행하고, 그 터미널을 시간 제한 없이 계속 실행합니다. 거기에 새 줄이 나타날 때마다 `check_inbox`를 호출하고 답합니다.

6. **테스트합니다.** 새 프로세스에서 `gemini -p "Call send_message with the text '✅ installed'"`를 실행합니다. ✅ installed가 담긴 `send_message`가 내 WhatsApp에 도착합니다. 명령이 실패하면 멈추고 마지막 20줄을 보여 줍니다. 그다음 Gemini CLI를 다시 시작하세요.

## 작동 확인

Gemini CLI에게 WhatsApp으로 `✅ installed`를 보내라고 요청하세요. 도착하면 연결이 작동하는 것입니다.

<Chat messages={[{ name: 'Gemini CLI', text: '✅ installed', time: '09:03' }]} />

도착하지 않으면 Gemini CLI를 다시 시작하고 다시 요청하세요.

수동 설정이 필요한 앱은 [모든 MCP 클라이언트 연결하기](/ko/developers/any-mcp-client)를 보세요.
