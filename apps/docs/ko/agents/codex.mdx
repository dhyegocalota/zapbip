## 지원하는 기능

| 하고 싶은 일                  | Codex                                                  |
| ----------------------------- | ------------------------------------------------------ |
| Codex의 메시지 받기           | 텍스트, 사진, 동영상, 오디오, 문서, 위치, 연락처, 반응 |
| 버튼으로 답하기               | 버튼과 목록. 내 답을 기다려요                          |
| WhatsApp에서 먼저 쓰기        | 예. 세션이 쉬고 있어도 약 6초 안에 답해요              |
| 질문을 몇 시간 동안 열어 두기 | 예. 시간 제한이 없어요                                 |

<Chat
  messages={[
    { name: 'Codex', text: '마이그레이션이 끝났어요. 시드 스크립트도 실행할까요?', options: ['예', '아니요'], time: '11:40' },
    { you: true, text: '예', time: '11:41' },
  ]}
/>

## 수신 방식

깨우기 방식: **로컬**. 내가 쓸 때마다 내 컴퓨터의 커넥터가 `codex exec resume`으로 Codex 세션을 약 6초 만에 다시 시작해요. Codex가 그 세션을 이미 앱에서 열어 두었다면, 세션이 비워질 때까지 다시 시작이 기다려요.

- 커넥터를 계속 실행하세요. 터미널을 닫은 뒤에도 유지하려면 [커넥터를 서비스로 실행하기](/ko/developers/background-running)를 따르세요.

AI가 나에게 무언가를 물으면 zapbip은 그 질문을 붙잡고 최대 50초마다 "보류 중"으로 답해요. 그러면 Codex가 다시 호출하고, 내가 답할 때까지 계속 호출해요. 시간 제한 없이 기다려요.

설치가 Codex에 설정하는 900초 도구 시간 제한은 한 번의 호출의 한도이지 듣기의 한도가 아니에요. 호출이 끝나면 Codex가 다음 호출을 시작해요.

Codex는 하나의 답을 최대 15분 기다린 뒤 다시 묻기 때문에, 전체적으로는 제한이 없어요.

## 처음부터 설정하기

1. **WhatsApp에서 zapbip 번호로 메시지를 보내요.** 아무 텍스트나, 예를 들어 `hi`를 보내세요.

   <StartLink />

2. **새 에이전트를 요청해요.** 에이전트는 연결하는 AI 하나를 뜻해요. 명령어는 한국어, 영어, 포르투갈어 단어로 입력할 수 있어요.

   <Chat
     messages={[
       { you: true, text: '새 에이전트 codex', time: '11:00' },
       {
         name: 'zapbip',
         text: 'Agent codex created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate codex".',
         time: '11:00',
       },
     ]}
   />

3. **그 줄을 Codex에 붙여 넣어요.**

   <InstallPrompt />

   Codex가 안내를 읽고 순서대로 따라요. 파일이나 설정을 바꾸기 전에 어느 것인지 알려 주고 내 "예"를 기다려요. 링크는 비밀이므로 공유하는 채팅에는 올리지 마세요.

4. **"예"라고 답해요.** 그다음은 Codex가 이 순서대로 나머지를 해요.

5. **Codex에 zapbip을 추가해요.** 내 "예" 뒤에 `~/.codex/config.toml`의 `[mcp_servers.zapbip]` 테이블을 `url = "<connectionLink>"`, `tool_timeout_sec = 900`, `default_tools_approval_mode = "approve"`로 바꿔요. 승인 모드는 zapbip 도구가 매번 묻지 않고 실행되게 하며, Codex가 그 사실을 알려 줘요.

6. **커넥터를 시작해요.** `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 connect --client codex`를 백그라운드에서 실행해요. 계속 듣고 있다가 `codex exec resume`으로 세션을 다시 시작해요.

7. **테스트해요.** 새 프로세스에서 `codex exec -c 'mcp_servers.zapbip.default_tools_approval_mode="approve"' "Call send_message with the text '✅ 설치 완료'"`를 실행해요. ✅ 설치 완료가 담긴 `send_message`가 내 WhatsApp에 도착해요. 명령이 실패하면 멈추고 마지막 20줄을 보여 줘요. 그다음 Codex를 다시 시작하세요.

## 작동 확인

Codex에게 WhatsApp으로 `✅ 설치 완료`를 보내라고 요청하세요. 몇 초 안에 도착해야 해요.

<Chat messages={[{ name: 'Codex', text: '✅ 설치 완료', time: '11:03' }]} />

아무것도 도착하지 않으면 [문제 해결](/ko/help/troubleshooting)을 보세요.
