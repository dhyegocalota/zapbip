zapbip은 모든 계정이 함께 쓰는 하나의 번호로, 공식 WhatsApp Cloud API를 통해 소유자와 이야기합니다.

## 수신 메시지

소유자가 번호로 씁니다. zapbip은 모든 알림의 서명을 검증하고, WhatsApp이 같은 메시지를 두 번 전달해도 한 번만 저장하며, [라우팅 규칙](/ko/concepts/routing)에 따라 에이전트 하나로 전달합니다.

| 소유자가 보내는 것                                        | 에이전트가 받는 것                                                                     |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 텍스트, 이미지, 동영상, 오디오, 음성 메시지, 문서, 스티커 | 메시지. 미디어는 zapbip이 저장합니다                                                   |
| 위치, 연락처 카드                                         | 메시지                                                                                 |
| 버튼이나 목록 행 답                                       | 선택. 질문에 대한 답이 됩니다                                                          |
| 반응                                                      | 반응. 반응한 메시지를 보낸 에이전트에게 전달되며, 반응을 지우면 이모지 없이 도착합니다 |
| 그 밖의 종류의 메시지                                     | 없음. 소유자에게 아직 지원하지 않는 종류라고 알립니다                                  |

소유자가 보낸 메시지는 [24시간 창](/ko/concepts/24-hour-window)을 엽니다. 반응은 열지 않습니다.

파일을 내려받을 수 없으면 에이전트는 `media_id: null`과 `media_status: "unavailable"`이 붙은 메시지를 받고, 소유자에게는 다시 보내 달라고 요청합니다.

## 발신 메시지

창 안에서는 모든 종류가 즉시 전송됩니다. 창 밖에서는 메시지가 대기열에 들어가고 소유자는 [알림](/ko/concepts/owner-notices)을 받습니다.

| 종류   | 한도                                                                                  |
| ------ | ------------------------------------------------------------------------------------- |
| 텍스트 | 4,096자                                                                               |
| 버튼   | 버튼 최대 3개, 질문 최대 1,024자, 제목 최대 20자                                      |
| 목록   | 행 최대 10개, 질문 최대 1,024자, 버튼 최대 20자, 행 제목 최대 24자, 행 설명 최대 72자 |
| 반응   | 반응 대상 메시지는 30일 이내여야 하고, 같은 스레드에 있으며 삭제되지 않아야 합니다    |
| 이미지 | JPEG, PNG 또는 WebP, 최대 5 MB                                                        |
| 동영상 | 3GP 또는 MP4, 최대 16 MB                                                              |
| 오디오 | AAC, AMR, MP3, M4A 또는 OGG, 최대 16 MB                                               |
| 문서   | PDF, Word, Excel, PowerPoint 또는 일반 텍스트, 최대 100 MB                            |
| 스티커 | 정적 WebP, 최대 100 KB                                                                |

zapbip은 한도를 어기는 전송을 거부하고, 도구는 해당 필드를 밝힌 오류를 반환합니다.

## 전달 상태

메시지의 `delivery`는 앞으로만 나아갑니다. `sent`, `delivered`, `read` 순서입니다. WhatsApp이 거부한 전송은 `failed`가 됩니다. 이미 `delivered`나 `read`가 된 메시지는 `failed`가 되지 않습니다.

## 제한된 번호

WhatsApp이 번호가 제한되었거나 계정이 비활성화되었다고 알리면, zapbip은 24시간 동안 전송을 중단하고 운영자에게 경보가 갑니다. 그 사이에 보낸 메시지는 `delivery: "failed"`를 반환합니다.
