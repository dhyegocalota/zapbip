WhatsApp에서 쓸 때 AI가 닫혀 있거나, 작업 중이거나, 그저 나를 기다리고 있지 않을 수 있어요. 그러면 zapbip은 그 AI의 연결이 지원하는 가장 높은 단계로 연락하고, 어떤 단계를 쓸 수 없으면 다음 단계로 내려가요.

| 단계         | 일어나는 일                                                                                                                                           | 예상 지연                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 로컬         | zapbip이 내 컴퓨터에서 실행 중인 [커넥터](/ko/developers/local-connector)로 메시지를 밀어 넣고, 커넥터가 Claude Code 또는 Codex 세션을 다시 시작해요. | Claude Code 7초, Codex 6초   |
| Webhook      | zapbip이 AI를 시작하는 링크를 호출해요. [웹훅 웨이크 가이드](/ko/developers/webhook-wake)를 보세요.                                                   | Grok Bot 9초, claude.ai 16초 |
| 예약         | AI가 타이머로 받은편지함을 확인하므로 시간 제한 없이 들을 수 있어요.                                                                                  | 설정한 간격까지              |
| 대기         | 내 다른 AI가 메시지 사본을 받아 대신 답해요.                                                                                                          | 측정 안 됨                   |
| 받은편지함만 | 메시지는 기다리고, zapbip이 그 AI가 지금 듣고 있지 않다고 알려 줘요.                                                                                  | AI가 읽을 때까지             |

어느 단계에서든 메시지는 AI가 읽을 때까지 [받은편지함](/ko/concepts/inbox)에 보관돼요. 잃어버리는 것은 없어요.

## 로컬: 내 컴퓨터

커넥터는 실행되는 동안 zapbip으로 열린 회선 하나를 유지해요. 내가 쓰면 zapbip이 그 회선으로 메시지를 밀어 넣고, 커넥터가 내 컴퓨터의 세션을 다시 시작해요. 마지막 회선이 닫히면 zapbip은 이전에 설정해 둔 웨이크로 되돌려요. `npx zapbip@0.1.0 connect`로 시작해요.

## 예약: 시간 제한 없이 듣기

일부 AI는 밖에서 시작시킬 방법이 없고, zapbip으로의 각 호출이 몇 분 뒤에 끝나요. 예약 웨이크가 이를 해결해요. AI에게 몇 분마다 또는 한 시간마다 타이머로 작은 작업을 실행하게 하면, 실행할 때마다 내가 쓴 내용을 읽고 답해요.

주기는 1분마다부터 1440분(하루)마다까지 고를 수 있어요. ChatGPT와 claude.ai는 예약 작업을 60분 이하 간격으로는 실행하지 않으므로, 이 둘의 최단 간격은 60분이에요.

내가 쓰면 zapbip이 답을 언제쯤 기대하면 되는지 알려 줘요.

<Chat
  contact="zapbip"
  messages={[
    { you: true, text: 'Can you summarize the report?' },
    {
      notice: true,
      text: '에이전트 Claude은(는) 받은 편지함을 1시간마다 확인해요. 마지막 확인은 20분 전이에요. 메시지는 다음 확인 때까지 그곳에서 기다려요.',
    },
  ]}
/>

타이머가 멈추면, 확인 없이 간격의 두 배가 지났을 때 zapbip이 한 번 알려 주고, 메시지는 계속 기다려요.

<Chat contact="zapbip" messages={[{ notice: true, text: "Claude hasn't checked in 2 h: your messages wait" }]} />

다음 확인이 이루어지면 추가 메시지 없이 경고가 해제돼요.

[24시간 창](/ko/concepts/24-hour-window)이 닫혀 있을 때는 이 안내를 그대로 보낼 수 없어요. zapbip은 닫힌 창마다 템플릿 [알림](/ko/concepts/owner-notices)을 하나 보내고, 안내는 기다렸다가 내가 쓸 때 도착해요.

## 대기: 다른 AI가 답하기

웹의 Grok처럼 아예 시작시킬 수 없는 AI도 있어요. 같은 계정의 다른 AI, 예를 들어 Grok Bot을 대기(스탠바이)로 지정할 수 있어요. 첫 번째 AI에게 쓰면 zapbip이 대기 AI에게 사본을 주고 깨우며, 대기 AI는 자신이 누구인지 밝히고 자기 이름으로 답해요. 첫 번째 AI에게는 그 메시지가 대기 AI에 의해 처리된 것으로 보여요.

<Chat
  contact="zapbip"
  messages={[
    { you: true, text: '@grok what is on my calendar?' },
    { name: 'Grok Bot (standby for Grok)', text: 'Today you have two meetings: 10:00 and 15:30.' },
  ]}
/>

대기 연결은 다른 대기 연결로 전달하지 않아요. 1홉뿐이에요. 대기 연결이 없거나, 삭제되었거나, 그 자체가 대기 연결이면 아무것도 복사되지 않고, 메시지는 첫 번째 AI에서 기다리며 평소와 같은 알림이 와요.

이 설정은 설치 중에 AI가 대신 해 줘요. 직접 바꾸려면 [set_wake](/ko/mcp-reference/set-wake)를 사용하세요.
