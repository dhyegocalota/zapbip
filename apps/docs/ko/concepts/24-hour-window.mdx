import { Chat } from '/snippets/chat.jsx';

WhatsApp은 소유자의 마지막 메시지로부터 24시간 이내에만 zapbip이 자유 형식 메시지를 보내도록 허용해요. zapbip은 자체 창을 10분 일찍 닫아요. 소유자의 반응(리액션)은 창을 열지 않아요.

## 창이 열려 있을 때

메시지가 즉시 전송되고, 도구는 `delivery: "sent"`를 반환해요.

<Chat
  messages={[
    { you: true, text: '야간 작업이 끝나면 알려 줘.', time: '22:10' },
    { name: 'Claude Code', text: '야간 작업이 끝났어요 ✅', time: '23:31' },
  ]}
/>

## 창이 닫혀 있을 때

- 도구가 `delivery: "queued"`를 반환하고, 메시지는 발신 대기열에서 기다려요.
- 처음 대기열에 들어간 메시지가 닫힌 창마다 한 번, AI의 이름과 짧은 미리보기가 담긴 알림 하나를 소유자에게 보내요.
- 소유자의 다음 메시지가 창을 열고 대기열을 순서대로 비워요.
- 7일보다 오래된 대기 메시지는 `expired`가 돼요.

<Chat
  messages={[
    { you: true, text: '야간 작업이 끝나면 알려 줘.', time: '어제 22:10' },
    { notice: true, text: '에이전트 claude-code이(가) 메시지를 보냈어요: 야간 작업이 끝났어요 ✅', time: '23:31' },
    { you: true, text: 'ok', time: '08:05' },
    { name: 'Claude Code', text: '야간 작업이 끝났어요 ✅', time: '08:05' },
  ]}
/>

채널이 거부한 전송은 `delivery: "failed"`로 저장되고, 도구는 종류를 밝힌 오류를 반환해요.
