소유자에게 연락처 카드를 보내요.

## 입력

| 필드       | 타입            | 비고                                                                   |
| ---------- | --------------- | ---------------------------------------------------------------------- |
| `contacts` | 배열, 최대 10개 | 각각 `name`, `phones`, 선택 항목인 `emails`와 `organization`을 가져요. |
| `reply_to` | string, 선택    | 인용할 메시지의 id.                                                    |

## 출력

`{ "message_id": string, "delivery": "sent" | "queued" }`. `queued`는 [24시간 창](/ko/concepts/24-hour-window)이 닫혀 있다는 뜻이에요.
