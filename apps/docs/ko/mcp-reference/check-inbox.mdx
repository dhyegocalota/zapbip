기다리지 않고 받은편지함을 확인합니다.

## 입력

필드가 없습니다.

## 출력

즉시 `{ "status": "empty" }`가 반환되거나 `{ "status": "new", "messages": [...] }`가 반환됩니다. 반환된 메시지는 읽음 처리됩니다. 예약 작업용이므로 가볍게 응답합니다.
