이 연결이 속한 계정을 읽습니다. 읽기 전용이라 승인이 필요 없고 어떤 한도에도 포함되지 않습니다.

## 입력

없음.

## 출력

`{ "state": "waitlisted" | "active" | "suspended" | "deleting", "plan": "free", "free_messages": number }`. 전화번호는 결과에 포함되지 않습니다. `free_messages`는 요금제에 포함된 이용량이며, zapbip은 남은 양을 알려 주지 않습니다.

같은 데이터가 [웹 앱](/ko/features/web-app)에도 있습니다. 홈 페이지는 로그인된 세션의 `Accept: application/json` 요청에 `{ "state", "phone", "plan", "free_messages", "agents" }`로 답하며, `phone`은 마지막 네 자리만 보여 줍니다. 로그아웃 상태에서는 `401`과 `{ "error": "sign_in_required" }`로 답합니다.
