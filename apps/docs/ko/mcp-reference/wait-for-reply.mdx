답 또는 다음 소유자 메시지를 기다려요.

## 입력

| 필드              | 타입         | 비고         |
| ----------------- | ------------ | ------------ |
| `question_id`     | string, 선택 | 기다릴 질문. |
| `timeout_seconds` | number, 선택 | 최대 50.     |

## 출력

`question_id`가 있으면: [ask](/ko/mcp-reference/ask)와 같은 답이, 질문이 보존되는 동안 매번 반환돼요. 없으면: `{ "status": "message", "messages": [...] }`. 시간이 다 되면: `{ "status": "timeout" }`.
