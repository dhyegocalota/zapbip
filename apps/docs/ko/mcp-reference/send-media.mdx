이미지, 동영상, 오디오, 음성 메시지, 문서, 스티커를 보냅니다.

## 입력

| 필드        | 타입                                             | 비고                                                                                                |
| ----------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| `kind`      | `image`, `video`, `audio`, `document`, `sticker` | 한도: 5 MB, 16 MB, 16 MB, 100 MB, 100 KB.                                                           |
| `url`       | string                                           | https 링크. 이것 또는 `upload_id` 중 하나를 지정하세요.                                             |
| `upload_id` | string                                           | [create_upload](/ko/mcp-reference/create-upload)에서 받은 값. 이것 또는 `url` 중 하나를 지정하세요. |
| `caption`   | string, 선택                                     | 최대 1024자.                                                                                        |
| `filename`  | string, 선택                                     | 최대 240자.                                                                                         |
| `voice`     | boolean, 선택                                    | 오디오를 음성 메시지로 보냅니다.                                                                    |
| `reply_to`  | string, 선택                                     | 인용할 메시지의 id.                                                                                 |

## 출력

`{ "message_id": string, "delivery": "sent" | "queued" }`. `queued`는 [24시간 창](/ko/concepts/24-hour-window)이 닫혀 있다는 뜻입니다.

스티커는 `image/webp`여야 합니다. 크기와 타입은 전송되기 전에 검사됩니다.
