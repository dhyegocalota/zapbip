AI는 zapbip 번호에 메시지를 써서 관리합니다. 명령어는 포르투갈어 또는 영어의 짧은 문구입니다. 아직 한국어 명령어는 없으며, 내가 쓴 언어가 답변의 언어가 됩니다. 각 행에 두 가지 표현을 모두 보여 줍니다.

| 하려는 일        | 영어로 입력                                           | 또는 포르투갈어로 입력                                | 일어나는 일                                                           |
| ---------------- | ----------------------------------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------- |
| 새 AI 연결       | `new agent claude`                                    | `novo agente claude`                                  | zapbip이 그 AI에 붙여 넣을 프롬프트로 답합니다                        |
| AI 목록 보기     | `agents`                                              | `agentes`                                             | 각 AI의 이름과 날짜 목록                                              |
| AI 연결 해제     | `revoke claude`                                       | `revogar claude`                                      | 그 AI가 즉시 작동을 멈춥니다                                          |
| 새 프롬프트 받기 | `rotate claude`                                       | `girar claude`                                        | 이전 연결이 멈추고 새 프롬프트를 받습니다                             |
| 웹 앱 로그인     | `login`                                               | `entrar`                                              | 10분 동안 한 번만 쓸 수 있는 링크. [웹 앱](/ko/features/web-app) 참고 |
| 메뉴 열기        | `help` 또는 `menu`                                    | `ajuda` 또는 `menu`                                   | 명령어가 텍스트와 탭할 수 있는 목록으로 표시됩니다                    |
| 계정 삭제        | `delete account`, 이어서 `delete account permanently` | `apagar conta`, 이어서 `apagar conta definitivamente` | [계정 삭제하기](/ko/help/delete-your-account) 참고                    |

문구만 단독으로 쓰세요. 끝에 `?`나 `!`가 붙으면 AI에게 가는 일반 메시지가 됩니다.

## 예시

<Chat
  messages={[
    { you: true, text: 'agents', time: '09:20' },
    { text: 'Your agents:\nclaude (2026-11-06, Claude Code)', time: '09:20' },
    { you: true, text: 'revoke claude', time: '09:21' },
    { text: 'Agent claude revoked. Its link no longer works.', time: '09:21' },
  ]}
/>

## 명령어 단어로 AI에게 말하기

메시지가 명령어 단어 하나뿐이면 항상 명령어로 처리됩니다. 같은 단어를 AI에게 보내려면 AI의 이름으로 시작하세요. `@claude help`는 메뉴를 열지 않고 Claude에게 전달됩니다.

## 이름

`new`, `agents`, `revoke`, `rotate`, `help`, `menu`, `login`, `delete`와 그 포르투갈어 단어는 예약어이므로 AI의 이름으로 쓸 수 없습니다.

## 전달(포워드)된 메시지

전달된 메시지는 텍스트가 명령어 단어여도 명령어가 아닙니다. 다른 메시지와 똑같이 AI에게 전달됩니다.
