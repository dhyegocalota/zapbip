import { Chat } from '/snippets/chat.jsx';

AI가 먼저 쓰기를 기다릴 필요가 없어요. zapbip에 메시지를 보내면, 이름을 지정한 AI 또는 마지막으로 쓴 AI에게 전달돼요.

<Chat
  messages={[
    { you: true, text: '@claude 빌드 통과했어?', time: '09:00' },
    { name: 'Claude', text: '네, 212개 테스트가 모두 통과했어요.', time: '09:00' },
  ]}
/>

## AI가 내 말을 듣는 방법

AI는 무언가가 깨울 때만 답해요. zapbip은 각 AI가 허용하는 가장 좋은 방법을 사용해요.

| 깨우는 방법        | 일어나는 일                                     | 보통 대기 시간                         |
| ------------------ | ----------------------------------------------- | -------------------------------------- |
| 내 컴퓨터의 커넥터 | 내 컴퓨터의 세션이 즉시 다시 시작돼요.          | Claude Code 7초, Codex 6초             |
| Webhook            | zapbip이 AI 자체 링크를 호출하면 AI가 시작돼요. | Grok Bot 9초, claude.ai 16초           |
| 예약 작업          | AI가 타이머로 내 메시지를 확인해요.             | 타이머 간격까지, ChatGPT는 1시간       |
| 내 다른 AI         | 내 두 번째 AI가 대신 답해요.                    | 그 AI에 따라 다름, 예를 들어 웹의 Grok |
| 받은편지함만       | AI가 볼 때까지 메시지가 기다려요.               | AI가 확인할 때까지                     |

메시지는 절대 사라지지 않아요. AI를 깨울 수 없으면 받은편지함에서 기다려요.

## AI가 듣고 있지 않을 때

zapbip이 바로 알려 주므로 기다리는 중이라는 것을 알 수 있어요.

<Chat
  messages={[
    { you: true, text: '@claude 빌드 통과했어?', time: '09:00' },
    {
      notice: true,
      text: '에이전트 claude이(가) 지금은 듣고 있지 않아요. 메시지는 받은 편지함에서 기다려요.',
      time: '09:00',
    },
  ]}
/>

## 24시간 창이 닫혀 있을 때

WhatsApp은 내 마지막 메시지로부터 24시간 이내에만 zapbip이 자유롭게 쓰도록 허용해요. 창이 닫히면 zapbip은 닫힌 창마다 알림을 하나 보내고 나머지는 보류해요. 아무 메시지나 쓰면 창이 다시 열려요. zapbip 자체의 알림도 마찬가지예요.

<Chat
  messages={[
    { you: true, text: '@claude 빌드 통과했어?', time: '어제 09:00' },
    { notice: true, text: '에이전트 claude이(가) 메시지를 보냈어요: 네, 212개 테스트가 모두 통과했어요.', time: '10:30' },
    { you: true, text: 'ok', time: '10:31' },
    { name: 'Claude', text: '네, 212개 테스트가 모두 통과했어요.', time: '10:31' },
  ]}
/>

[24시간 창](/ko/concepts/24-hour-window)과 [여러 AI를 하나의 번호로](/ko/features/many-agents-on-one-number)도 보세요.
