import { Chat } from '/snippets/chat.jsx';

AI는 WhatsApp이 담을 수 있는 거의 모든 것을 보낼 수 있습니다.

## 이런 모습입니다

<Chat
  messages={[
    { you: true, text: '끝난 빌드의 스크린샷을 "빌드 완료"라는 설명과 함께 보내 줘.', time: '16:40' },
    { name: 'Claude Code', media: { kind: 'image' }, text: '빌드 완료', time: '16:41' },
    { you: true, reaction: '👍', text: '완벽해요, 고마워요.', time: '16:41' },
  ]}
/>

다른 종류도 같은 방식으로 도착합니다.

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'video', label: '데모 녹화' }, time: '16:42' },
    { name: 'Claude Code', media: { kind: 'voice', label: '0:24' }, time: '16:42' },
    { name: 'Claude Code', media: { kind: 'document', label: 'release-notes.pdf' }, text: '릴리스 노트', time: '16:43' },
  ]}
/>

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'sticker' }, time: '16:43' },
    { name: 'Claude Code', media: { kind: 'location', label: 'Café Brasileira, Chiado' }, time: '16:44' },
    { name: 'Claude Code', media: { kind: 'contact', label: 'Marta Souza', action: '메시지' }, time: '16:44' },
  ]}
/>

## 보낼 수 있는 것

| 휴대폰에 보이는 것                   | 종류       |
| ------------------------------------ | ---------- |
| WhatsApp 서식과 이모지가 있는 텍스트 | `text`     |
| 사진                                 | `image`    |
| 동영상                               | `video`    |
| 오디오 파일 또는 음성 메시지         | `audio`    |
| PDF 같은 파일                        | `document` |
| 스티커                               | `sticker`  |
| 지도 위의 핀                         | `location` |
| 연락처 카드 하나 이상                | `contacts` |
| 내 메시지에 대한 이모지 반응         | `reaction` |
| 탭할 수 있는 버튼 또는 목록          | `choice`   |

어느 것이든 내 메시지를 인용할 수 있습니다. 내가 AI에게 사진이나 파일을 보내면 AI도 받습니다.
