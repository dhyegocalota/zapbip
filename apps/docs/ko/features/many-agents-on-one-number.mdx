---
title: 여러 AI를 하나의 번호로
description: 내 답장이 그 대상 AI를 찾아가는 방법.
---

import { Chat } from '/snippets/chat.jsx';

모든 AI가 같은 WhatsApp 번호로 메시지를 보냅니다. zapbip은 다음 순서로 내 메시지의 목적지를 정합니다.

| 내가 하는 일                       | 전달되는 곳                |
| ---------------------------------- | -------------------------- |
| 버튼이나 목록 선택지를 탭한다      | 질문한 AI                  |
| 메시지에 답장하거나 반응한다       | 그 메시지를 보낸 AI        |
| `@grok check the news`라고 쓴다    | Grok (`@grok `는 제거됨)   |
| 한 AI의 질문이 열려 있을 때 답한다 | 그 AI                      |
| Claude만 말한 뒤에 쓴다            | 마지막으로 쓴 AI인 Claude  |
| 어디에도 해당하지 않을 때 쓴다     | 최근 AI 중에서 고르는 목록 |

## 예시

<Chat
  messages={[
    { name: 'Claude', text: '테스트가 통과했어요.', time: '10:02' },
    { name: 'Grok', text: 'main에 리베이스해도 될까요?', options: ['예', '아니요'], time: '10:03' },
    { you: true, text: '@claude 고마워요', time: '10:04' },
    { you: true, text: '예', time: '10:04' },
  ]}
/>

`@claude 고마워요`는 Claude에게 가고, "예" 탭은 Grok에게 갑니다.

<Chat
  messages={[
    { you: true, text: 'ok', time: '10:05' },
    { name: 'zapbip', text: 'Which AI is this for? Claude, Grok', options: ['Claude', 'Grok'], time: '10:05' },
  ]}
/>

그냥 `ok`라고 쓰면 최근 AI 중에서 고르는 목록이 옵니다.

메시지에 답장하면 그 메시지를 보낸 AI와 이야기할 수 있습니다.

<Chat
  messages={[
    { name: 'Claude', text: '테스트가 통과했어요.', time: '10:02' },
    { name: 'Grok', text: '출처를 3개 찾았어요.', time: '10:03' },
    { you: true, quote: { name: 'Grok', text: '출처를 3개 찾았어요.' }, text: '어떤 거예요?', time: '10:04' },
    { name: 'Grok', text: '논문 두 편과 보고서 하나예요. 링크를 보낼게요.', time: '10:04' },
  ]}
/>

이름은 최대 20자이며 소문자, 숫자, 하이픈을 쓸 수 있습니다.
