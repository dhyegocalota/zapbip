## AI에게 하는 말

<Chat messages={[{ you: true, text: '예약하기 전에 어느 호텔이 좋은지 물어보고, 내 답을 기다려 줘.', time: '09:14' }]} />

## 휴대폰에 보이는 모습

선택지가 3개까지면 버튼으로 표시됩니다.

<Chat
  messages={[
    { name: 'Claude', text: '리스본에서 어느 호텔로 할까요?', options: ['알파마', '바이샤', '벨렝'], time: '09:15' },
    { you: true, text: '바이샤', time: '09:16' },
    { name: 'Claude', text: '바이샤로 3박 예약할게요.', time: '09:16' },
  ]}
/>

선택지가 4~10개면 목록으로 표시됩니다.

<Chat
  messages={[
    {
      name: 'Claude',
      text: '어느 동네에서 찾아볼까요?',
      list: { title: '하나를 고르세요', rows: ['알파마', '바이샤', '벨렝', '시아두', '프린시페 헤알'] },
      time: '09:17',
    },
    { you: true, text: '시아두', time: '09:17' },
  ]}
/>

하나를 고르거나, 그냥 답을 입력하세요.

## 답이 늦어질 때

AI는 한동안 기다리고, 그 뒤에도 계속 기다립니다. 답이 늦게 도착해도 사라지지 않습니다.
