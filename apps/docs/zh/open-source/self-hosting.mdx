zapbip 是开源的。代码、背后的决策以及构建它的流程都公开在 [GitHub 仓库](https://github.com/dhyegocalota/zapbip)中。许可证见[许可证](/zh/open-source/license)页面。

## 运行自己的副本

| 方式         | 适合                           | 指南                                             |
| ------------ | ------------------------------ | ------------------------------------------------ |
| 在你的电脑上 | 试用 zapbip 并参与开发         | [在本地运行 zapbip](/zh/open-source/run-locally) |
| Docker       | 一条命令,数据保存在卷中        | [在本地运行 zapbip](/zh/open-source/run-locally) |
| Cloudflare   | 使用自己的 WhatsApp 号码上生产 | [部署到 Cloudflare](/zh/open-source/deploy)      |

## 参与贡献

- 请先阅读 [CONTRIBUTING](https://github.com/dhyegocalota/zapbip/blob/main/.github/CONTRIBUTING.md)。较大的改动前请先开一个 issue。
- 测试是必须的,所有贡献都适用[贡献者许可协议](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md)。
- 请按 [SECURITY](https://github.com/dhyegocalota/zapbip/blob/main/.github/SECURITY.md) 的说明私下报告漏洞,不要发在公开 issue 里。
- 所有人都遵守[行为准则](https://github.com/dhyegocalota/zapbip/blob/main/.github/CODE_OF_CONDUCT.md)。
