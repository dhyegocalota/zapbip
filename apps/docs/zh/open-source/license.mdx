zapbip 是开源的，代码的两个部分分别采用两种许可证。

| 部分                 | 许可证                                                                         |
| -------------------- | ------------------------------------------------------------------------------ |
| 服务器、网站和库     | [GNU AGPL v3.0](https://github.com/dhyegocalota/zapbip/blob/main/LICENSE)      |
| 本地连接器和渠道插件 | [MIT](https://github.com/dhyegocalota/zapbip/blob/main/apps/connector/LICENSE) |

[OpenClaw](https://github.com/dhyegocalota/zapbip/blob/main/apps/openclaw-plugin/LICENSE) 和 [Hermes](https://github.com/dhyegocalota/zapbip/blob/main/apps/hermes-plugin/LICENSE) 的渠道插件同样采用 MIT，每个包都带有自己的 `LICENSE` 文件。

## 贡献

所有贡献都适用[贡献者许可协议](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md)，协议中写明了下面这家公司。提交第一个 pull request 之前请先阅读。

## 公司

zapbip 是 Logic Bit 的产品。
