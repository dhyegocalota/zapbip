---
title: 'sign_in_link'
description: '通过 WhatsApp 把网页应用的登录链接发给所有者。'
---

把用于登录[网页应用](/zh/features/web-app)的一次性链接发给所有者。它就是替所有者执行的 `登录` 命令。它不需要批准，因为链接发给所有者，永远不会回到智能体手里。参见[让你的 AI 管理 zapbip](/zh/features/let-your-ai-manage-zapbip)。

删除账户不是工具。它仍然是 WhatsApp 命令。

## 输入

无。

## 输出

`{ "status": "applied" | "refused", "agent": null, "reason": string | null, "install_prompt": null }`。`refused` 且 `reason` 为 `window_closed`，表示 24 小时窗口已关闭：链接不会被排队，因为它会过期。`send_failed` 表示无法联系到所有者。链接永远不会出现在结果中。

适用与 [connect_agent](/zh/mcp-reference/connect-agent) 相同的限制：每个连接每分钟最多 3 次执行操作的调用。
