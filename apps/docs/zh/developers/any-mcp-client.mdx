---
title: 连接任意 MCP 客户端
description: 连接 URL、Bearer 替代方式和工具。
---

zapbip 通过可流式传输的 HTTP 使用 MCP。任何支持它的客户端，都可以使用 zapbip 提供给你的智能体的连接 URL 进行连接。

## 连接 URL

```text
https://<zapbip-host>/c/<secret>/mcp
```

URL 中的密钥就是这条连接本身。请保密。

## Bearer 替代方式

对于无法在 URL 中隐藏密钥的客户端，使用 `/mcp`，并把密钥放在请求头里发送：

```text
POST https://<zapbip-host>/mcp
Authorization: Bearer <secret>
```

两种形式连到同一个智能体。缺少密钥或密钥错误时，返回 `401`。
