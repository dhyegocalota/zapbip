import { Chat } from '/snippets/chat.jsx';

WhatsApp 只允许 zapbip 在你最后一次给它发消息之后的 24 小时内自由地给你发消息。

## 窗口开着

你的 AI 发来的消息会立即送达。

<Chat
  messages={[
    { you: true, text: '夜间任务完成后告诉我。', time: '22:10' },
    { name: 'Claude Code', text: '夜间任务已完成 ✅', time: '23:31' },
  ]}
/>

## 窗口关闭

你会收到一条通知，写明 AI 的名称和它消息的简短预览。随便写点什么，这些消息就会按顺序送达。超过 7 天的消息会过期。

<Chat
  messages={[
    { you: true, text: '夜间任务完成后告诉我。', time: '昨天 22:10' },
    { notice: true, text: 'The agent claude-code has a message for you: Nightly job finished ✅', time: '23:31' },
    { you: true, text: 'ok', time: '08:05' },
    { name: 'Claude Code', text: '夜间任务已完成 ✅', time: '08:05' },
  ]}
/>
