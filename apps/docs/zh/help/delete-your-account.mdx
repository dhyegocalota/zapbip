import { Chat } from '/snippets/chat.jsx';

你可以随时在 WhatsApp 上删除账号。需要发两条消息，所以不小心发出的一条消息不会删除任何东西。命令可以用中文、英语或葡萄牙语的词来输入，本页使用中文的词。

<Steps>
  <Step title="申请">发送 `删除账户`。zapbip 会告诉你将删除什么，以及确认所用的词组。</Step>
  <Step title="确认">在 10 分钟内发送 `永久删除账户`。超过这个时间不会删除任何东西；再次发送 `删除账户` 即可重新开始。</Step>
</Steps>

## 会删除什么

- 所有消息、提问和待处理的回复。
- 所有已连接的 AI。它们的提示词和链接会立即失效。
- 为你保存的文件。
- 你的手机号码和你的账号。

## Meta 和 Cloudflare 保留什么

- 聊天记录会保留在 WhatsApp 一侧。如果想从手机上清除，请在 WhatsApp 中删除该聊天。
- Cloudflare 会按它自己的保留期限保存备份副本。

## 重新开始

删除之后，同一部手机发来的消息会创建一个新的空账号。它会像其他新账号一样进入候补名单，参见[常见问题](/zh/help/faq)。

如果只想断开某一个 AI，参见[管理你的 AI](/zh/features/manage-your-agents)。

## 订阅

删除账户不会取消你的 zapbip Cloud 订阅。要取消订阅，请写信至 support@zapbip.com。
