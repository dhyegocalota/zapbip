## My AI's message did not arrive

The [24-hour window](/features/the-24-hour-window) is probably closed. Write anything to the zapbip number and the waiting messages arrive in order.

<Chat
  messages={[
    { notice: true, text: 'The agent claude-code has a message for you: Migration finished ✅', time: '07:12' },
    { you: true, text: 'ok', time: '07:30' },
    { name: 'Claude Code', text: 'Migration finished ✅', time: '07:30' },
    { name: 'Grok', text: 'Found 3 sources.', time: '07:30' },
  ]}
/>

## I wrote and my AI did not answer

Your AI was not listening. Your message waits for it, and zapbip tells you the AI is not listening right now.

<Chat
  messages={[
    { you: true, text: '@claude is the build green?', time: '14:20' },
    { notice: true, text: 'The agent claude is not listening right now. Your message waits in the inbox.', time: '14:20' },
  ]}
/>

Open the AI and ask it to check its messages, and see how each AI keeps listening in [Supported agents](/agents/supported-agents).

## My message went to the wrong AI

Start it with `@name`, for example `@grok check the news`, or reply directly to the AI's message.

<Chat
  messages={[
    { name: 'Grok', text: 'Found 3 sources.', time: '11:05' },
    { you: true, text: '@grok check the news', time: '11:06' },
    { you: true, quote: { name: 'Grok', text: 'Found 3 sources.' }, text: 'Which ones?', time: '11:07' },
  ]}
/>

See [Many AIs on one number](/features/many-agents-on-one-number).

## I sent a message and nothing came back

Your account may be on the waitlist. It is held until the zapbip team activates it. Wait, and send `help` when access opens.

## The link in my prompt does not work

The link works once, for 30 minutes. Write `rotate` and the AI's name, for example `rotate claude`, to get a new prompt. See [revoke and rotate](/help/revoke-and-rotate-keys).

## zapbip refused the name of my AI

A name has 1 to 20 lowercase letters, numbers or hyphens, starts with a letter or a number, and cannot start like a command. Send `new agent` with another name.

## zapbip says I reached the limit

You can have up to 8 connected AIs. Write `revoke` and the name of one you no longer use to free a slot.

## Something else

Technical errors, such as a rejected connection or an upload that failed, are listed under For developers.
