zapbip はオープンソースです。コード、その背景にある判断、それを作るプロセスは、[GitHub リポジトリ](https://github.com/dhyegocalota/zapbip)で公開されています。

## ライセンス

| 対象                                   | ライセンス    |
| -------------------------------------- | ------------- |
| サーバー、サイト、ライブラリ           | GNU AGPL v3.0 |
| ローカルコネクターとチャネルプラグイン | MIT           |

## 自分のコピーを動かす

| 方法                 | 向いている用途                            | ガイド                                                   |
| -------------------- | ----------------------------------------- | -------------------------------------------------------- |
| 自分のコンピューター | zapbip を試す、開発する                   | [zapbip をローカルで動かす](/ja/open-source/run-locally) |
| Docker               | コマンド 1 つで、データはボリュームに保存 | [zapbip をローカルで動かす](/ja/open-source/run-locally) |
| Cloudflare           | 自分の WhatsApp 番号での本番運用          | [Cloudflare にデプロイする](/ja/open-source/deploy)      |

## コントリビュート

- まず [CONTRIBUTING](https://github.com/dhyegocalota/zapbip/blob/main/.github/CONTRIBUTING.md) を読んでください。大きな変更の前には issue を作成してください。
- テストは必須で、すべての貢献は[コントリビューターライセンス契約](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md)の下で受け付けます。
- 脆弱性は [SECURITY](https://github.com/dhyegocalota/zapbip/blob/main/.github/SECURITY.md) の手順に従って非公開で報告し、公開の issue には書かないでください。
- 全員が[行動規範](https://github.com/dhyegocalota/zapbip/blob/main/.github/CODE_OF_CONDUCT.md)に従います。
