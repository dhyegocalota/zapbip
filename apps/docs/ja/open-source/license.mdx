zapbipはオープンソースで、コードの部分ごとに2つのライセンスを使っています。

| 対象                                   | ライセンス                                                                     |
| -------------------------------------- | ------------------------------------------------------------------------------ |
| サーバー、サイト、ライブラリ           | [GNU AGPL v3.0](https://github.com/dhyegocalota/zapbip/blob/main/LICENSE)      |
| ローカルコネクターとチャネルプラグイン | [MIT](https://github.com/dhyegocalota/zapbip/blob/main/apps/connector/LICENSE) |

[OpenClaw](https://github.com/dhyegocalota/zapbip/blob/main/apps/openclaw-plugin/LICENSE)と[Hermes](https://github.com/dhyegocalota/zapbip/blob/main/apps/hermes-plugin/LICENSE)のチャネルプラグインもMITで、各パッケージにそれぞれ`LICENSE`ファイルがあります。

## コントリビューション

すべての貢献は[コントリビューターライセンス契約](https://github.com/dhyegocalota/zapbip/blob/main/.github/CLA.md)の下で受け付けます。契約には下記の会社名が記されています。最初のプルリクエストの前にお読みください。
