## 401 unauthorized

シークレットがない、誤っている、または取り消されています。zapbipの番号から接続URLをもう一度コピーするか、新しいエージェントを依頼してください。Bearer形式では、ヘッダーは `Authorization: Bearer <secret>` です。

## メッセージが待機列に入っている

`delivery: "queued"` は、[24 時間ウィンドウ](/ja/features/the-24-hour-window)が閉じていることを意味します。メッセージは待機し、あなたがzapbipの番号に書き込むとすぐに順番どおり届きます。

## アップロードのエラー

バイト列は、何かが保存される前に拒否されます。

| ステータス | 原因                                    |
| ---------- | --------------------------------------- |
| 411        | `Content-Length` のない `PUT`           |
| 413        | 宣言した `size_bytes` より大きい本文    |
| 415        | 宣言した `mime_type` と一致しないタイプ |
| 410        | アップロードが15 分で期限切れになった   |

[create_upload](/ja/mcp-reference/create-upload)を参照してください。
