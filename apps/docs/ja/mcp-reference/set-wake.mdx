---
title: 'set_wake'
description: 'このエージェントが聞いていないときの届け方をzapbipに伝えます。'
---

あなたが書き込んだとき、待機中の呼び出しがない場合に、この接続をどう起こすかを保存します。[ウェイクラダー](/ja/concepts/wake-ladder)と[Webhookウェイクのガイド](/ja/developers/webhook-wake)をご覧ください。

## 入力

| フィールド         | 型            | 備考                                                                                                                                                                                                                                                       |
| ------------------ | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mode`             | string        | `local` は[コネクタ](/ja/developers/local-connector)経由で起こします。`webhook` はWebhookを保存します。`scheduled` はエージェントにタイマーで受信トレイを確認させます。`standby` はメッセージを別のエージェントに渡します。`none` はウェイクを解除します。 |
| `url`              | string、任意  | `webhook` では必須。`https`、userinfoなし、フラグメントなし、ポートは443または省略、最大512文字。ホストでプロバイダーが決まります。                                                                                                                        |
| `token`            | string、任意  | `webhook` では必須。表示可能な文字で、空白なし、16〜512文字。汎用Webhookでは署名キーで、32文字以上です。                                                                                                                                                   |
| `interval_minutes` | integer、任意 | `scheduled` では必須。1〜1440 分。ChatGPTとclaude.aiは、スケジュールタスクを最短でも60 分ごとに実行します。                                                                                                                                                |
| `standby_agent`    | string、任意  | `standby` では必須。同じアカウントの別の接続の名前で、それ自体が待機の接続でないもの。                                                                                                                                                                     |

別のモードのフィールドは指定してはいけません。

## スケジュール

外から起動できないエージェントは、[check_inbox](/ja/mcp-reference/check-inbox) を呼ぶタスクをタイマーで実行します。これにより、時間制限なく聞き続け、メッセージごとに `send_message` で答えられます。

```json
{ "mode": "scheduled", "interval_minutes": 60 }
```

あなたが書き込むと、zapbipは答えがいつ届くかをお知らせします。間隔の2倍の間、確認が行われなかった場合、通知が1つ届き、メッセージは次の確認まで受信トレイで待ちます。

## ローカル

[コネクタ](/ja/developers/local-connector)があなたのコンピュータで動いている間に、エージェントにこのツールを `{ "mode": "local" }` で呼ぶよう依頼します。

## 待機

起こせないエージェントは、同じアカウントの別のエージェントを、代わりに答える役として指定します。zapbipはあなたのメッセージを待機の接続にコピーして起こし、待機の接続は自分として答えます。

```json
{ "mode": "standby", "standby_agent": "grok-bot" }
```

待機の接続が別の待機の接続へ転送することはありません。1 ホップだけです。待機の接続が存在しない、削除された、またはそれ自体が待機モードの場合は、何もコピーされず、メッセージは最初のエージェントのところで待ちます。

## プロバイダー

プロバイダーはURLのホストで決まり、フィールドで指定することはありません。

| プロバイダー     | ホスト                              | パス                                         | 認証                                                                     |
| ---------------- | ----------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------ |
| `grok_routine`   | `api2.cursor.sh`                    | `/automations/webhook/<routine-id>`          | `Authorization: Bearer <token>`                                          |
| `claude_routine` | `api.anthropic.com`                 | `/v1/claude_code/routines/<trigger-id>/fire` | `Authorization: Bearer <token>`                                          |
| `generic`        | 公開されている任意の `https` ホスト | 任意                                         | `X-Zapbip-Timestamp` と `X-Zapbip-Signature`。シークレットは送信しません |

## 出力

`{ "status": "saved", "wake_mode": string, "effective_rung": string, "provider": string | null }`。`provider` が設定されるのは `webhook` のときだけです。`effective_rung` は、待機が使えないとき、およびコネクタが接続されていない間の `local` では `inbox` になります。その場合メッセージは受信トレイで待つためです。URL、トークン、ホストが返されることはありません。

## エラー

ツールのエラーは、無効なフィールド（`url`、`token`、`interval_minutes`、`standby_agent`、`mode`）とその制限を示し、値をそのまま返すことはありません。何も保存されず、以前のウェイクが維持されます。zapbipは保存時にプロバイダーを呼び出しません。誤ったトークンは、最初のウェイクで、WhatsAppにあなた宛ての通知として現れます。
