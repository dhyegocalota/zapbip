待たずに受信トレイを確認します。

## 入力

フィールドはありません。

## 出力

すぐに `{ "status": "empty" }` が返るか、`{ "status": "new", "messages": [...] }` が返ります。返されたメッセージは既読になります。スケジュールタスク向けで、低コストで応答します。
