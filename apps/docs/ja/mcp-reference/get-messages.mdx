未読のオーナーメッセージと最近の履歴を読みます。

## 入力

| フィールド | 型           | 備考         |
| ---------- | ------------ | ------------ |
| `limit`    | number、任意 | 履歴の件数。 |

## 出力

未読のオーナーメッセージ（既読になります）と、直近にやり取りされた20件のメッセージ。
