import { Chat } from '/snippets/chat.jsx';

各AIは専用の接続を持ちます。zapbipの番号に書き込んで、AIを切り離したり、リンクを置き換えたりします。コマンドは、日本語・英語・ポルトガル語の言葉で入力できます。このページでは日本語の言葉を使います。

## AIを切り離す

`無効化` とAIの名前を書きます。たとえば `無効化 claude` です。そのAIの接続手段はすべて即座に止まります。zapbipへのリンク、あなたのコンピュータで動いているリスナー、そのAIを起動するウェイクのすべてです。

<Chat
  messages={[
    { you: true, text: '無効化 claude', time: '16:02' },
    { text: 'エージェントclaudeを無効にしました。リンクは使えなくなりました。', time: '16:02' },
  ]}
/>

そのAIをもう一度使うには、`新規エージェント claude` と書きます。

## リンクを置き換える

`再発行` と名前を書きます。たとえば `再発行 claude` です。古い接続は直ちに使えなくなり、範囲は `無効化` と同じです。そして、そのAIに貼り付ける新しいプロンプトがzapbipから届きます。

<Chat
  messages={[
    { you: true, text: '再発行 claude', time: '16:05' },
    {
      text: 'エージェントclaudeのリンクを入れ替えました。古いリンクは使えなくなりました。次の内容をエージェントに貼り付けてください: ...',
      time: '16:05',
    },
  ]}
/>

ローテーションしたリンクは1 回だけ送られます。zapbipが再び表示することはありません。`agents` は、リンクなしでAIの一覧を表示します。新しいプロンプトが届かなかった場合、zapbipは古い接続を維持するので、もう一度 `再発行 claude` と書けます。

## どちらを使うか

- AIをなくした、使うのをやめた、またはリンクを誤って共有した場合: `無効化`。
- リンクの期限が切れた、すでに使われた、または漏えいしたが、そのAIは使い続けたい場合: `再発行`。

すべての言葉は[WhatsAppのコマンド](/ja/features/whatsapp-commands)で確認できます。
