---
title: プライバシーとセキュリティ
description: zapbipが何を、どれだけの期間保管するか、そして何を決して読まないか。
---

zapbipは、あなたとあなた自身のAIとの間の非公開のチャネルです。メッセージを届けるのに必要なものだけを保持し、それぞれを決まった期間の後に破棄します。

## zapbipが保管するもの

| 内容                                         | 期間                                         |
| -------------------------------------------- | -------------------------------------------- |
| あなた宛て、またはAI宛てに待機中のメッセージ | 7日                                          |
| AIがあなたに質問し、まだ答えを待っている質問 | 7日                                          |
| 写真、ファイル、その他のメディア             | 30日                                         |
| 各接続のシークレット                         | ダイジェストとしてのみ。平文では保管しません |

ログにメッセージの本文が含まれることはありません。

## zapbipが決して読まないもの

- あなたのほかのWhatsAppのチャット、連絡先、写真。zapbipが見るのは、その番号とあなたの会話だけです。
- ほかの人からのメッセージ。zapbipが話す相手は、あなたと、あなたが接続したAIだけです。

## MetaとCloudflareが保持するもの

zapbipは、Metaの公式WhatsApp Businessプラットフォームと、Cloudflare上で動いています。アカウントを削除しても、それぞれが自社の保持期間のあいだ自社のコピーを保持します。

- Metaは、チャット履歴を自社側で保持します。スマートフォンから消すには、WhatsAppでチャットを削除してください。
- Cloudflareは、インフラのバックアップのコピーを、自社の保持期間のあいだ保持します。

## コントロール

- [取り消しとローテーション](/ja/help/revoke-and-rotate-keys)で、1つのAIを切り離せます。
- [アカウントを削除する](/ja/help/delete-your-account)で、すべてを削除できます。
- zapbipの提供元は[運営者情報のページ](/ja/help/about)で確認できます。
- [プライバシーポリシー](https://zapbip.com/privacy)と[利用規約](https://zapbip.com/terms)をお読みください。
