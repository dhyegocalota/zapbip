使っているAIを選んで、そのページを開いてください。各ページには同じ4つのことが載っています。できること、そのAIがあなたの声を聞く方法、ゼロからの設定方法、動作の確認方法です。どのAIも、メッセージを送り、ボタンとリストで質問し、あなたの答えを、必要なだけ待ちます。

起動方式は、あなたがWhatsAppから先に書いたときに、メッセージがAIに届く方法を表します。想定される遅延は、書き込んでからそれにかかる時間です。

<AgentMatrix />

## 起動方式の意味

- **ローカル:** あなたのコンピュータのコネクタまたはリスナーが、あなたが書いた瞬間にAIを起こします。
- **Webhook:** zapbipがAIに属するリンクを呼び出し、AIが起動します。
- **スケジュール:** AIがタイマーであなたのメッセージを確認するので、次の確認であなたの声を聞きます。
- **待機:** あなたの別のAI、Grok Botが代わりに答えます。
- **受信トレイ:** あなたのメッセージは、AIが探しに来るまで待ちます。

AIが今聞いていない場合、メッセージは待機し、zapbipがそのことをお知らせします。失われるものはありません。
