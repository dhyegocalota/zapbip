## 使えること

| できること                                     | MCP対応アプリ                    |
| ---------------------------------------------- | -------------------------------- |
| テキスト、写真、動画、音声、ドキュメントを送る | はい                             |
| 位置情報、連絡先、リアクションを受け取る       | はい                             |
| ボタンまたはリストで質問して待つ               | はい                             |
| あなたが先に書いたときに会話を始める           | メッセージは受信トレイで待ちます |

## 聞き取りの仕組み

段: 受信トレイ。外からアプリを起こす方法がないため、あなたが送ったメッセージは、アプリが見に来るまで受信トレイで待ちます。アプリは `check_inbox` で、zapbipに新しいものが待っているか尋ね、それを読みます。

聞き続けるために、アプリは `ask` または `wait_for_reply` であなたに尋ねます。あなたが答えないままだと、各呼び出しは最大50 秒で保留中（pending）を返し、アプリは答えが来るまでもう一度呼び出します。時間制限なしです。

## ゼロから設定する

1. **WhatsAppでzapbipの番号にメッセージを送ります。** `新規エージェント my-app` を送ってください。コマンドは今のところ英語かポルトガル語の言葉で入力します。すべてのメッセージは[始め方](/ja/get-started/how-to-start)で確認できます。

   <Chat
     messages={[
       { you: true, text: '新規エージェント my-app', time: '09:00' },
       { name: 'zapbip', text: 'Agent my-app created. Paste this into your agent.', time: '09:00' },
     ]}
   />

2. **その1行を、アプリのAIに貼り付けます。** zapbipが、あなた専用の1行で返信します。

   <InstallPrompt />

3. **サーバーを追加します。** アプリのMCP設定で、AIがzapbipのアドレスを、ストリーミング可能なHTTPサーバーとして追加します。アドレスにはシークレットが含まれるので、非公開にしてください。アプリがヘッダーを求める場合は、シークレットを `Authorization: Bearer <secret>` として送ります。

4. **ときどき受信トレイを確認します。** アプリは、可能なときに `check_inbox` を呼びます。たとえば、各タスクの開始時です。

## 動作の確認

AIに、WhatsAppで `✅ インストール完了` を送るよう頼んでください。届けば、接続は機能しています。

<Chat messages={[{ name: 'My app', text: '✅ インストール完了', time: '09:03' }]} />

次にWhatsAppで何か書き、アプリに受信トレイを確認するよう頼んでください。あなたのメッセージが読まれます。

アドレス、ヘッダー、ツールについては、[任意のMCPクライアントを接続する](/ja/developers/any-mcp-client)をご覧ください。
