WhatsAppのコマンドは、日本語・英語・ポルトガル語の言葉で入力できます。このページでは日本語の言葉を使います。

1. **WhatsAppでzapbipの番号にメッセージを送ります。** 任意のテキスト、たとえば `hi` を送ってください。最初のメッセージでアカウントが作られ、その電話があなたのものだと確認されます。

   <StartLink />

   <Chat
     messages={[
       { you: true, text: 'hi', time: '09:00' },
       { name: 'zapbip', text: '接続されているエージェントがありません。メッセージは保管されています。', time: '09:00' },
     ]}
   />

2. **新しいエージェントを依頼します。** エージェントとは、接続するAI1つのことです。`新規エージェント` と名前を送ります。たとえば `新規エージェント claude` です。

3. **プロンプトを受け取ります。** zapbipが、あなた専用の1〜2行で返信します。

   <Chat
     messages={[
       { you: true, text: '新規エージェント claude', time: '09:01' },
       {
         name: 'zapbip',
         text: 'エージェントclaudeを作成しました。次の内容をエージェントに貼り付けてください: zapbipで私のWhatsAppにつながってください。https://mcp.zapbip.com/i/zb_inst_<code>を読み、手順に従ってください。 このリンクは30分間、1回だけ使えます。共有しないでください。 リンクの期限が切れた場合や使用済みの場合は、「再発行 claude」と送信してください。',
         time: '09:01',
       },
     ]}
   />

4. **AIに貼り付けます。** ChatGPT、Claude、Grok、または普段使っているAIを開き、zapbipから届いた1行を貼り付けます。次のような内容です。

   <InstallPrompt />

   AIはオンラインで指示を読み、自分で設定を行います。

5. **AIからメッセージが届きます。** 接続を確認するために、WhatsAppに最初のメッセージを送ってきます。

   <Chat messages={[{ name: 'Claude', text: '✅ installed', time: '09:03' }]} />

<Note>
  claude.ai、ChatGPT、Web版のGrokでは、お願いが1つあります。AIが、設定でコネクタを追加するよう案内します。その案内に従ってください。これはそれらのアプリの決まりです。
</Note>

## 知っておくこと

- すべてのAIに使うWhatsApp番号は1つです。AIごとに1行が発行されるので、見分けられます。
- その1行は1回だけ使え、30 分で期限が切れます。期限が切れたら `再発行 claude` と送ると新しいものが届きます。
- いつでも自分から書けます。AIは時間制限なく聞き続けます。
- ウェイトリストに載っている場合は、この後どうなるかを[FAQ](/ja/help/faq)で確認してください。
- 使うAIを選んで、[対応エージェント](/ja/agents/supported-agents)にあるそのページに従ってください。
