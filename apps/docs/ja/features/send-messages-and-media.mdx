import { Chat } from '/snippets/chat.jsx';

AIは、WhatsAppで運べるものなら何でもあなたに送れます。

## こんなふうに届きます

<Chat
  messages={[
    { you: true, text: '完成したビルドのスクリーンショットを、「ビルド完了」というキャプション付きで送って。', time: '16:40' },
    { name: 'Claude Code', media: { kind: 'image' }, text: 'ビルド完了', time: '16:41' },
    { you: true, reaction: '👍', text: '完璧、ありがとう。', time: '16:41' },
  ]}
/>

ほかの種類も同じように届きます。

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'video', label: 'デモ録画' }, time: '16:42' },
    { name: 'Claude Code', media: { kind: 'voice', label: '0:24' }, time: '16:42' },
    { name: 'Claude Code', media: { kind: 'document', label: 'release-notes.pdf' }, text: 'リリースノート', time: '16:43' },
  ]}
/>

<Chat
  messages={[
    { name: 'Claude Code', media: { kind: 'sticker' }, time: '16:43' },
    { name: 'Claude Code', media: { kind: 'location', label: 'Café Brasileira, Chiado' }, time: '16:44' },
    { name: 'Claude Code', media: { kind: 'contact', label: 'Marta Souza', action: 'メッセージ' }, time: '16:44' },
  ]}
/>

## 送れるもの

| スマートフォンに表示されるもの             | 種類       |
| ------------------------------------------ | ---------- |
| テキスト。WhatsAppの書式と絵文字が使えます | `text`     |
| 写真                                       | `image`    |
| 動画                                       | `video`    |
| 音声ファイルまたはボイスメッセージ         | `audio`    |
| PDFなどのファイル                          | `document` |
| スタンプ                                   | `sticker`  |
| 地図上のピン                               | `location` |
| 1件以上の連絡先カード                      | `contacts` |
| あなたのメッセージへの絵文字リアクション   | `reaction` |
| タップするボタンまたはリスト               | `choice`   |

どれも、あなたのメッセージを引用できます。あなたがAIに写真やファイルを送ると、AIもそれを受け取ります。
