AIの管理は、zapbipの番号に書き込んで行います。コマンドは、日本語または英語の短い言葉です。ポルトガル語、スペイン語、ドイツ語、フランス語、韓国語、中国語にもそれぞれのコマンドがあります。書いた言語が返信の言語になります。表の各行に両方の言い方を示します。

| やりたいこと            | 日本語で入力                                  | または英語で入力                                      | 何が起こるか                                                                              |
| ----------------------- | --------------------------------------------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 新しいAIを接続する      | `新規エージェント claude`                     | `new agent claude`                                    | zapbipが、そのAIに貼り付けるプロンプトを返信します                                        |
| AIの一覧を見る          | `エージェント一覧`                            | `agents`                                              | 各AIの名前と日付の一覧                                                                    |
| AIを切断する            | `無効化 claude`                               | `revoke claude`                                       | そのAIが即座に使えなくなります                                                            |
| 新しいプロンプトを得る  | `再発行 claude`                               | `rotate claude`                                       | 古い接続が止まり、新しいプロンプトが届きます                                              |
| Webアプリにログインする | `ログイン`                                    | `login`                                               | 10 分間、1回だけ使えるリンク。[Webアプリ](/ja/features/web-app)を参照                     |
| メニューを開く          | `ヘルプ` または `menu`                        | `help` または `menu`                                  | コマンドがテキストとタップできるリストで表示されます                                      |
| 言語を変更する          | `言語 ja`                                     | `language ja`                                         | zapbipが、選んだ言語で返信します。コードは `en`、`pt`、`es`、`de`、`fr`、`ja`、`ko`、`zh` |
| アカウントを削除する    | `アカウント削除`、続けて `アカウント完全削除` | `delete account`、続けて `delete account permanently` | [アカウントを削除する](/ja/help/delete-your-account)を参照                                |

言葉だけを書いてください。末尾に `?` や `!` が付くと、AI宛ての通常のメッセージとして扱われます。

## 例

zapbipの返信が日本語なのは、日本語で書いたからです。

  ]}

## コマンド語をAIに伝えるには

メッセージがコマンド語だけのときは、常にコマンドとして扱われます。同じ言葉をAIに送るには、AIの名前から始めます。`@claude help` は、メニューを開かずにClaudeに届きます。

## 名前

`新規`、`エージェント`、`無効化`、`再発行`、`ヘルプ`、`menu`、`ログイン`、`アカウント` といった言葉と、その英語・ポルトガル語版は予約されており、AIの名前には使えません。

## 転送されたメッセージ

転送されたメッセージは、本文がコマンド語であってもコマンドになりません。ほかのメッセージと同じようにAIに届きます。
