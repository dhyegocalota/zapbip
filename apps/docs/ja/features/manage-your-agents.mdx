各AIは、あなたのWhatsAppへの専用の接続を持ちます。すべてzapbipの番号に書き込んで管理します。コマンドは、今のところ英語かポルトガル語の言葉で入力します。このページでは英語の言葉を使います。

## 新しいAIを接続する

`new agent` と名前を書きます。たとえば `new agent claude` です。zapbipは2行で返信します。それをそのAIに貼り付けると、AIがリンク先の指示を読み、自分で接続します。

名前は自動的に整えられます。アクセント記号は取り除かれ、英字は小文字になり、スペースはハイフンに変わるので、`Claude Code` は `claude-code` になります。名前は20文字まで、文字か数字で始まり、接続中のAIの間で重複できません。切断した名前は再利用できます。

## リンクは1回だけ使えます

プロンプトのリンクは30 分間有効で、AIが最初に接続した時点で無効になります。それまでは、リンクを持っている人は誰でもそのAIとして接続できてしまうので、公開の場に投稿しないでください。期限が切れた場合や、誤って共有してしまった場合は、`rotate claude` と書くと新しいリンクが届きます。

## AIの一覧を見る

`agents` と書きます。zapbipは、接続中の各AIの名前、作成日、アプリを一覧にして返します。リンクは表示しません。

## AIを切断する

`revoke claude` と書きます。そのAIの接続手段はすべて即座に止まります。zapbipへのリンク、あなたのコンピュータで動いているローカルリスナー、そのAIを起動するウェイクのすべてです。そのAIをもう一度使うには、`new agent claude` と書きます。

## 新しいプロンプトを受け取る

`rotate claude` と書きます。古い接続は直ちに使えなくなり、範囲は `revoke` と同じです。リンク、接続中のローカルリスナー、ウェイクのすべてが止まります。新しいプロンプトが届きます。zapbipが新しいプロンプトを届けられなかった場合、古い接続は維持されます。

## 上限

接続できるAIは8つまでです。切断したものは数えません。上限に達すると、zapbipがそのことを伝え、`revoke` を案内します。

すべての言葉は[WhatsAppのコマンド](/ja/features/whatsapp-commands)で確認できます。
