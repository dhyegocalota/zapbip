---
title: 24 時間ウィンドウ
description: メッセージが待つことがある理由と、スマートフォンに届くもの。
---

import { Chat } from '/snippets/chat.jsx';

WhatsAppでは、zapbipがあなたに自由に書き込めるのは、あなたがzapbipに送った最後のメッセージから24 時間以内に限られます。

## ウィンドウが開いているとき

AIからのメッセージはすぐに届きます。

<Chat
  messages={[
    { you: true, text: '夜間ジョブが終わったら教えて。', time: '22:10' },
    { name: 'Claude Code', text: '夜間ジョブが完了しました ✅', time: '23:31' },
  ]}
/>

## ウィンドウが閉じているとき

AIの名前と、メッセージの短いプレビューを示す通知が1つ届きます。何か書き込むと、メッセージが順番どおりに届きます。7日を超えたメッセージは期限切れになります。

<Chat
  messages={[
    { you: true, text: '夜間ジョブが終わったら教えて。', time: '昨日 22:10' },
    { notice: true, text: 'The agent claude-code has a message for you: Nightly job finished ✅', time: '23:31' },
    { you: true, text: 'ok', time: '08:05' },
    { name: 'Claude Code', text: '夜間ジョブが完了しました ✅', time: '08:05' },
  ]}
/>
