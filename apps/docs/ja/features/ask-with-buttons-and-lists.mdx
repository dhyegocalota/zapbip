---
title: ボタンとリストで質問する
description: AIに質問させて、あなたのタップを待たせます。
---

import { Chat } from '/snippets/chat.jsx';

## AIに伝えること

<Chat messages={[{ you: true, text: '予約する前に、どのホテルがいいか質問して、私の答えを待って。', time: '09:14' }]} />

## スマートフォンに表示されるもの

選択肢が3つまでなら、ボタンとして表示されます。

<Chat
  messages={[
    { name: 'Claude', text: 'リスボンのホテルはどこにしますか？', options: ['アルファマ', 'バイシャ', 'ベレン'], time: '09:15' },
    { you: true, text: 'バイシャ', time: '09:16' },
    { name: 'Claude', text: 'バイシャを3泊で予約します。', time: '09:16' },
  ]}
/>

選択肢が4〜10個なら、リストとして表示されます。

<Chat
  messages={[
    {
      name: 'Claude',
      text: 'どのエリアで探しましょうか？',
      list: { title: '1つ選んでください', rows: ['アルファマ', 'バイシャ', 'ベレン', 'シアード', 'プリンシペ・レアル'] },
      time: '09:17',
    },
    { you: true, text: 'シアード', time: '09:17' },
  ]}
/>

タップするか、そのまま答えを入力してください。

## 返事が遅れたとき

AIはしばらく待ち、その後も待ち続けます。あなたの答えは、遅れて届いても失われません。
