title: AIにzapbipを任せる
description: AIが、あなたのAIの一覧表示、接続、切断、Webアプリの起動をしてくれます。変更はすべて、WhatsAppでのあなたのタップを待ちます。
---

[Webアプリ](/ja/features/web-app)や[WhatsAppコマンド](/ja/features/whatsapp-commands)でできることは、すべてAIが代わりにできます。主導権はあなたにあります。変更にはWhatsAppでのタップが必要で、それがなければ何も起きません。

## AIにできること

| AIに頼むこと         | 何が起きるか                                                             | タップが必要 |
| -------------------- | ------------------------------------------------------------------------ | ------------ |
| AIの一覧を見る       | 各AIの名前、接続元のアプリ、作成日時、最終アクティブ日時を読み取ります。 | いいえ       |
| アカウントを確認する | アカウントの状態とプランを読み取ります。                                 | いいえ       |
| 新しいAIを接続する   | zapbipがWhatsAppであなたに確認し、そのあとで接続します。                 | はい         |
| AIを切断する         | zapbipがWhatsAppであなたに確認し、そのあとでそのAIをただちに止めます。   | はい         |
| Webアプリを開く      | zapbipがWhatsAppでログインリンクを送ります。                             | いいえ       |

アカウントの削除は一覧に含まれません。これまでどおり、あなただけが送れるWhatsAppコマンドです。

## タップのしくみ

AIが`helper`という名前の新しいAIの接続を求めると、zapbipは、求めたAIとして、WhatsAppであなたにメッセージを送ります。

- **Allow**: 接続し、そのAIに貼り付けるリンクを、`新規エージェント`と同じようにあなたへ送ります。
- **Allow, send to agent**: 接続し、リンクを求めたAIに渡します。AIが自分でセットアップを終えられます。
- **Deny**: 何も変更しません。

切断のボタンは、AllowとDenyの2つです。ボタンのタップだけが有効です。入力したメッセージは、Allowという言葉であってもDenyとして扱われます。質問の最後には短い参照が付くので、古い質問への返答が新しい質問に使われることはありません。

AIは、あなたの返答を最長50秒待ちます。時間内に答えなければ何も変わらず、その後のタップでも何も変わりません。Denyされた場合や返答がなかった場合、同じAIからの同じリクエストは10分間拒否されるため、何度も聞き直すことはできません。

## 非公開のまま守られるもの

- 新しいAIを接続するためのリンクは、WhatsAppであなたに届きます。**Allow, send to agent**のボタンだけが、それをAIに渡します。
- ログインリンクはあなたにだけ届きます。AIがそれを見ることはありません。24時間ウィンドウが閉じている場合、zapbipはリンクを待機させません。zapbipにメッセージを送ってから、もう一度AIに頼んでください。
- AIが、キー、コード、あなたの電話番号を見ることはありません。

## 制限

接続ごと、そしてアカウント全体で、1分間に開始できる変更は3件までです。4件目には「少ししてからもう一度」という短い返答が返るので、誤ったループでWhatsAppが質問であふれることはありません。
