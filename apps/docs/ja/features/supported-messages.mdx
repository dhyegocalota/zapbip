---
title: 対応しているメッセージ
description: AIが受け取り、送信できるWhatsAppのメッセージ種類、zapbipが無視するもの、公式APIだけを使う理由。
---

zapbipは以下のメッセージ種類を両方向で扱います。ここにない種類は対応していません。

## AIが受け取るもの

| 種類       | あなたが送るもの                   | AIが受け取るもの                                                                     |
| ---------- | ---------------------------------- | ------------------------------------------------------------------------------------ |
| `text`     | メッセージ                         | テキスト                                                                             |
| `image`    | 写真                               | 写真。zapbipが保存します                                                             |
| `video`    | 動画                               | 動画。zapbipが保存します                                                             |
| `audio`    | 音声ファイルまたはボイスメッセージ | 音声。zapbipが保存します。ボイスメッセージは区別されて届きます                       |
| `document` | PDFなどのファイル                  | ファイル。名前と種類とともにzapbipが保存します                                       |
| `sticker`  | スタンプ                           | スタンプ。zapbipが保存します                                                         |
| `location` | 位置情報のピン                     | 緯度、経度、名前、住所                                                               |
| `contacts` | 1件以上の連絡先カード              | 連絡先カード                                                                         |
| `reaction` | 絵文字のリアクション               | 絵文字と、リアクションされたメッセージ。リアクションを取り消すと絵文字なしで届きます |
| `choice`   | ボタンまたはリストの行をタップ     | 質問への答えとなる選択                                                               |

AIのメッセージへの返信は、そのメッセージを送ったAIに届きます。

ほかの種類を送った場合は、その種類はまだ対応していないという短い通知が届き、AIには何も届きません。注文（order）やWhatsApp Flowの返信も同様です。zapbipの通知の「開く」ボタンをタップすると、[24時間の受付時間](/ja/features/the-24-hour-window)が開くだけです。通話やその他のアカウントイベントは無視されます。

## AIが送れるもの

| 種類       | AIが送れるもの                                                           |
| ---------- | ------------------------------------------------------------------------ |
| `text`     | 4,096文字までのテキストメッセージ                                        |
| `image`    | 写真：JPEG、PNG、WebP、5 MBまで                                          |
| `video`    | 動画：3GPまたはMP4、16 MBまで                                            |
| `audio`    | 音声ファイル：AAC、AMR、MP3、M4A、OGG、16 MBまで。またはボイスメッセージ |
| `document` | ファイル：PDF、Word、Excel、PowerPoint、プレーンテキスト、100 MBまで     |
| `sticker`  | 静止画のWebPスタンプ、100 KBまで                                         |
| `location` | 位置情報のピン                                                           |
| `contacts` | 1件以上の連絡先カード                                                    |
| `reaction` | あなたのメッセージへの絵文字リアクション。または取り消しのための空       |
| `choice`   | ボタン最大3つ付きの質問、または4〜10件の選択肢のリスト                   |

zapbipは、これらの制限を超える送信を拒否し、誤っているフィールドを伝えます。投票、注文、支払い、WhatsApp Flows、通話は利用できません。AIがWhatsAppのテンプレートを選ぶことはできません。zapbipが自分の通知を送るのは、24時間の受付時間が閉じているときだけです。

## 公式WhatsApp Cloud APIのみ

zapbipは、Metaの公式WhatsApp Cloud APIのみを通じて、zapbipの番号で送受信します。次のものには対応していません。

- Baileys、whatsapp-web.js、WPPConnect、Evolution APIなど、非公式のWhatsAppクライアントやライブラリ；
- WhatsApp Webの自動化、および個人アカウントやQRコードでログインするあらゆるブリッジ；
- あなた個人のWhatsApp番号。どのAIもzapbipの番号から書き、あなたはいつものWhatsAppで返信します。

短い回答は[よくある質問](/ja/help/faq)をご覧ください。
