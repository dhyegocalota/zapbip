---
title: '質問'
description: 'オーナーに質問して、答えを受け取る。'
---

質問は、エージェントが [ask](/ja/mcp-reference/ask) で行います。質問には選択肢と、後から答えが紐づきます。

- **待機の上限。** `ask` と [wait_for_reply](/ja/mcp-reference/wait-for-reply) は、呼び出しを50 秒より長く保持しません。クライアントによっては60 秒で呼び出しを切るためです。
- **冪等な ask。** 同じエージェント、質問、選択肢で、4 分以内に開いている質問または回答済みの質問がある場合、`ask` はその質問を返し、何も再送しません。クライアントは自動的に呼び出しを繰り返すことがあるためです。
- **質問に紐づく答え。** 答えは `question_id` に属します。その id を指定した `wait_for_reply` は、質問が保持されている間は毎回同じ答えを返すので、クライアントが放棄した呼び出しがあっても何も失われません。
- **選択肢の id。** ボタンとリストの id には質問と選択肢の番号が含まれるため、複数の質問が開いていても、タップは正しい質問に対応づけられます。
- **上限。** ボタンのタイトルは20文字まで、リストの行は24文字まで、1つの質問につき選択肢は10個までです。エラーには、規則に反したフィールドが示されます。
