title: 'WhatsAppチャネル'
description: 'メッセージがオーナーとエージェントの間をどう流れるか、そしてWhatsAppが定める制限。'
---

zapbipは、すべてのアカウントで共有する1つの番号から、公式のWhatsApp Cloud APIを通してオーナーと話します。

## 受信メッセージ

オーナーが番号に書き込みます。zapbipはすべての通知の署名を検証し、WhatsAppが同じメッセージを2回配信しても1回だけ保存して、[ルーティングルール](/ja/concepts/routing)で1つのエージェントに振り分けます。

| オーナーが送るもの                                                   | エージェントが受け取るもの                                                                           |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| テキスト、画像、動画、音声、ボイスメッセージ、ドキュメント、スタンプ | メッセージ。メディアはzapbipが保管します                                                             |
| 位置情報、連絡先カード                                               | メッセージ                                                                                           |
| ボタンまたはリストの行での返信                                       | 選択。質問への答えになります                                                                         |
| リアクション                                                         | リアクション。リアクションされたメッセージを送ったエージェントに届き、取り消しは絵文字なしで届きます |
| それ以外の種類のメッセージ                                           | なし。オーナーには、その種類がまだ対応していないと伝えられます                                       |

オーナーが送ったメッセージは[24 時間ウィンドウ](/ja/concepts/24-hour-window)を開きます。リアクションでは開きません。

ファイルをダウンロードできなかった場合、エージェントは `media_id: null` と `media_status: "unavailable"` のついたメッセージを受け取り、オーナーにはもう一度送るよう依頼されます。

## 送信メッセージ

ウィンドウ内では、どの種類もすぐに送信されます。ウィンドウ外ではメッセージは待機列に入り、オーナーには[通知](/ja/concepts/owner-notices)が届きます。

| 種類         | 制限                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| テキスト     | 4,096文字                                                                                             |
| ボタン       | ボタンは3つまで、質問は1,024文字まで、タイトルは20文字まで                                            |
| リスト       | 行は10個まで、質問は1,024文字まで、ボタンは20文字まで、行のタイトルは24文字まで、行の説明は72文字まで |
| リアクション | リアクション先のメッセージは30日以内で、同じスレッドにあり、削除されていないこと                      |
| 画像         | JPEG、PNG、WebP、最大5 MB                                                                             |
| 動画         | 3GPまたはMP4、最大16 MB                                                                               |
| 音声         | AAC、AMR、MP3、M4A、OGG、最大16 MB                                                                    |
| ドキュメント | PDF、Word、Excel、PowerPoint、またはプレーンテキスト、最大100 MB                                      |
| スタンプ     | 静止画のWebP、最大100 KB                                                                              |

zapbipは制限に違反する送信を拒否し、ツールはフィールドを示すエラーを返します。

## 配信状況

メッセージの `delivery` は前にしか進みません。`sent`、`delivered`、`read` の順です。WhatsAppに拒否された送信は `failed` になります。すでに `delivered` または `read` になったメッセージが `failed` になることはありません。

## 制限された番号

WhatsAppが、番号が制限された、またはアカウントが無効になったと通知してきた場合、zapbipは24 時間送信を停止し、運営者にアラートが届きます。その間に送ったメッセージは `delivery: "failed"` を返します。
