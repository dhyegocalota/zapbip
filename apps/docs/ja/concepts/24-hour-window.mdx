import { Chat } from '/snippets/chat.jsx';

WhatsAppでは、zapbipが自由形式のメッセージを送れるのは、オーナーからの最後のメッセージから24 時間以内に限られます。zapbipは自分側のウィンドウを10 分早く閉じます。オーナーのリアクションではウィンドウは開きません。

## ウィンドウが開いているとき

メッセージはすぐに送信され、ツールは `delivery: "sent"` を返します。

<Chat
  messages={[
    { you: true, text: '夜間ジョブが終わったら教えて。', time: '22:10' },
    { name: 'Claude Code', text: '夜間ジョブが完了しました ✅', time: '23:31' },
  ]}
/>

## ウィンドウが閉じているとき

- ツールは `delivery: "queued"` を返し、メッセージは送信待ち行列で待ちます。
- 最初に待機したメッセージが、閉じたウィンドウ1回につき1度だけ、AIの名前と短いプレビューを示す通知をオーナーに送ります。
- オーナーが次にメッセージを送るとウィンドウが開き、待ち行列が順番どおりに送り出されます。
- 7日を超えて待機したメッセージは `expired` になります。

<Chat
  messages={[
    { you: true, text: '夜間ジョブが終わったら教えて。', time: '昨日 22:10' },
    { notice: true, text: 'エージェントclaude-codeからメッセージです: 夜間ジョブが完了しました ✅', time: '23:31' },
    { you: true, text: 'ok', time: '08:05' },
    { name: 'Claude Code', text: '夜間ジョブが完了しました ✅', time: '08:05' },
  ]}
/>

チャネルに拒否された送信は `delivery: "failed"` として保存され、ツールは種類を示すエラーを返します。
