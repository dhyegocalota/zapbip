## क्या-क्या काम करता है

Hermes एक छोटे zapbip प्लगइन के ज़रिए आपके WhatsApp पर सुनता रहता है। आप पहले लिखें या किसी सवाल का जवाब बाद में दें, संदेश Hermes के सेशन तक पहुँच जाता है।

<Chat
  contact="Hermes"
  messages={[
    { you: true, text: 'आज repo में क्या-क्या बदला, उसका सारांश दो।', time: '18:02' },
    { name: 'Hermes', text: 'तीन commit: billing में एक फ़िक्स, एक नया टेस्ट और docs का एक अपडेट।', time: '18:03' },
  ]}
/>

### आपके फ़ॉरवर्ड किए संदेश

किसी और का जो संदेश आप फ़ॉरवर्ड करते हैं, वह Hermes तक एक लेबल के साथ पहुँचता है, जो बताता है कि इसे आपने नहीं लिखा, इसलिए Hermes उसे आपका निर्देश नहीं मानता।

## यह कैसे सुनता है

जगाने का तरीका: लोकल। जब तक कोई सवाल खुला है, Hermes एक बार में 50 सेकंड तक इंतज़ार करता है। अगर आपने जवाब नहीं दिया है, तो इंतज़ार "पेंडिंग" पर खत्म होता है और Hermes फिर से कॉल करता है, जितनी बार ज़रूरी हो, कोई समय-सीमा नहीं है।

प्लगइन zapbip से एक कनेक्शन खुला रखता है, बिना किसी समय-सीमा के। नेटवर्क टूट जाए, तो यह खुद फिर से जुड़ता है, और हर नाकाम कोशिश के बाद थोड़ा ज़्यादा इंतज़ार करता है (पहले 1 सेकंड, ज़्यादा से ज़्यादा 30 सेकंड)। इस बीच आपके भेजे संदेश आपके zapbip इनबॉक्स में इंतज़ार करते हैं, और वापस जुड़ते ही प्लगइन हर उस संदेश को उठा लेता है जिसका जवाब नहीं गया था।

### अगर प्लगइन इंस्टॉल न हो सके

Hermes इसकी जगह तय समय पर इनबॉक्स देख सकता है। सेटअप वाला MCP सर्वर जोड़ें और हर 1 मिनट में चलने वाला एक जॉब बनाएँ जो `check_inbox` कॉल करे। आपके संदेश एक मिनट तक इंतज़ार करते हैं, और जवाब भी इसी रास्ते आता है।

## शुरू से सेटअप करें

### आपको क्या चाहिए

- Hermes, जिसका gateway चल रहा हो।
- आपका कनेक्शन लिंक, वही `https://.../c/<secret>/mcp` लिंक जिससे आपका AI zapbip से बात करता है। इसे पासवर्ड की तरह संभालें।

### प्लगइन इंस्टॉल करें

पैकेज को उसी Python एनवायरनमेंट में इंस्टॉल करें जिसमें Hermes चलता है:

```bash
d=$(mktemp -d) && curl -fsSL https://mcp.zapbip.com/pkg/zapbip_platform-0.2.0-requirements.txt -o "$d/zapbip-requirements.txt" && python3 -c 'import hashlib,sys; sys.exit(hashlib.sha256(open(sys.argv[1],"rb").read()).hexdigest() != sys.argv[2])' "$d/zapbip-requirements.txt" 5e3c28d1d8170431504b4fe3780e897ac80c5fd3d134ce8ad5f9abf214ecd3f4 && python3 -m pip install --only-binary=:all: --require-hashes -r "$d/zapbip-requirements.txt"
```

फिर इसे `~/.hermes/config.yaml` में चालू करें:

```yaml
plugins:
  enabled:
    - zapbip-platform
```

लिंक, और यह कि Hermes से कौन बात कर सकता है, उसी एनवायरनमेंट में सेट करें जिसमें gateway चलता है, कभी भी ऐसी फ़ाइल में नहीं जिसे आप शेयर करते हैं:

```bash
export ZAPBIP_CONNECTION_LINK='https://<host>/c/<secret>/mcp'
export ZAPBIP_ALLOWED_USERS=owner
```

जिस फ़ाइल में आपका कनेक्शन लिंक है, वह पासवर्ड की तरह काम करती है। उसे `600` परमिशन दें ताकि सिर्फ़ आपका यूज़र उसे पढ़ सके, और उसे कभी शेयर या commit न करें:

```bash
chmod 600 <file>
```

gateway को फिर से शुरू करें।

हर एजेंट के लिए सिर्फ़ एक लिसनर चलाएँ: प्लगइन या `npx zapbip@0.2.0 listen`, दोनों कभी नहीं। दूसरा लिसनर पहले वाले की जगह ले लेता है।

### Hermes कैसे जवाब देता है

Hermes आपके संदेशों के जवाब खुद प्लगइन के ज़रिए वापस भेजता है, बिना किसी अलग सेटअप के।

zapbip को MCP सर्वर के रूप में जोड़ें, ताकि Hermes आपसे बातचीत शुरू भी कर सके, बटन के साथ सवाल पूछकर जवाब का इंतज़ार कर सके, और ऊपर बताया गया पोलिंग वाला विकल्प इस्तेमाल कर सके:

```yaml
mcp_servers: { zapbip: { url: 'https://<host>/c/<secret>/mcp' } }
```

फिर WhatsApp पर Hermes से `✅ इंस्टॉल हो गया` भेजने को कहें। यह संदेश पहुँच जाए, तो सब काम कर रहा है।

<Chat
  contact="zapbip"
  messages={[
    { you: true, text: 'इंस्टॉल हो जाए तो ✅ इंस्टॉल हो गया भेजना।', time: '18:10' },
    { name: 'Hermes', text: '✅ इंस्टॉल हो गया', time: '18:10' },
  ]}
/>

## जाँचें कि यह काम करता है

| आपको क्या दिखता है                                  | इसका मतलब                                                                  |
| --------------------------------------------------- | -------------------------------------------------------------------------- |
| आपके संदेश का कोई जवाब नहीं आता                     | gateway नहीं चल रहा, या प्लगइन `plugins.enabled` में नहीं है।              |
| प्लगइन अपने आप रुक जाता है                          | उसी कनेक्शन के लिए कोई दूसरा प्लगइन या कनेक्टर शुरू हुआ और उसकी जगह ले ली। |
| Hermes न बातचीत शुरू कर पाता है, न आपसे पूछ पाता है | `config.yaml` में `zapbip` MCP सर्वर नहीं है।                              |
| प्लगइन किसी गड़बड़ी के साथ रुक जाता है              | लिंक पहचाना नहीं गया या कनेक्शन हटा दिया गया। नया लिंक माँगें।             |
