इस अकाउंट का एक एजेंट नाम से हटाएँ। ओनर से WhatsApp पर, कॉल करने वाले एजेंट के नाम से पूछा जाता है, और कॉल जवाब का इंतज़ार करती है। यह `एजेंट हटाएँ` कमांड वाला ही use case चलाता है: वह एजेंट जिस भी तरह जुड़ा है, सब तुरंत बंद हो जाता है। देखें [zapbip को अपने AI से मैनेज करवाएँ](/hi/features/let-your-ai-manage-zapbip)।

## इनपुट

| फ़ील्ड | टाइप   | नोट                             |
| ------ | ------ | ------------------------------- |
| `name` | string | इस अकाउंट के किसी एजेंट का नाम। |

## सवाल

दो बटन: **अनुमति दें** और **मना करें**। कॉल 50 सेकंड तक इंतज़ार करती है। सिर्फ़ बटन चुनना ही गिना जाता है: लिखा हुआ टेक्स्ट मना करना माना जाता है। मना करने और चुप रहने से कुछ नहीं बदलता, और उसके बाद वही अनुरोध 10 मिनट के लिए ठुकरा दिया जाता है (`cooling_down`)।

## आउटपुट

`{ "status": "applied" | "denied" | "timed_out" | "refused", "agent": string | null, "reason": string | null, "install_prompt": null }`। `refused` के साथ `reason` `not_found` का मतलब है कि इस अकाउंट के किसी सक्रिय एजेंट का यह नाम नहीं है; ओनर से पूछा नहीं जाता। किसी दूसरे अकाउंट का एजेंट कभी नहीं मिलता।

[connect_agent](/hi/mcp-reference/connect-agent) वाली सीमा यहाँ भी लागू है: हर कनेक्शन पर एक मिनट में 3 बदलाव वाली कॉल।
