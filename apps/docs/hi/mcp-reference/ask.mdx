ओनर से बटन या लिस्ट के साथ सवाल पूछें और जवाब का इंतज़ार करें।

## इनपुट

| फ़ील्ड            | टाइप             | नोट                                                                                                  |
| ----------------- | ---------------- | ---------------------------------------------------------------------------------------------------- |
| `question`        | string           | 1024 अक्षरों तक।                                                                                     |
| `options`         | 1 से 10 का array | 3 तक विकल्प बटन के रूप में दिखते हैं (टाइटल 20 अक्षरों तक), 4 से 10 लिस्ट के रूप में (पंक्ति 24 तक)। |
| `timeout_seconds` | number, वैकल्पिक | 50 तक।                                                                                               |

## आउटपुट

ओनर समय पर जवाब दे तो `{ "status": "answered", "answer": ..., "message_id": string }`, या इंतज़ार पहले खत्म हो जाए तो `{ "status": "pending", "question_id": string }`। `question_id` को [wait_for_reply](/hi/mcp-reference/wait-for-reply) में भेजें।

4 मिनट के अंदर वही सवाल दोहराने पर वही सवाल लौटता है और कुछ नहीं भेजा जाता। देखें [सवाल](/hi/concepts/questions)।
