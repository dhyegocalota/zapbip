सेव करें कि जब आप लिखें और कोई कॉल इंतज़ार न कर रही हो, तब यह कनेक्शन कैसे जगाया जाए। देखें [वेक लैडर](/hi/concepts/wake-ladder) और [webhook वेक गाइड](/hi/developers/webhook-wake)।

## इनपुट

| फ़ील्ड             | टाइप              | नोट                                                                                                                                                                                                                            |
| ------------------ | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `mode`             | string            | `local` [कनेक्टर](/hi/developers/local-connector) से जगाता है; `webhook` एक webhook सेव करता है; `scheduled` एजेंट से टाइमर पर इनबॉक्स देखवाता है; `standby` आपके संदेश किसी दूसरे एजेंट को सौंपता है; `none` वेक हटा देता है। |
| `url`              | string, वैकल्पिक  | `webhook` के लिए ज़रूरी। `https`, बिना userinfo, बिना fragment, पोर्ट 443 या कोई नहीं, 512 अक्षरों तक। इसका होस्ट प्रोवाइडर तय करता है।                                                                                        |
| `token`            | string, वैकल्पिक  | `webhook` के लिए ज़रूरी। प्रिंट होने लायक, बिना whitespace, 16 से 512 अक्षर। जेनेरिक webhook के लिए यह साइनिंग की है, कम से कम 32 अक्षर।                                                                                       |
| `interval_minutes` | integer, वैकल्पिक | `scheduled` के लिए ज़रूरी। 1 से 1440 मिनट। ChatGPT और claude.ai शेड्यूल्ड टास्क कम से कम हर 60 मिनट पर चलाते हैं।                                                                                                              |
| `standby_agent`    | string, वैकल्पिक  | `standby` के लिए ज़रूरी। उसी अकाउंट के किसी दूसरे कनेक्शन का नाम, जो खुद स्टैंडबाय न हो।                                                                                                                                       |

किसी दूसरे mode के फ़ील्ड मौजूद नहीं होने चाहिए।

## Scheduled

जिस एजेंट को बाहर से शुरू नहीं किया जा सकता, वह टाइमर पर एक टास्क चलाता है जो [check_inbox](/hi/mcp-reference/check-inbox) कॉल करता है। इससे वह बिना किसी समय-सीमा के सुन सकता है, और हर संदेश का जवाब `send_message` से देता है।

```json
{ "mode": "scheduled", "interval_minutes": 60 }
```

जब आप लिखते हैं, तो zapbip बताता है कि जवाब कब आएगा। अगर इंटरवल के दोगुने समय तक कोई जाँच न हो, तो आपको एक सूचना मिलती है और आपके संदेश अगली जाँच तक इनबॉक्स में इंतज़ार करते हैं।

## Local

जब आपके कंप्यूटर पर [कनेक्टर](/hi/developers/local-connector) चल रहा हो, तब अपने एजेंट से यह टूल `{ "mode": "local" }` के साथ कॉल करने को कहें।

## Standby

जिस एजेंट को जगाया नहीं जा सकता, वह उसी अकाउंट का कोई दूसरा एजेंट अपनी जगह जवाब देने के लिए तय करता है। zapbip आपका संदेश स्टैंडबाय को कॉपी करता है और उसे जगाता है; स्टैंडबाय अपने नाम से जवाब देता है।

```json
{ "mode": "standby", "standby_agent": "grok-bot" }
```

स्टैंडबाय कभी किसी दूसरे स्टैंडबाय को आगे नहीं भेजता: सिर्फ़ एक कदम। अगर स्टैंडबाय मौजूद नहीं है, हटा दिया गया है या खुद स्टैंडबाय mode में है, तो कुछ भी कॉपी नहीं होता और आपका संदेश पहले एजेंट के पास इंतज़ार करता है।

## प्रोवाइडर

प्रोवाइडर URL के होस्ट से चुना जाता है, कभी किसी फ़ील्ड से नहीं।

| प्रोवाइडर        | होस्ट                          | पाथ                                          | ऑथेंटिकेशन                                                               |
| ---------------- | ------------------------------ | -------------------------------------------- | ------------------------------------------------------------------------ |
| `grok_routine`   | `api2.cursor.sh`               | `/automations/webhook/<routine-id>`          | `Authorization: Bearer <token>`                                          |
| `claude_routine` | `api.anthropic.com`            | `/v1/claude_code/routines/<trigger-id>/fire` | `Authorization: Bearer <token>`                                          |
| `generic`        | कोई भी सार्वजनिक `https` होस्ट | कोई भी                                       | `X-Zapbip-Timestamp` और `X-Zapbip-Signature`, कोई सीक्रेट नहीं भेजा जाता |

## आउटपुट

`{ "status": "saved", "wake_mode": string, "effective_rung": string, "provider": string | null }`। `provider` सिर्फ़ `webhook` के लिए सेट होता है। जब स्टैंडबाय इस्तेमाल लायक न हो, और `local` के लिए जब तक कोई कनेक्टर न जुड़ा हो, `effective_rung` का मान `inbox` होता है, क्योंकि तब संदेश इनबॉक्स में इंतज़ार करता है। URL, टोकन और होस्ट कभी लौटाए नहीं जाते।

## गड़बड़ियाँ

टूल की गड़बड़ी गलत फ़ील्ड (`url`, `token`, `interval_minutes`, `standby_agent` या `mode`) और उसकी सीमा बताती है, और उसका मान कभी नहीं दोहराती। कुछ भी नहीं रखा जाता और पिछला वेक बना रहता है। सेव करते समय zapbip प्रोवाइडर को कॉल नहीं करता: गलत टोकन पहले वेक पर, WhatsApp पर आपको एक सूचना के रूप में दिखता है।
