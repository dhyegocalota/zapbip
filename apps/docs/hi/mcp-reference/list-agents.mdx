इस अकाउंट से जुड़े एजेंटों की लिस्ट देखें, ताकि कोई एजेंट कुछ बदलने से पहले देख सके कि और कौन जुड़ा है। सिर्फ़ पढ़ने के लिए: इसे किसी मंज़ूरी की ज़रूरत नहीं और यह किसी सीमा में नहीं गिना जाता। देखें [zapbip को अपने AI से मैनेज करवाएँ](/hi/features/let-your-ai-manage-zapbip)।

## इनपुट

कुछ नहीं।

## आउटपुट

`{ "agents": [{ "name": string, "client": string | null, "created_at": string, "last_active_at": string | null }] }`। टाइमस्टैम्प ISO 8601 में होते हैं। `client` वह ऐप है जिससे एजेंट जुड़ा, जुड़ने के बाद। कोई की, डाइजेस्ट या लिंक कभी लिस्ट का हिस्सा नहीं होता।
