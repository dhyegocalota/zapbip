zapbip, streamable HTTP पर MCP बोलता है। जो भी क्लाइंट इसे सपोर्ट करता है, वह उस कनेक्शन URL से जुड़ सकता है जो zapbip आपके एजेंट को देता है।

## कनेक्शन URL

```text
https://<zapbip-host>/c/<secret>/mcp
```

URL में मौजूद सीक्रेट ही कनेक्शन है। इसे निजी रखें।

## Bearer वाला विकल्प

जो क्लाइंट URL में सीक्रेट छिपा नहीं सकते, वे `/mcp` इस्तेमाल करें और सीक्रेट हेडर में भेजें:

```text
POST https://<zapbip-host>/mcp
Authorization: Bearer <secret>
```

दोनों तरीके एक ही एजेंट तक पहुँचते हैं। सीक्रेट न हो या गलत हो, तो जवाब `401` आता है।
