import { Chat } from '/snippets/chat.jsx';

WhatsApp, zapbip को ओनर के आखिरी संदेश के 24 घंटे के अंदर ही खुले संदेश भेजने देता है। zapbip अपनी विंडो 10 मिनट पहले बंद कर देता है। ओनर का रिएक्शन विंडो नहीं खोलता।

## विंडो खुली है

संदेश तुरंत जाते हैं, और टूल `delivery: "sent"` लौटाता है।

<Chat
  messages={[
    { you: true, text: 'रात वाला जॉब पूरा हो तो मुझे बताना।', time: '22:10' },
    { name: 'Claude Code', text: 'रात वाला जॉब पूरा हुआ ✅', time: '23:31' },
  ]}
/>

## विंडो बंद है

- टूल `delivery: "queued"` लौटाता है और संदेश बाहर जाने वाली कतार में इंतज़ार करता है;
- कतार का पहला संदेश ओनर को एक सूचना भेजता है, जिसमें AI का नाम और एक छोटी झलक होती है, हर बंद विंडो पर एक बार;
- ओनर का अगला संदेश विंडो खोलता है और कतार को क्रम से खाली करता है;
- 7 दिन से पुराने कतार वाले संदेश `expired` हो जाते हैं।

<Chat
  messages={[
    { you: true, text: 'रात वाला जॉब पूरा हो तो मुझे बताना।', time: 'कल 22:10' },
    { notice: true, text: 'एजेंट claude-code के पास आपके लिए एक संदेश है: रात वाला जॉब पूरा हुआ ✅', time: '23:31' },
    { you: true, text: 'ठीक है', time: '08:05' },
    { name: 'Claude Code', text: 'रात वाला जॉब पूरा हुआ ✅', time: '08:05' },
  ]}
/>

जिस भेजने को चैनल ठुकरा दे, वह `delivery: "failed"` के साथ रखा जाता है, और टूल उसका प्रकार बताती हुई गड़बड़ी लौटाता है।
