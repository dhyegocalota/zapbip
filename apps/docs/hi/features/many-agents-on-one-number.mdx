import { Chat } from '/snippets/chat.jsx';

आपके सभी AI एक ही WhatsApp नंबर से लिखते हैं। zapbip इस क्रम में तय करता है कि आपका संदेश कहाँ जाएगा:

| आप क्या करते हैं                                      | संदेश किसके पास जाता है                   |
| ----------------------------------------------------- | ----------------------------------------- |
| कोई बटन या लिस्ट का विकल्प चुनते हैं                  | जिस AI ने पूछा था                         |
| किसी संदेश का जवाब देते हैं, या उस पर रिएक्ट करते हैं | जिस AI ने वह संदेश भेजा था                |
| `@grok खबरें देखो` लिखते हैं                          | Grok को, `@grok ` हटाकर                   |
| किसी AI का सवाल खुला रहते जवाब देते हैं               | उसी AI को                                 |
| सिर्फ़ Claude के बोलने के बाद लिखते हैं               | Claude को, जिसने आखिरी बार लिखा था        |
| कुछ मेल न खाए, तब लिखते हैं                           | हाल के AI की एक लिस्ट, जिसमें से आप चुनें |

## उदाहरण

<Chat
  messages={[
    { name: 'Claude', text: 'टेस्ट पास हो गए।', time: '10:02' },
    { name: 'Grok', text: 'main को rebase कर दूँ?', options: ['हाँ', 'नहीं'], time: '10:03' },
    { you: true, text: '@claude धन्यवाद', time: '10:04' },
    { you: true, text: 'हाँ', time: '10:04' },
  ]}
/>

`@claude धन्यवाद` Claude के पास जाता है और "हाँ" बटन का जवाब Grok के पास।

<Chat
  messages={[
    { you: true, text: 'ठीक है', time: '10:05' },
    { name: 'zapbip', text: 'आपका संदेश किस एजेंट को भेजूँ?', options: ['Claude', 'Grok'], time: '10:05' },
  ]}
/>

सिर्फ़ `ठीक है` लिखने पर हाल के AI की एक लिस्ट आती है, जिसमें से आप चुनते हैं।

जिस AI ने कोई संदेश भेजा था, उससे बात करने के लिए उस संदेश का जवाब दें:

<Chat
  messages={[
    { name: 'Claude', text: 'टेस्ट पास हो गए।', time: '10:02' },
    { name: 'Grok', text: '3 सोर्स मिले।', time: '10:03' },
    { you: true, quote: { name: 'Grok', text: '3 सोर्स मिले।' }, text: 'कौन-से?', time: '10:04' },
    { name: 'Grok', text: 'दो पेपर और एक रिपोर्ट। लिंक भेजे जा रहे हैं।', time: '10:04' },
  ]}
/>

नामों में 20 तक अक्षर होते हैं: छोटे अक्षर (a-z), अंक और हाइफ़न।
