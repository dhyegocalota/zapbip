zapbip नीचे दिए संदेश प्रकारों को दोनों दिशाओं में समर्थन देता है। यहाँ न दिया गया कोई भी प्रकार समर्थित नहीं है।

## आपका AI जो प्राप्त करता है

| प्रकार     | आप भेजते हैं                      | आपका AI प्राप्त करता है                                                              |
| ---------- | --------------------------------- | ------------------------------------------------------------------------------------ |
| `text`     | एक संदेश                          | टेक्स्ट                                                                              |
| `image`    | एक फ़ोटो                          | फ़ोटो, जिसे zapbip सहेजता है                                                         |
| `video`    | एक वीडियो                         | वीडियो, जिसे zapbip सहेजता है                                                        |
| `audio`    | एक ऑडियो फ़ाइल या वॉइस नोट        | ऑडियो, जिसे zapbip सहेजता है; वॉइस नोट को ऐसा ही चिह्नित करके भेजा जाता है           |
| `document` | एक फ़ाइल, जैसे PDF                | फ़ाइल, जिसे zapbip उसके नाम और प्रकार के साथ सहेजता है                               |
| `sticker`  | एक स्टिकर                         | स्टिकर, जिसे zapbip सहेजता है                                                        |
| `location` | एक लोकेशन पिन                     | अक्षांश, देशांतर, नाम और पता                                                         |
| `contacts` | एक या अधिक कॉन्टैक्ट कार्ड        | कॉन्टैक्ट कार्ड                                                                      |
| `reaction` | एक इमोजी रिएक्शन                  | इमोजी और वह संदेश जिस पर रिएक्शन दिया गया; रिएक्शन हटाने पर इमोजी के बिना पहुँचता है |
| `choice`   | किसी बटन या सूची की पंक्ति पर टैप | चुना गया विकल्प, जो प्रश्न का उत्तर है                                               |

आपके AI के संदेश का जवाब उसी AI तक पहुँचता है जिसने वह संदेश भेजा था।

कोई और प्रकार भेजने पर आपको एक छोटी सूचना मिलती है कि यह प्रकार अभी समर्थित नहीं है, और आपके AI को कुछ नहीं मिलता। किसी ऑर्डर (order) या WhatsApp Flow के जवाब पर भी यही होता है। zapbip की सूचना पर "खोलें" बटन दबाने से केवल [24 घंटे की विंडो](/hi/features/the-24-hour-window) खुलती है। कॉल या कोई और खाता-इवेंट अनदेखा किया जाता है।

## आपका AI जो भेज सकता है

| प्रकार     | आपका AI जो भेज सकता है                                         |
| ---------- | -------------------------------------------------------------- |
| `text`     | 4,096 अक्षरों तक का टेक्स्ट संदेश                              |
| `image`    | फ़ोटो: JPEG, PNG या WebP, 5 MB तक                              |
| `video`    | वीडियो: 3GP या MP4, 16 MB तक                                   |
| `audio`    | ऑडियो फ़ाइल: AAC, AMR, MP3, M4A या OGG, 16 MB तक; या वॉइस नोट  |
| `document` | फ़ाइल: PDF, Word, Excel, PowerPoint या सादा टेक्स्ट, 100 MB तक |
| `sticker`  | स्थिर WebP स्टिकर, 100 KB तक                                   |
| `location` | लोकेशन पिन                                                     |
| `contacts` | एक या अधिक कॉन्टैक्ट कार्ड                                     |
| `reaction` | आपके किसी संदेश पर इमोजी रिएक्शन, या हटाने के लिए कुछ नहीं     |
| `choice`   | अधिकतम 3 बटन वाला प्रश्न, या 4 से 10 विकल्पों की सूची          |

zapbip ऐसा भेजना अस्वीकार करता है जो इनमें से किसी सीमा को तोड़ता है, और बताता है कि कौन सा फ़ील्ड गलत है। पोल, ऑर्डर, भुगतान, WhatsApp Flows और कॉल उपलब्ध नहीं हैं। आपका AI WhatsApp टेम्पलेट नहीं चुन सकता; zapbip अपनी सूचना केवल तब भेजता है जब 24 घंटे की विंडो बंद हो।

## केवल आधिकारिक WhatsApp Cloud API

zapbip केवल Meta के आधिकारिक WhatsApp Cloud API के माध्यम से, zapbip के नंबर पर, भेजता और प्राप्त करता है। ये समर्थित नहीं हैं:

- Baileys, whatsapp-web.js, WPPConnect या Evolution API जैसे गैर-आधिकारिक WhatsApp क्लाइंट और लाइब्रेरी;
- WhatsApp Web का स्वचालन, या कोई भी ब्रिज जो निजी खाते या QR कोड से लॉग इन करता है;
- आपका अपना निजी WhatsApp नंबर। हर AI zapbip के नंबर से लिखता है, और आप अपने सामान्य WhatsApp पर जवाब देते हैं।

छोटे उत्तरों के लिए [अक्सर पूछे जाने वाले प्रश्न](/hi/help/faq) देखें।
