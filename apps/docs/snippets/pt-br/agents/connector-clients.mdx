O Claude Code também roda sem os seus arquivos de configuração e com todas as ferramentas internas desligadas, e as configurações de política gerenciada do Claude Code continuam valendo.

O Codex roda com um sandbox somente leitura e com os outros servidores MCP que encontra nos seus arquivos de configuração do Codex desligados. Se não consegue ler um desses arquivos, não acorda o Codex e deixa a mensagem sem ler. Também recusa quando um arquivo gerenciado do Codex define qualquer chave fora de uma lista curta de chaves inofensivas, quando um perfil define sandbox, aprovação, ferramentas ou recursos (ou qualquer chave fora dessa lista), quando um arquivo liga uma chave de busca na web, ou quando `zapbip` é definido fora do `config.toml` da sua pasta do Codex. A busca na web do Codex fica desligada. O que sobra para o Codex é `send_message` e um shell somente leitura; apps e conectores da sua conta do Codex não são desligados, e as preferências gerenciadas do macOS `com.openai.codex` continuam valendo.

Se o app do Codex já estiver com a conversa aberta, o Codex recusa retomá-la. O conector então abre uma única sessão nova na mesma pasta, que começa sem a conversa anterior, e passa a usá-la.
