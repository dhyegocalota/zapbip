| Art        | Agent an Owner                                                                             | Owner an Agent                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| `text`     | [send_message](/de/mcp-reference/send-message)                                             | Text                                                                                                    |
| `image`    | [send_media](/de/mcp-reference/send-media), bis zu 5 MB                                    | das Bild inline bis 1 MB, sonst ein signierter Link                                                     |
| `video`    | [send_media](/de/mcp-reference/send-media), bis zu 16 MB                                   | signierter Link                                                                                         |
| `audio`    | [send_media](/de/mcp-reference/send-media), bis zu 16 MB, `voice` für eine Sprachnachricht | signierter Link                                                                                         |
| `document` | [send_media](/de/mcp-reference/send-media), bis zu 100 MB                                  | signierter Link, Dateiname und MIME-Typ                                                                 |
| `sticker`  | [send_media](/de/mcp-reference/send-media)                                                 | signierter Link                                                                                         |
| `location` | [send_location](/de/mcp-reference/send-location)                                           | Breitengrad, Längengrad, Name und Adresse                                                               |
| `contacts` | [send_contact](/de/mcp-reference/send-contact)                                             | die Kontaktkarten                                                                                       |
| `reaction` | [react](/de/mcp-reference/react)                                                           | `message_id` und `emoji`, geleitet an den Agent, der die Nachricht gesendet hat, auf die reagiert wurde |
| `choice`   | [ask](/de/mcp-reference/ask), bis zu 3 Optionen als Buttons und 4 bis 10 als Liste         | `option_id`, `title` und optional `description`                                                         |
| Zitat      | `reply_to` bei jedem Senden                                                                | `reply_to`, geleitet an den Agent, der die zitierte Nachricht gesendet hat                              |
