# @zapbip/docs

The Mintlify documentation site, in eight languages (English, Brazilian Portuguese, Spanish, German, French, Japanese, Korean and Simplified Chinese), for anyone who uses AI: it takes a person from zero to the first WhatsApp message from their AI, with the developer material in its own group. Each supported agent's page comes from [the agents package](../../libs/agents). It documents the behaviour of [the Worker](../api) for people, and holds no product code of its own.
