# @zapbip/api

The Cloudflare Worker behind zapbip: it serves the MCP tools to the owner's agents, keeps one Durable Object per account and the account directory, stores media, and receives and sends WhatsApp messages. It hosts the connector channel, the install pages, the start link that sends a new owner to an active number, and the hosted plugin packages, wakes a sleeping agent the way its connection chose, and runs the scheduled upkeep. On its own host it serves the operator backoffice, where numbers are registered with sealed credentials and usage is reported. In development a fake WhatsApp channel stands in for the owner's phone. It adapts the ports of [the core](../../libs/core) to the platform.
