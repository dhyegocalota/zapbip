# @zapbip/api

The Cloudflare Worker behind zapbip: it serves the MCP tools to the owner's agents, keeps one Durable Object per account and the account directory, stores media, and receives and sends WhatsApp messages. It hosts the connector channel, the install pages, the start link that sends a new owner to an active number, and the hosted plugin packages, wakes a sleeping agent the way its connection chose, and runs the scheduled upkeep. On the bare domain it serves the public waitlist page, where a visitor joins behind a captcha and invites friends. On its own host it serves the operator backoffice, where numbers are registered with sealed credentials and usage is reported. On its own host it serves the customer web app, where an owner signs in with a one-time link sent over WhatsApp and manages their agents. In development a fake WhatsApp channel stands in for the owner's phone. It adapts the ports of [the core](../../libs/core) to the platform.
