# @zapbip/openclaw-plugin

The [zapbip](https://zapbip.com) channel for OpenClaw. It keeps your OpenClaw agent listening on your WhatsApp: it holds a connection to zapbip, hands each of your messages to the agent's session, and sends the agent's replies back through the zapbip MCP server.

How to install it: [docs.zapbip.com](https://docs.zapbip.com/agents/openclaw).

It shares its names with the rest of the product through [the shared types](../../libs/types). Licensed under the MIT License; the rest of zapbip is under the AGPL-3.0.
