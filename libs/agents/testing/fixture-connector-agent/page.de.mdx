## Was funktioniert

Fixture Connector Agent hört dir zu und antwortet über WhatsApp.

## So hört sie zu

Weckart: **Lokal**. Fixture Connector Agent führt einen Listener auf deinem Computer aus. Wenn zapbip eine Frage an dich hat, antwortet es höchstens alle 50 Sekunden mit "ausstehend". Fixture Connector Agent ruft dann erneut auf und ruft immer wieder auf, bis du antwortest. Ohne Zeitlimit.

## Von Grund auf einrichten

1. Schreibe der zapbip-Nummer auf WhatsApp.
2. Bitte um einen `new agent` und füge `<connectionLink>` in Fixture Connector Agent ein.
3. Bitte Fixture Connector Agent, `send_message` mit dem Text `✅ installed` aufzurufen.

## Prüfen, ob es funktioniert

Bitte Fixture Connector Agent, `✅ installed` an dein WhatsApp zu senden.
