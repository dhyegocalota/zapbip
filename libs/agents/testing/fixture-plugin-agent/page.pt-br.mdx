## O que funciona

O Agente plugin de teste ouve você e responde pelo WhatsApp.

## Como ela escuta

Tipo de despertar: **Local**. O Agente plugin de teste roda um ouvinte no seu computador. Quando o zapbip tem uma pergunta para você, ele responde "pendente" no máximo a cada 50 segundos. O Agente plugin de teste chama de novo, e continua chamando de novo até você responder. Sem limite de tempo.

## Configure do zero

1. Mande uma mensagem para o número do zapbip no WhatsApp.
2. Peça um novo agente e cole a linha no Agente plugin de teste.

## Confira se funciona

Peça ao Agente plugin de teste para enviar `✅ instalado` para o seu WhatsApp.
