## O que funciona

O Agente plugin de teste ouve você e responde pelo WhatsApp.

## Como ela escuta

Tipo de despertar: **Local**. O Agente plugin de teste roda um ouvinte no seu computador. Quando o zapbip tem uma pergunta para você, ele responde "pendente" no máximo a cada 50 segundos. O Agente plugin de teste chama de novo, e continua chamando de novo até você responder. Sem limite de tempo.

## Configure do zero

1. Mande uma mensagem para o número do zapbip no WhatsApp.
2. Peça um novo agente e rode o comando de instalação abaixo e coloque o link de conexão nas configurações do Agente plugin de teste.

```bash
pip install --require-hashes --requirement https://mcp.zapbip.com/pkg/fixture-requirements.txt # sha256:eb1fc5e4bae42f5a04d9bc2001ef4516367ff8520495100b1ccaec1320b85f84
```

## Confira se funciona

Peça ao Agente plugin de teste para enviar `✅ instalado` para o seu WhatsApp.

Rode apenas um listener por agente: o plugin ou `npx zapbip@0.2.0 listen`, nunca os dois. Um segundo listener substitui o primeiro.
