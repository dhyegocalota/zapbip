## 지원하는 기능

Fixture Plugin Agent이(가) 내 말을 듣고 WhatsApp으로 답합니다.

## 수신 방식

깨우기 방식: **로컬**. Fixture Plugin Agent은(는) 내 컴퓨터에서 리스너를 실행합니다. zapbip에 물어볼 것이 있으면 최대 50초마다 "보류 중"이라고 답합니다. Fixture Plugin Agent은(는) 다시 호출하고, 내가 답할 때까지 계속 다시 호출합니다. 시간 제한 없이 동작합니다.

## 처음부터 설정하기

1. WhatsApp으로 zapbip 번호에 메시지를 보내세요.
2. `새 에이전트`를 요청하고 아래 설치 명령을 실행한 뒤 연결 링크를 Fixture Plugin Agent의 설정에 넣으세요.

```bash
pip install --require-hashes --requirement https://mcp.zapbip.com/pkg/fixture-requirements.txt # sha256:eb1fc5e4bae42f5a04d9bc2001ef4516367ff8520495100b1ccaec1320b85f84
```

## 작동 확인

Fixture Plugin Agent에게 `✅ 설치 완료`를 내 WhatsApp으로 보내라고 요청하세요.

에이전트마다 리스너는 하나만 실행하세요. 플러그인 또는 `npx zapbip@0.1.0 listen` 중 하나만 쓰고, 둘 다 쓰지 마세요. 두 번째 리스너는 첫 번째를 대체합니다.
