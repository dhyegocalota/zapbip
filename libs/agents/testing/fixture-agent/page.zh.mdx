## 支持的功能

Fixture Agent 会听你说话，并通过 WhatsApp 回复。

## 监听方式

唤醒方式：**本地**。Fixture Agent 在你的电脑上运行 listener。zapbip 有问题要问你时，最多每 50 秒回复一次“待处理”。Fixture Agent 会再次调用，并一直再次调用，直到你回答。没有时间限制。

## 从零开始设置

1. 在 WhatsApp 上给 zapbip 的号码发一条消息。
2. 请求一个 `新建智能体`，然后把 `<connectionLink>` 粘贴到 Fixture Agent。
3. 让 Fixture Agent 用文本 `✅ 安装完成` 调用 `send_message`。

## 检查是否正常工作

让 Fixture Agent 把 `✅ 安装完成` 发送到你的 WhatsApp。
