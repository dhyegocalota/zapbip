## 지원하는 기능

| 하고 싶은 일                  | Cursor                                                 |
| ----------------------------- | ------------------------------------------------------ |
| Cursor의 메시지 받기          | 텍스트, 사진, 동영상, 오디오, 문서, 위치, 연락처, 반응 |
| 버튼으로 답하기               | 버튼과 목록. 내 답을 기다립니다                        |
| WhatsApp에서 먼저 쓰기        | 예. 채팅이 열려 있는 동안 Cursor가 내 말을 듣습니다    |
| 질문을 몇 시간 동안 열어 두기 | 예. 시간 제한이 없습니다                               |

<Chat
  messages={[
    { name: 'Cursor', text: '테스트가 통과했어요. 변경 사항을 커밋할까요?', options: ['예', '아직'], time: '14:10' },
    { you: true, text: '예', time: '14:11' },
  ]}
/>

## 수신 방식

깨우기 방식: **로컬**. Cursor는 백그라운드 터미널에서 `npx zapbip@0.1.0 listen`을 계속 실행합니다. WhatsApp에서 쓰면 그 터미널에 새 줄이 나타나 채팅을 깨웁니다.

- Cursor에는 예약 옵션이 없으므로, 그 터미널을 계속 실행해 두세요.

AI가 나에게 무언가를 물으면 zapbip은 그 질문을 붙잡고 최대 50초마다 "보류 중"으로 답합니다. 그러면 Cursor가 다시 호출하고, 내가 답할 때까지 계속 호출합니다. 시간 제한 없이 기다립니다.

## 처음부터 설정하기

1. **WhatsApp에서 zapbip 번호로 메시지를 보냅니다.** 아무 텍스트나, 예를 들어 `hi`를 보내세요.

   <StartLink />

2. **새 에이전트를 요청합니다.** 에이전트는 연결하는 AI 하나를 뜻합니다. 명령어는 한국어, 영어, 포르투갈어 단어로 입력할 수 있습니다.

   <Chat
     messages={[
       { you: true, text: '새 에이전트 cursor', time: '14:00' },
       {
         name: 'zapbip',
         text: 'Agent cursor created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate cursor".',
         time: '14:00',
       },
     ]}
   />

3. **그 줄을 Cursor 채팅에 붙여 넣습니다.**

   <InstallPrompt />

   Cursor가 안내를 읽고 순서대로 따릅니다. 설정을 바꾸기 전에 어느 것인지 알려 주고 내 "예"를 기다립니다. 링크는 비밀이므로 공유하는 채팅에는 올리지 마세요.

4. **"예"라고 답합니다.** 그다음은 Cursor가 이 순서대로 나머지를 합니다.

5. **Cursor에 zapbip을 추가합니다.** 먼저 나에게 묻고 "예"를 기다립니다. 그런 다음 Cursor의 MCP 설정에 `<connectionLink>`를 HTTP로 가리키는 `zapbip`이라는 MCP 서버를 추가합니다.

6. **듣기를 시작합니다.** 백그라운드 터미널에서 `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 listen`을 실행하고, 그 터미널을 시간 제한 없이 계속 실행합니다. 거기에 새 줄이 나타날 때마다 `check_inbox`를 호출하고 답합니다.

7. **테스트합니다.** 채팅에서 `send_message`를 호출해 ✅ 설치 완료를 보냅니다. 그다음 zapbip 도구를 쓰기 위해 Cursor 채팅을 다시 시작하세요.

## 작동 확인

Cursor에게 WhatsApp으로 `✅ 설치 완료`를 보내라고 요청하세요. 몇 초 안에 도착해야 합니다.

<Chat messages={[{ name: 'Cursor', text: '✅ 설치 완료', time: '14:03' }]} />

아무것도 도착하지 않으면 [문제 해결](/ko/help/troubleshooting)을 보세요.
