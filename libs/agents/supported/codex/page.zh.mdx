## 支持的功能

| 你想要               | Codex                                                |
| -------------------- | ---------------------------------------------------- |
| 收到它的消息         | 文本、照片、视频、音频、文档、位置、联系人、表情回应 |
| 点按作答             | 按钮和列表；它会等你点按                             |
| 从 WhatsApp 先发消息 | 可以，即使会话闲置，它也会在约 6 秒内回答            |
| 让问题保持几个小时   | 可以，没有时间限制                                   |

## 监听方式

唤醒方式：**本地**。你每次发消息，你电脑上的连接器都会用 `codex exec resume` 恢复你的 Codex 会话，大约 6 秒。如果 Codex 已经在它的应用中打开了该会话，恢复会等到会话空闲。

- 请保持连接器运行。想在关闭终端后仍保持运行，请按[把连接器作为服务运行](/zh/developers/background-running)操作。

你的 AI 向你提问时，zapbip 会保留这个问题，并最多每 50 秒回答一次“待处理”。Codex 随后再次调用，并一直调用下去，直到你回答。没有时间限制。

安装时在 Codex 中设置的 900 秒工具超时，限制的是一次调用，而不是监听。一次调用结束后，Codex 会开始下一次。

Codex 对单个答案最多等待 15 分钟，然后再次询问，所以整体没有限制。

## 从零开始设置

1. **在 WhatsApp 上给 zapbip 的号码发消息。** 随便发一段文字，例如 `hi`。

   <StartLink />

2. **申请一个新智能体。** 智能体就是你连接的一个 AI。目前命令需要用英语或葡萄牙语的词来输入。

   <Chat
     messages={[
       { you: true, text: '新建智能体 codex', time: '11:00' },
       {
         name: 'zapbip',
         text: 'Agent codex created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate codex".',
         time: '11:00',
       },
     ]}
   />

3. **把这一行粘贴到 Codex 里。**

   <InstallPrompt />

   Codex 会阅读说明并按顺序执行。在更改文件或设置之前，它会告诉你要改哪一个，并等你说“好”。链接是机密的，请不要放进你会分享的聊天里。

4. **说“好”。** 之后 Codex 会按这个顺序完成其余的事。

5. **把 zapbip 添加到 Codex。** 在你同意之后，它会把 `~/.codex/config.toml` 里的 `[mcp_servers.zapbip]` 表替换为 `url = "<connectionLink>"`、`tool_timeout_sec = 900` 和 `default_tools_approval_mode = "approve"`。审批模式让 zapbip 的工具无需每次询问你就能运行，Codex 会告知你这一点。

6. **启动连接器。** 它在后台运行 `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 connect --client codex`。它持续监听，并用 `codex exec resume` 恢复你的会话。

7. **测试。** 在一个新进程中，它运行 `codex exec -c 'mcp_servers.zapbip.default_tools_approval_mode="approve"' "Call send_message with the text '✅ 安装完成'"`。一条内容为 ✅ 安装完成 的 `send_message` 会到达你的 WhatsApp。如果命令失败，它会停下并显示最后 20 行。然后重启 Codex。

## 检查是否正常工作

让 Codex 向你的 WhatsApp 发送 `✅ 安装完成`。它应在几秒内到达。

<Chat messages={[{ name: 'Codex', text: '✅ 安装完成', time: '11:03' }]} />

如果什么也没收到，请参见[故障排查](/zh/help/troubleshooting)。
