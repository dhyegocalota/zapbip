| आप क्या कर सकते हैं                             | Gemini CLI              |
| ----------------------------------------------- | ----------------------- |
| टेक्स्ट, फ़ोटो, वीडियो, ऑडियो और दस्तावेज़ पाना | हाँ                     |

## यह कैसे सुनता है

जगाने का तरीका: लोकल। Gemini CLI एक बैकग्राउंड टर्मिनल में zapbip लिसनर चलाता है और उसे चलाए रखता है। जब आप WhatsApp पर लिखते हैं, तो वहाँ एक नई लाइन आती है और सेशन जाग जाता है। वह टर्मिनल खुला रखें: Gemini CLI में शेड्यूल करने का कोई विकल्प नहीं है।

```bash
npx zapbip@0.2.0 listen
```

जब तक कोई सवाल खुला है, Gemini CLI एक बार में 50 सेकंड तक इंतज़ार करता है। अगर आपने जवाब नहीं दिया है, तो इंतज़ार "पेंडिंग" पर खत्म होता है और Gemini CLI फिर से कॉल करता है, जितनी बार ज़रूरी हो, कोई समय-सीमा नहीं है।

एक समय में एक ही लिसनर चलाएँ। दूसरा लिसनर पहले वाले की जगह ले लेता है।

## शुरू से सेटअप करें

1. **WhatsApp पर zapbip नंबर को संदेश भेजें।** `नया एजेंट gemini-cli` भेजें। [शुरुआत कैसे करें](/hi/get-started/how-to-start) में हर संदेश दिखाया गया है।

   <Chat
     messages={[
       { you: true, text: 'नया एजेंट gemini-cli', time: '09:00' },
       { name: 'zapbip', text: 'एजेंट gemini-cli बन गया। इसे अपने एजेंट में पेस्ट करें।', time: '09:00' },
     ]}
   />

2. **लाइन को Gemini CLI में पेस्ट करें।** zapbip आपके लिए बनी एक लाइन भेजता है:

   <InstallPrompt />

3. **हर बदलाव पर हाँ कहें।** Gemini CLI बताता है कि वह कौन-सी सेटिंग बदल रहा है और आपकी हाँ का इंतज़ार करता है। लिंक को उन चैट्स में न डालें जिन्हें आप शेयर करते हैं।

4. **zapbip को Gemini CLI में जोड़ें।** आपकी हाँ के बाद यह `gemini mcp add --transport http --scope user zapbip <connectionLink>` चलाता है।

5. **सुनना शुरू करें।** यह एक बैकग्राउंड टर्मिनल में `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.2.0 listen` चलाता है और उस टर्मिनल को चलाए रखता है, बिना किसी समय-सीमा के। जब भी वहाँ नई लाइन आती है, यह `check_inbox` कॉल करता है और जवाब देता है।

6. **टेस्ट करें।** एक नए प्रोसेस में यह `gemini -p "Call send_message with the text '✅ इंस्टॉल हो गया'"` चलाता है। ✅ इंस्टॉल हो गया वाला एक `send_message` आपके WhatsApp पर पहुँचता है। अगर कमांड फ़ेल हो जाए, तो यह रुक जाता है और आखिरी 20 लाइनें दिखाता है। फिर Gemini CLI को फिर से शुरू करें।

## जाँचें कि यह काम करता है

Gemini CLI से कहें कि वह WhatsApp पर `✅ इंस्टॉल हो गया` भेजे। यह पहुँच जाए, तो कनेक्शन काम कर रहा है।

<Chat messages={[{ name: 'Gemini CLI', text: '✅ इंस्टॉल हो गया', time: '09:03' }]} />

अगर यह नहीं पहुँचता, तो Gemini CLI को फिर से शुरू करें और दोबारा कहें।

जिन ऐप्स को हाथ से सेटअप करना पड़ता है, उनके लिए [किसी भी MCP क्लाइंट को जोड़ें](/hi/developers/any-mcp-client) देखें।
