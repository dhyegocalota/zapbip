## क्या-क्या काम करता है

| आप क्या कर सकते हैं                              | कोई भी MCP ऐप                          |
| ------------------------------------------------ | -------------------------------------- |
| टेक्स्ट, फ़ोटो, वीडियो, ऑडियो और दस्तावेज़ भेजना | हाँ                                    |
| लोकेशन, संपर्क और रिएक्शन पाना                   | हाँ                                    |
| बटन या लिस्ट से पूछना और इंतज़ार करना            | हाँ                                    |
| पहले आप लिखें तो बातचीत शुरू करना                | आपका संदेश इनबॉक्स में इंतज़ार करता है |

## यह कैसे सुनता है

जगाने का तरीका: इनबॉक्स। ऐप को बाहर से जगाने का कोई तरीका नहीं है, इसलिए आपका भेजा संदेश तब तक इनबॉक्स में इंतज़ार करता है, जब तक ऐप उसे देख न ले। ऐप `check_inbox` से zapbip से पूछता है कि कुछ नया आया है या नहीं, और उसे पढ़ लेता है।

सुनने के लिए ऐप आपसे `ask` या `wait_for_reply` से पूछता है। अगर आपने जवाब नहीं दिया है, तो हर कॉल ज़्यादा से ज़्यादा 50 सेकंड बाद "पेंडिंग" लौटाती है, और ऐप आपके जवाब देने तक फिर से कॉल करता रहता है। कोई समय-सीमा नहीं है।

## शुरू से सेटअप करें

1. **WhatsApp पर zapbip नंबर को संदेश भेजें।** `नया एजेंट my-app` भेजें। [शुरुआत कैसे करें](/hi/get-started/how-to-start) में हर संदेश दिखाया गया है।

   <Chat
     messages={[
       { you: true, text: 'नया एजेंट my-app', time: '09:00' },
       { name: 'zapbip', text: 'एजेंट my-app बन गया। इसे अपने एजेंट में पेस्ट करें।', time: '09:00' },
     ]}
   />

2. **लाइन को अपने ऐप के AI में पेस्ट करें।** zapbip आपके लिए बनी एक लाइन भेजता है:

   <InstallPrompt />

3. **सर्वर जोड़ें।** ऐप की MCP सेटिंग्स में AI, zapbip के पते को streamable HTTP सर्वर के रूप में जोड़ता है। इस पते में एक सीक्रेट होता है, इसलिए इसे किसी को न दिखाएँ। अगर ऐप इसकी जगह हेडर माँगे, तो AI सीक्रेट को `Authorization: Bearer <secret>` के रूप में भेजता है।

4. **बीच-बीच में इनबॉक्स देखें।** ऐप जब भी मौका मिले `check_inbox` कॉल करता है, जैसे हर टास्क की शुरुआत में।

## जाँचें कि यह काम करता है

AI से कहें कि वह WhatsApp पर `✅ इंस्टॉल हो गया` भेजे। यह पहुँच जाए, तो कनेक्शन काम कर रहा है।

<Chat messages={[{ name: 'मेरा ऐप', text: '✅ इंस्टॉल हो गया', time: '09:03' }]} />

फिर WhatsApp पर कुछ लिखें और ऐप से इनबॉक्स देखने को कहें: वह आपका संदेश पढ़ लेता है।

पते, हेडर और टूल्स के लिए [किसी भी MCP क्लाइंट को जोड़ें](/hi/developers/any-mcp-client) देखें।
