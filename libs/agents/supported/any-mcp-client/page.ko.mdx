## 지원하는 기능

| 할 수 있는 일                             | MCP 앱                            |
| ----------------------------------------- | --------------------------------- |
| 텍스트, 사진, 동영상, 오디오, 문서 보내기 | 예                                |
| 위치, 연락처, 반응 받기                   | 예                                |
| 버튼이나 목록으로 질문하고 기다리기       | 예                                |
| 내가 먼저 쓸 때 대화 시작하기             | 내 메시지는 받은편지함에서 기다림 |

## 수신 방식

단계: 받은편지함. 밖에서 앱을 깨울 방법이 없으므로, 내가 보낸 메시지는 앱이 볼 때까지 받은편지함에서 기다려요. 앱은 `check_inbox`로 zapbip에 새로운 것이 기다리는지 묻고 읽어 가요.

듣기 위해 앱은 `ask`나 `wait_for_reply`로 나에게 물어요. 내가 답하지 않으면 각 호출은 최대 50초 뒤에 보류 중(pending)을 반환하고, 앱은 내가 답할 때까지 다시 호출해요. 시간 제한 없이 기다려요.

## 처음부터 설정하기

1. **WhatsApp에서 zapbip 번호로 메시지를 보내요.** `새 에이전트 my-app`을 보내세요. 명령어는 한국어, 영어, 포르투갈어 단어로 입력할 수 있어요. 모든 메시지는 [시작하기](/ko/get-started/how-to-start)에 나와 있어요.

   <Chat
     messages={[
       { you: true, text: '새 에이전트 my-app', time: '09:00' },
       { name: 'zapbip', text: 'Agent my-app created. Paste this into your agent.', time: '09:00' },
     ]}
   />

2. **그 줄을 앱의 AI에 붙여 넣어요.** zapbip이 나를 위해 만든 한 줄로 답해요.

   <InstallPrompt />

3. **서버를 추가해요.** 앱의 MCP 설정에서 AI가 zapbip 주소를 스트리밍 가능한 HTTP 서버로 추가해요. 주소에는 시크릿이 들어 있으므로 비공개로 유지하세요. 앱이 헤더를 요구하면 시크릿을 `Authorization: Bearer <secret>`으로 보내요.

4. **가끔 받은편지함을 확인해요.** 앱은 가능할 때 `check_inbox`를 호출해요. 예를 들어 각 작업을 시작할 때예요.

## 작동 확인

AI에게 WhatsApp으로 `✅ 설치 완료`를 보내라고 요청하세요. 도착하면 연결이 작동하는 것이에요.

<Chat messages={[{ name: 'My app', text: '✅ 설치 완료', time: '09:03' }]} />

그다음 WhatsApp에 무언가 쓰고 앱에게 받은편지함을 확인하라고 요청하세요. 앱이 내 메시지를 읽어요.

주소, 헤더, 도구에 대해서는 [모든 MCP 클라이언트 연결하기](/ko/developers/any-mcp-client)를 보세요.
