## 使えること

| やりたいこと                      | claude.ai                                                                |
| --------------------------------- | ------------------------------------------------------------------------ |
| claude.aiからメッセージを受け取る | テキスト、写真、動画、音声、ドキュメント、位置情報、連絡先、リアクション |
| タップで答える                    | ボタンとリスト。タップを待ちます                                         |
| WhatsAppから先に書く              | はい。タスクが約16 秒で起こします                                        |
| 質問を何時間も開いたままにする    | はい。時間制限はありません                                               |

<Chat
  messages={[
    { name: 'Claude', text: 'レポートができました。チームに送りますか？', options: ['はい', 'まだ'], time: '08:15' },
    { you: true, text: 'はい', time: '08:16' },
  ]}
/>

## 聞き取りの仕組み

起動方式: **Webhook**。WhatsAppで書き込むと、zapbipがclaude.aiのタスクのトリガーリンクを呼び出し、タスクがあなたのコネクタとともにクラウドで動きます。承認の確認なしで、書き込んでから約16 秒で答えます。

- claude.aiのタスクは、スケジュール実行が最短で1 時間に1回です。そのため、メッセージを確認する1 時間ごとのタスクも作成します。これはあくまでセーフティネットで、ウェイクが取りこぼされても、1 時間以上待たされないようにするものです。

AIがあなたに何かを尋ねると、zapbipはその質問を保持し、最大でも50 秒ごとに「保留中」と答えます。claude.aiはそのたびにもう一度呼び出し、あなたが答えるまで呼び出しを続けます。時間制限なしで待ち続けます。

claude.aiは1回の答えを約4 分待ち、自分で再試行するので、全体としての制限はありません。

## ゼロから設定する

1. **WhatsAppでzapbipの番号にメッセージを送ります。** 任意のテキスト、たとえば `hi` を送ってください。

   <StartLink />

2. **新しいエージェントを依頼します。** エージェントとは、接続するAI1つのことです。コマンドは今のところ英語かポルトガル語の言葉で入力します。

   <Chat
     messages={[
       { you: true, text: 'new agent claude-ai', time: '08:00' },
       {
         name: 'zapbip',
         text: 'Agent claude-ai created. Paste this into your agent: Connect yourself to my WhatsApp with zapbip: read https://mcp.zapbip.com/i/zb_inst_<code> and follow the instructions. This link works once for 30 minutes. Do not share it. If the link expires or was used, send "rotate claude-ai".',
         time: '08:00',
       },
     ]}
   />

3. **その1行をclaude.aiに貼り付けます。**

   <InstallPrompt />

   claude.aiは指示を読み、順番に従います。リンクはシークレットなので、共有するチャットには出さないでください。

4. **コネクタを貼り付けます。** claude.aiが、設定で `<connectionLink>` をカスタムコネクタとして貼り付けるよう案内します。claude.aiでは追加できるのがあなただけなので、これはあなた自身で行います。

5. **ウェイク用のタスクを作成します。** claude.ai/code/routines でAPIトリガー付きのタスクを作成し、その実行URLとトークンをチャットに貼り付けるよう案内されます。2回目の貼り付けもあなたの作業です。claude.aiはトークンをあなたにしか見せないからです。

6. **起こし方をzapbipに伝えます。** タスクを作る前に手を止めた場合は、`set_wake({mode: "none"})` を呼び、チャットが新しいメッセージを見るのは、あなたがチャットを開いたときだけだと伝えます。そうでなければ `set_wake({mode: "webhook", url, token})` を呼びます。

7. **1 時間ごとのセーフティネットを作成します。** `check_inbox` を呼ぶ1 時間ごとのタスクを作成するよう案内されます。ウェイクが取りこぼされても、1 時間以上待たされないようにするためです。

8. **テストします。** チャットで、`send_message` を呼び、✅ installed を送ります。

## 動作の確認

接続が済むと、claude.aiはあなたのWhatsAppに `✅ installed` を送ります。

<Chat messages={[{ name: 'Claude', text: '✅ installed', time: '08:05' }]} />

何も届かない場合は、[トラブルシューティング](/ja/help/troubleshooting)をご覧ください。
