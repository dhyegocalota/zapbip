## क्या-क्या काम करता है

OpenClaw एक छोटे zapbip चैनल के ज़रिए आपके WhatsApp पर सुनता रहता है। आप पहले लिखें या किसी सवाल का जवाब बाद में दें, संदेश OpenClaw के सेशन तक पहुँच जाता है।

<Chat
  contact="OpenClaw"
  messages={[
    { you: true, text: 'कल सुबह 9 बजे मुझे इनवॉइस भेजने की याद दिलाना।', time: '18:02' },
    { name: 'OpenClaw', text: 'हो गया। कल 9:00 बजे याद दिला दिया जाएगा।', time: '18:02' },
  ]}
/>

### आपके फ़ॉरवर्ड किए संदेश

किसी और का जो संदेश आप फ़ॉरवर्ड करते हैं, वह OpenClaw तक एक लेबल के साथ पहुँचता है, जो बताता है कि इसे आपने नहीं लिखा, और उससे कोई कमांड नहीं चल सकती।

## यह कैसे सुनता है

जगाने का तरीका: लोकल। जब तक कोई सवाल खुला है, OpenClaw एक बार में 50 सेकंड तक इंतज़ार करता है। अगर आपने जवाब नहीं दिया है, तो इंतज़ार "पेंडिंग" पर खत्म होता है और OpenClaw फिर से कॉल करता है, जितनी बार ज़रूरी हो, कोई समय-सीमा नहीं है।

चैनल zapbip से एक कनेक्शन खुला रखता है, बिना किसी समय-सीमा के। नेटवर्क टूट जाए, तो यह खुद फिर से जुड़ता है, और हर नाकाम कोशिश के बाद थोड़ा ज़्यादा इंतज़ार करता है (पहले 1 सेकंड, ज़्यादा से ज़्यादा 30 सेकंड)। इस बीच आपके भेजे संदेश आपके zapbip इनबॉक्स में इंतज़ार करते हैं, और वापस जुड़ते ही चैनल हर उस संदेश को उठा लेता है जिसका जवाब नहीं गया था।

### अगर चैनल इंस्टॉल न हो सके

OpenClaw इसकी जगह तय समय पर इनबॉक्स देख सकता है। सेटअप वाला MCP सर्वर जोड़ें और हर 1 मिनट में चलने वाला एक जॉब बनाएँ जो `check_inbox` कॉल करे। आपके संदेश एक मिनट तक इंतज़ार करते हैं, और जवाब भी इसी रास्ते आता है।

## शुरू से सेटअप करें

### आपको क्या चाहिए

- OpenClaw 2026.10.10 या नया, जिसका gateway चल रहा हो।
- आपका कनेक्शन लिंक, वही `https://.../c/<secret>/mcp` लिंक जिससे आपका AI zapbip से बात करता है। इसे पासवर्ड की तरह संभालें।

### चैनल इंस्टॉल करें

यह प्लगइन इस एजेंट के लिए आए आपके संदेश zapbip से पढ़ता है और एजेंट के जवाब वापस भेजता है। इसके अलावा यह कुछ नहीं करता। इंस्टॉल कमांड में `--accept-capabilities` ज़रूरी है, ताकि OpenClaw आपसे दोबारा पूछे बिना इसे इंस्टॉल कर सके।

```bash
openclaw plugins install @zapbip/openclaw-plugin@0.1.0 --force --accept-capabilities
```

फिर `openclaw.json` में `zapbip` चैनल पर लिंक सेट करें और प्लगइन चालू करें:

```json
{
  "channels": { "zapbip": { "connectionLink": "https://<host>/c/<secret>/mcp" } },
  "plugins": { "entries": { "zapbip": { "enabled": true } } }
}
```

जिस फ़ाइल में आपका कनेक्शन लिंक है, वह पासवर्ड की तरह काम करती है। उसे `600` परमिशन दें ताकि सिर्फ़ आपका यूज़र उसे पढ़ सके, और उसे कभी शेयर या commit न करें:

```bash
chmod 600 <file>
```

gateway को फिर से शुरू करें।

हर एजेंट के लिए सिर्फ़ एक लिसनर चलाएँ: प्लगइन या `npx zapbip@0.1.0 listen`, दोनों कभी नहीं। दूसरा लिसनर पहले वाले की जगह ले लेता है।

### OpenClaw कैसे जवाब देता है

आपके संदेशों पर OpenClaw के जवाब खुद चैनल के ज़रिए वापस जाते हैं, बिना किसी अलग सेटअप के। अगर कोई जवाब भेजना फ़ेल हो जाए, तो चैनल gateway लॉग में `plugin_reply_failed` लिखता है और दोबारा कोशिश नहीं करता, इसलिए वह जवाब खो सकता है।

zapbip को MCP सर्वर के रूप में जोड़ें, ताकि OpenClaw आपसे बातचीत शुरू भी कर सके, बटन के साथ सवाल पूछकर जवाब का इंतज़ार कर सके, और ऊपर बताया गया पोलिंग वाला विकल्प इस्तेमाल कर सके:

```json
{
  "mcp": {
    "servers": {
      "zapbip": { "url": "https://<host>/c/<secret>/mcp", "transport": "streamable-http" }
    }
  }
}
```

फिर WhatsApp पर OpenClaw से `✅ इंस्टॉल हो गया` भेजने को कहें। यह संदेश पहुँच जाए, तो सब काम कर रहा है।

<Chat
  contact="zapbip"
  messages={[
    { you: true, text: 'इंस्टॉल हो जाए तो ✅ इंस्टॉल हो गया भेजना।', time: '18:10' },
    { name: 'OpenClaw', text: '✅ इंस्टॉल हो गया', time: '18:10' },
  ]}
/>

## जाँचें कि यह काम करता है

| आपको क्या दिखता है                                 | इसका मतलब                                                                                                                  |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| आपके संदेश का कोई जवाब नहीं आता                     | gateway नहीं चल रहा, `channels.zapbip` में `connectionLink` नहीं है, या `plugins.entries.zapbip.enabled` `true` नहीं है।     |
| चैनल अपने आप रुक जाता है                            | उसी कनेक्शन के लिए कोई दूसरा चैनल या कनेक्टर शुरू हुआ और उसकी जगह ले ली।                                                  |
| OpenClaw आपकी बात सुनता है पर जवाब कभी नहीं आता      | gateway लॉग में `plugin_reply_failed` दिखता है: जवाब भेजना फ़ेल हुआ और दोबारा कोशिश नहीं होती। फिर से लिखें।                  |
| OpenClaw न बातचीत शुरू कर पाता है, न आपसे पूछ पाता है | `mcp.servers` में `zapbip` MCP सर्वर नहीं है।                                                                               |
| चैनल किसी गड़बड़ी के साथ रुक जाता है                  | लिंक पहचाना नहीं गया या कनेक्शन हटा दिया गया। नया लिंक माँगें।                                                              |
