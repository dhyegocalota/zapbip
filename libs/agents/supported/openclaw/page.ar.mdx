## ما الذي يعمل

يستمع OpenClaw إلى WhatsApp الخاص بك باستمرار عبر قناة zapbip صغيرة. وسواء راسلته أولًا أو أجبت لاحقًا عن سؤال، تصل الرسالة إلى جلسة OpenClaw.

<Chat
  contact="OpenClaw"
  messages={[
    { you: true, text: 'ذكّرني غدًا في التاسعة صباحًا بإرسال الفاتورة.', time: '18:02' },
    { name: 'OpenClaw', text: 'حسنًا. سأذكّرك غدًا في 9:00.', time: '18:02' },
  ]}
/>

### الرسائل التي تعيد توجيهها

الرسائل التي تعيد توجيهها من شخص آخر تصل إلى OpenClaw مع وسم يبيّن أنك لم تكتبها، ولا يستطيع تنفيذ أوامر بسببها.

## كيف يستمع

المستوى: محلي. عندما يكون هناك سؤال معلّق، ينتظر OpenClaw 50 ثانية على الأكثر في كل مرة. وإذا لم تجب بعد، ينتهي هذا الانتظار بحالة «قيد الانتظار» (pending)، فيستدعي OpenClaw مرة أخرى، بقدر ما يلزم، دون حد زمني.

تُبقي القناة اتصالًا واحدًا مفتوحًا بـ zapbip، دون حد زمني. وإذا انقطعت الشبكة، تعيد الاتصال تلقائيًا، وتنتظر بعد كل فشل مدة أطول قليلًا (ثانية واحدة في البداية، و30 ثانية على الأكثر). وخلال ذلك تنتظر رسائلك في صندوق وارد zapbip، وتجلب القناة فور عودتها كل رسالة لم يُجَب عنها.

### إذا تعذّر تثبيت القناة

يستطيع OpenClaw الاستعلام الدوري بدلًا من ذلك. أضف خادم MCP في الإعدادات، وأنشئ مهمة تستدعي `check_inbox` كل دقيقة. تنتظر رسائلك دقيقة على الأكثر، ويصل الجواب بالطريقة نفسها.

## الإعداد من الصفر

### ما الذي تحتاج إليه

- OpenClaw بالإصدار 2026.10.10 أو أحدث، مع تشغيل البوابة (gateway).
- رابط اتصالك، وهو الرابط نفسه `https://.../c/<secret>/mcp` الذي يستخدمه الذكاء الاصطناعي لديك للتواصل مع zapbip. عامله كما تعامل كلمة المرور.

### ثبّت القناة

يقرأ هذا المكوّن الإضافي رسائلك الموجّهة إلى هذا الوكيل من zapbip وينشر ردود الوكيل عائدةً إليها. ولا يفعل شيئًا غير ذلك. يحتاج أمر التثبيت إلى `--accept-capabilities` ليثبّته OpenClaw دون أن يسألك مرة أخرى.

```bash
openclaw plugins install @zapbip/openclaw-plugin@0.1.0 --force --accept-capabilities
```

ثم اضبط الرابط على قناة `zapbip` وفعّل المكوّن الإضافي في `openclaw.json`:

```json
{
  "channels": { "zapbip": { "connectionLink": "https://<host>/c/<secret>/mcp" } },
  "plugins": { "entries": { "zapbip": { "enabled": true } } }
}
```

الملف الذي يحمل رابط اتصالك يعادل كلمة مرور. اجعل صلاحياته `600` ليقرأه مستخدمك وحده، ولا تشاركه ولا ترفعه إلى commit:

```bash
chmod 600 <file>
```

أعد تشغيل البوابة.

شغّل مستمعًا واحدًا فقط لكل وكيل: المكوّن الإضافي أو `npx zapbip@0.1.0 listen`، وليس الاثنين معًا. المستمع الثاني يحل محل الأول.

### كيف يجيب OpenClaw

تعود ردود OpenClaw على رسائلك عبر القناة نفسها، دون إعداد إضافي. وإذا فشل إرسال رد، تكتب القناة `plugin_reply_failed` في سجل البوابة ولا تعيد المحاولة، فقد يضيع ذلك الرد.

أضف zapbip خادم MCP ليتمكن OpenClaw أيضًا من بدء محادثة معك، وسؤالك بالأزرار وانتظار الجواب، ومن استخدام بديل الاستعلام الدوري أدناه:

```json
{
  "mcp": {
    "servers": {
      "zapbip": { "url": "https://<host>/c/<secret>/mcp", "transport": "streamable-http" }
    }
  }
}
```

ثم اطلب من OpenClaw على WhatsApp أن يرسل `✅ تم التثبيت`. إذا وصلت هذه الرسالة فكل شيء سليم.

<Chat
  contact="zapbip"
  messages={[
    { you: true, text: 'أرسل ✅ تم التثبيت عندما ينتهي التثبيت.', time: '18:10' },
    { name: 'OpenClaw', text: '✅ تم التثبيت', time: '18:10' },
  ]}
/>

## تحقق من أنه يعمل

| ما تراه                             | معناه                                                                                                              |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| رسالتك لا تُجاب                     | البوابة لا تعمل، أو لا يوجد `connectionLink` في `channels.zapbip`، أو `plugins.entries.zapbip.enabled` ليس `true`. |
| توقفت القناة من تلقاء نفسها         | بدأت قناة أخرى أو موصّل آخر للاتصال نفسه وحلّ محلها.                                                               |
| سمعك OpenClaw لكن الرد لا يصل أبدًا | ظهر `plugin_reply_failed` في سجل البوابة: فشل إرسال الرد ولن تُعاد المحاولة. اكتب مرة أخرى.                        |
| OpenClaw لا يبدأ محادثة ولا يسألك   | خادم MCP باسم `zapbip` غير موجود في `mcp.servers`.                                                                 |
| توقفت القناة بخطأ                   | الرابط غير معروف أو أُبطل الاتصال. اطلب رابطًا جديدًا.                                                             |
