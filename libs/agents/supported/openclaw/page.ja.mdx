## 使えること

OpenClawは、小さなzapbipチャネルを通して、あなたのWhatsAppを聞き続けます。あなたから先に書いても、質問に後から答えても、メッセージはOpenClawのセッションに届きます。

<Chat
  contact="OpenClaw"
  messages={[
    { you: true, text: '明日の9時に請求書を送るよう思い出させて。', time: '18:02' },
    { name: 'OpenClaw', text: '了解です。明日の9:00にお知らせします。', time: '18:02' },
  ]}
/>

### 転送したメッセージ

ほかの人から転送したメッセージは、あなたが書いたものではないと示すラベルが付いてOpenClawに届き、コマンドを実行することはできません。

## 聞き取りの仕組み

段: ローカル。質問が開いている間、OpenClawは一度に最大50 秒待ちます。あなたが答えていない場合、待機は保留中（pending）で終わり、OpenClawは必要なだけ何度でも、もう一度呼び出します。時間制限なしです。

チャネルは、zapbipへの接続を1本、時間制限なしで開いたままにします。ネットワークが切れると自分で再接続し、失敗するたびに待ち時間を少しずつ延ばします（最初は1 秒、最長30 秒）。その間にあなたが送ったメッセージはzapbipの受信トレイで待ち、チャネルは復帰するとすぐに、未回答のメッセージをすべて拾い上げます。

### チャネルをインストールできない場合

代わりにOpenClawがポーリングできます。設定で示したMCPサーバーを追加し、`check_inbox` を呼ぶ1 分ごとのジョブを作成します。メッセージは最大1 分待たされ、答えも同じように届きます。

## ゼロから設定する

### 必要なもの

- ゲートウェイが動いているOpenClaw 2026.10.10以降。
- 接続リンク。AIがzapbipと話すのに使うのと同じ `https://.../c/<secret>/mcp` のリンクです。パスワードと同じように扱ってください。

### チャネルをインストールする

プラグインは、このエージェント宛てのあなたのメッセージをzapbipから読み取り、エージェントの返信を送り返します。それ以外のことはしません。インストールのコマンドには `--accept-capabilities` が必要で、これによりOpenClawがもう一度あなたに尋ねずにインストールできます。

```bash
openclaw plugins install @zapbip/openclaw-plugin@0.1.0 --force --accept-capabilities
```

次に、`zapbip` チャネルにリンクを設定し、`openclaw.json` でプラグインを有効にします。

```json
{
  "channels": { "zapbip": { "connectionLink": "https://<host>/c/<secret>/mcp" } },
  "plugins": { "entries": { "zapbip": { "enabled": true } } }
}
```

接続リンクを保持するファイルはパスワードと同じ働きをします。自分のユーザーだけが読めるように権限を `600` にし、共有したりコミットしたりしないでください。

```bash
chmod 600 <file>
```

ゲートウェイを再起動します。

エージェントごとにリスナーは 1 つだけ実行してください。プラグインか `npx zapbip@0.1.0 listen` のどちらか一方で、両方は使わないでください。2 つ目のリスナーは 1 つ目を置き換えます。

### OpenClawの答え方

OpenClawは、あなたのメッセージへの返信を、追加の設定なしで、チャネル自身を通して返します。返信の送信に失敗した場合、チャネルはゲートウェイのログに `plugin_reply_failed` を書き、再試行しないので、その返信は失われることがあります。

zapbipをMCPサーバーとして追加すると、OpenClawから会話を始めたり、ボタン付きで質問して答えを待ったり、後述のポーリングによる代替手段を使ったりできます。

```json
{
  "mcp": {
    "servers": {
      "zapbip": { "url": "https://<host>/c/<secret>/mcp", "transport": "streamable-http" }
    }
  }
}
```

そのうえで、WhatsAppでOpenClawに `✅ installed` を送るよう頼んでください。そのメッセージが届けば、動作しています。

<Chat
  contact="zapbip"
  messages={[
    { you: true, text: 'インストールできたら ✅ installed を送って。', time: '18:10' },
    { name: 'OpenClaw', text: '✅ installed', time: '18:10' },
  ]}
/>

## 動作の確認

| 見えるもの                                     | 意味                                                                                                                                         |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| メッセージに答えが返ってこない                 | ゲートウェイが動いていない、`channels.zapbip` に `connectionLink` がない、または `plugins.entries.zapbip.enabled` が `true` ではありません。 |
| チャネルが自動で止まる                         | 同じ接続に対して別のチャネルまたはコネクタが起動し、置き換えました。                                                                         |
| OpenClawはあなたの声を聞いたが、返信が届かない | ゲートウェイのログに `plugin_reply_failed` が出ています。返信の送信に失敗し、再試行されません。もう一度書いてください。                      |
| OpenClawから会話を始められない、質問できない   | `zapbip` のMCPサーバーが `mcp.servers` にありません。                                                                                        |
| チャネルがエラーで停止する                     | リンクが不明か、接続が取り消されています。新しいものを依頼してください。                                                                     |
