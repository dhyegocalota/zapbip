## 지원하는 기능

Hermes는 작은 zapbip 플러그인을 통해 내 WhatsApp을 계속 들어요. 내가 먼저 쓰거나 나중에 질문에 답하면 메시지가 Hermes 세션에 도착해요.

<Chat
  contact="Hermes"
  messages={[
    { you: true, text: '오늘 저장소에서 바뀐 내용을 요약해 줘.', time: '18:02' },
    { name: 'Hermes', text: '커밋이 세 개예요. 결제 수정, 새 테스트, 문서 업데이트예요.', time: '18:03' },
  ]}
/>

### 내가 전달한 메시지

다른 사람에게서 전달받은 메시지는 내가 쓴 것이 아니라는 라벨이 붙어 Hermes에 도착하므로, Hermes는 그것을 내 지시로 취급하지 않아요.

## 수신 방식

단계: 로컬. 질문이 열려 있는 동안 Hermes는 한 번에 최대 50초 기다려요. 내가 답하지 않으면 대기가 보류 중(pending)으로 끝나고, Hermes는 필요한 만큼 몇 번이든 다시 호출해요. 시간 제한 없이 기다려요.

플러그인은 zapbip으로 가는 연결 하나를 시간 제한 없이 열어 둬요. 네트워크가 끊기면 스스로 다시 연결하며, 실패할 때마다 조금씩 더 오래 기다려요(처음에는 1초, 최대 30초). 그동안 내가 보낸 메시지는 zapbip 받은편지함에서 기다리고, 플러그인은 돌아오는 즉시 답하지 못한 메시지를 모두 가져와요.

### 플러그인을 설치할 수 없을 때

대신 Hermes가 폴링할 수 있어요. 설정에 나온 MCP 서버를 추가하고, `check_inbox`를 호출하는 1분마다 도는 작업을 만드세요. 메시지는 최대 1분 기다리고, 답도 같은 방식으로 와요.

## 처음부터 설정하기

### 필요한 것

- 게이트웨이가 실행 중인 Hermes.
- 연결 링크. AI가 zapbip과 이야기할 때 쓰는 것과 같은 `https://.../c/<secret>/mcp` 링크예요. 비밀번호처럼 다루세요.

### 플러그인 설치

Hermes가 실행되는 Python 환경에 패키지를 설치해요.

```bash
d=$(mktemp -d) && curl -fsSL https://mcp.zapbip.com/pkg/zapbip_platform-0.2.0-requirements.txt -o "$d/zapbip-requirements.txt" && python3 -c 'import hashlib,sys; sys.exit(hashlib.sha256(open(sys.argv[1],"rb").read()).hexdigest() != sys.argv[2])' "$d/zapbip-requirements.txt" 5e3c28d1d8170431504b4fe3780e897ac80c5fd3d134ce8ad5f9abf214ecd3f4 && python3 -m pip install --only-binary=:all: --require-hashes -r "$d/zapbip-requirements.txt"
```

그다음 `~/.hermes/config.yaml`에서 활성화해요.

```yaml
plugins:
  enabled:
    - zapbip-platform
```

링크와 Hermes와 이야기할 수 있는 사람을 게이트웨이가 실행되는 환경에 설정하세요. 공유하는 파일에는 절대 쓰지 마세요.

```bash
export ZAPBIP_CONNECTION_LINK='https://<host>/c/<secret>/mcp'
export ZAPBIP_ALLOWED_USERS=owner
```

연결 링크가 들어 있는 파일은 비밀번호처럼 작동해요. 내 사용자만 읽을 수 있도록 권한을 `600`으로 설정하고, 공유하거나 커밋하지 마세요.

```bash
chmod 600 <file>
```

게이트웨이를 다시 시작하세요.

에이전트마다 리스너는 하나만 실행하세요. 플러그인 또는 `npx zapbip@0.2.0 listen` 중 하나만 쓰고, 둘 다 쓰지 마세요. 두 번째 리스너는 첫 번째를 대체해요.

### Hermes가 답하는 방식

Hermes는 내 메시지에 대한 답을 추가 설정 없이 플러그인 자체를 통해 돌려보내요.

zapbip을 MCP 서버로 추가하면 Hermes가 나와 대화를 먼저 시작하거나, 버튼으로 질문하고 답을 기다리거나, 아래의 폴링 대안을 쓸 수 있어요.

```yaml
mcp_servers: { zapbip: { url: 'https://<host>/c/<secret>/mcp' } }
```

그다음 WhatsApp에서 Hermes에게 `✅ 설치 완료`를 보내라고 요청하세요. 그 메시지가 도착하면 작동하는 것이에요.

<Chat
  contact="zapbip"
  messages={[
    { you: true, text: '설치가 끝나면 ✅ 설치 완료를 보내 줘.', time: '18:10' },
    { name: 'Hermes', text: '✅ 설치 완료', time: '18:10' },
  ]}
/>

## 작동 확인

| 보이는 것                                 | 의미                                                                      |
| ----------------------------------------- | ------------------------------------------------------------------------- |
| 내 메시지에 답이 없음                     | 게이트웨이가 실행되고 있지 않거나, 플러그인이 `plugins.enabled`에 없어요. |
| 플러그인이 스스로 멈춤                    | 같은 연결에 다른 플러그인이나 커넥터가 시작되어 대체했어요.               |
| Hermes가 대화를 시작하거나 질문할 수 없음 | `config.yaml`에 `zapbip` MCP 서버가 없어요.                               |
| 플러그인이 오류와 함께 멈춤               | 링크를 알 수 없거나 연결이 해제되었어요. 새 링크를 요청하세요.            |
