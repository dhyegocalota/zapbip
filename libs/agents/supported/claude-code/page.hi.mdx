## यह कैसे सुनता है

जगाने का तरीका: **लोकल**। आपके कंप्यूटर पर चलने वाला एक कनेक्टर Claude Code को जगाता है, इसलिए आपके लिखने के करीब 7 सेकंड बाद यह जवाब देता है।

- Claude Code को `claude --dangerously-load-development-channels server:zapbip-channel` से शुरू करें। तब zapbip चैनल हर WhatsApp संदेश को आते ही खुले सेशन में पहुँचा देता है।
- अगर सेशन बंद है, तो कनेक्टर उसे करीब 7 सेकंड में फिर से शुरू कर देता है। खाली बैठे रहने पर कोई टोकन खर्च नहीं होता; हर संदेश पर एक टर्न खर्च होता है।
- लिसनर चलता रहने दें। टर्मिनल बंद करने के बाद भी उसे चालू रखने के लिए [कनेक्टर को सर्विस की तरह चलाएँ](/hi/developers/background-running) देखें।

जब आपका AI आपसे कुछ पूछता है, तो zapbip सवाल को रोककर रखता है और ज़्यादा से ज़्यादा हर 50 सेकंड में "पेंडिंग" जवाब देता है। तब आपका AI फिर से कॉल करता है, और आपके जवाब देने तक फिर से कॉल करता रहता है। कोई समय-सीमा नहीं है।

एक ही लिसनर इस्तेमाल करें, दो एक साथ कभी नहीं। अगर चैनल चालू नहीं है, तो Claude Code `npx zapbip@0.1.0 listen` को चलाए रखता है और Monitor से उस पर नज़र रखता है। एक निगरानी ज़्यादा से ज़्यादा 30 मिनट चलती है, इसलिए हर टाइमआउट सूचना पर Claude Code उसे फिर से चालू करता है।

## शुरू से सेटअप करें

1. **WhatsApp पर zapbip नंबर को संदेश भेजें।** कोई भी टेक्स्ट भेजें, जैसे `नमस्ते`।

   <StartLink />

2. **नया एजेंट माँगें।** एजेंट वह एक AI है जिसे आप जोड़ते हैं।

         time: '15:00',
       },

3. **लाइन को Claude Code में पेस्ट करें।**

   <InstallPrompt />

   Claude Code निर्देश पढ़ता है और उन्हें क्रम से पूरा करता है। कोई फ़ाइल या सेटिंग बदलने से पहले यह बताता है कि कौन-सी, और आपकी हाँ का इंतज़ार करता है। लिंक सीक्रेट है, इसलिए इसे उन चैट्स में न डालें जिन्हें आप शेयर करते हैं।

4. **हाँ कहें।** फिर Claude Code बाकी काम इसी क्रम में करता है।

5. **zapbip को Claude Code में जोड़ें।** अगर कोई पुरानी `zapbip` या `zapbip-channel` एंट्री है, तो Claude Code उसे `claude mcp remove --scope user zapbip` या `claude mcp remove --scope user zapbip-channel` से हटाता है। फिर टूल्स के लिए `claude mcp add --transport http --scope user zapbip <connectionLink>` और लाइव चैनल के लिए `claude mcp add --scope user zapbip-channel -e ZAPBIP_CONNECTION_URL=<connectionLink> -- npx zapbip@0.1.0 channel` चलाता है।

   इन स्टेप्स की कमांड में आपका कनेक्शन लिंक होता है, इसलिए वह आपकी shell history में पहुँच जाता है। उसे वहाँ से बाहर रखने के लिए `ZAPBIP_CONNECTION_URL` को एक env फ़ाइल में रखें, जैसा [कनेक्टर को सर्विस की तरह चलाएँ](/hi/developers/background-running) में बताया गया है।

6. **zapbip स्किल सेव करें।** आपकी हाँ के बाद यह `~/.claude/skills/zapbip/SKILL.md` लिखता है, ताकि हर सेशन को पता रहे कि WhatsApp कैसे इस्तेमाल करना है, और `check_inbox` कब कॉल करना है।

7. **एक लिसनर चुनें।** एक कनेक्शन पर एक ही लिसनर चलता है और दूसरा पहले वाले की जगह ले लेता है, इसलिए यह इनमें से ठीक एक इस्तेमाल करता है, दो एक साथ कभी नहीं। रुके हुए सेशन के लिए यह बैकग्राउंड में `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 connect --client claude-code` चलाता है। Claude Code खाली बैठा हो और आप लिखें, तो कनेक्टर आपके सेशन को जगाता है, और बंद सेशन को `claude -p --resume` से फिर से शुरू करता है।

8. **सिर्फ़ तब, जब चैनल उपलब्ध न हों।** यह बैकग्राउंड में `ZAPBIP_CONNECTION_URL=<connectionLink> npx zapbip@0.1.0 listen` चलाता है और Monitor से उस पर नज़र रखता है, हर टाइमआउट सूचना पर उसे फिर से चालू करता है।

9. **टेस्ट करें।** एक नए प्रोसेस में यह `claude -p "Call send_message with the text '✅ इंस्टॉल हो गया'" --allowedTools=mcp__zapbip__send_message` चलाता है। ✅ इंस्टॉल हो गया वाला एक `send_message` आपके WhatsApp पर पहुँचता है। अगर कमांड फ़ेल हो जाए, तो यह रुक जाता है और आखिरी 20 लाइनें दिखाता है। फिर zapbip के टूल्स इस्तेमाल करने के लिए Claude Code को फिर से शुरू करें।

## जाँचें कि यह काम करता है

Claude Code से कहें कि वह आपके WhatsApp पर `✅ इंस्टॉल हो गया` भेजे। यह कुछ ही सेकंड में पहुँच जाना चाहिए।
