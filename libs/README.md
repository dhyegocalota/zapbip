# Libraries

Shared TypeScript the applications in [apps](../apps/) build on. None of them is published on its own.

| Folder | What it is |
| --- | --- |
| [core](core/) | The inbox, routing, delivery and account rules as plain TypeScript behind ports, with no platform code |
| [agents](agents/) | The catalogue of supported agents: one folder per agent with its install guide, from which the docs pages and install pages are generated |
| [types](types/) | Enums and constants shared by every package, with no logic |
