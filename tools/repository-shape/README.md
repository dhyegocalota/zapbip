# @zapbip/repository-shape

Tests about the repository itself rather than any one package: its documents, indexes and links, its root entries, tracked files, test configuration and fixtures, its workflows and release facts, and the shape of the docs site, the agent surfaces, the agent registry and the backoffice, among others. They run as the shape gate of the local verification and as part of the unit suites, and the agent lifecycle runs as its own gate.
